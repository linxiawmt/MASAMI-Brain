    第 7 章 仿真随机服务系统#

    本章解决：回到第 1 章"模拟视角"的完整形态——把一个带时间演化的随机系统（顾客到达、排队、接受服务）在计算机里逐事件推演。内容：排队模型与 Kendall 记号（7.1）、Little 定律推导（7.2）、事件调度法与 M/M/1 模拟器（7.3）、模拟对撞解析答案（7.4）、三种系统对比揭示"变异性是敌人"（7.5）。 承上启下：泊松到达与指数服务正是第 4 章乘积法和第 5 章逆变换的产物；Erlang 服务时间来自 5.5 的卷积性质；误差棒语法来自第 2 章的 CLT；本章的"事件调度"与第 11 章交通流的"时间步进"是离散模拟的两兄弟。

    关键词 事实
    Kendall 记号 到达/服务/台数：M/M/1 = 指数到达、指数服务、单台
    泊松过程 独立指数间隔的累加；计数 \(N(t)\) 围绕 \(\lambda t\) 波动
    Little 定律 \(L=\lambda W\)，与分布和规则无关的守恒式
    事件调度法 只在事件时刻推进时钟；未来事件表
    稳态模拟 先删瞬态（burn-in），再用 replica 间标准差做误差棒

    本章代码：nb/ch07.ipynb（NumPy 实跑，种子 2030）。

    7.1 随机服务系统：三件套与记号#

    一个服务系统由三件套描述：到达过程（顾客何时来）、服务机制（几个台、多快、什么分布）、排队规则（先到先服务 FIFO、优先级……）。Kendall 记号 \(A/B/c\) 把三者写成代号：\(M/M/1\) 读作"马尔可夫到达、马尔可夫服务、单台"——两个 \(M\) 指指数分布（无记忆 = Markov）。

    泊松到达。第 4 章的乘积法在这里"转正"：独立的指数间隔 \(E_i\sim Exp(1/\lambda)\) 累加成到达时刻 \(A_k=E_1+\cdots+E_k\)，计数过程 \(N(t)\) 就是泊松过程。两种刻画完全等价：间隔看是指数分布，计数看是泊松分布（\(\lambda t\) 时刻期望 \(\lambda t\) 个）。一次实现里 \(N(t)\) 沿着 \(\lambda t\) 直线阶梯爬升，但局部忽快忽慢——"均匀的速率，不均匀的到达"：

    指数服务。服务时长 \(S\sim Exp(\mu)\)：均值 \(1/\mu\)，且无记忆（2.3 节拓展框）——"已服务了 10 分钟"不改变"还要多久"。正是无记忆性让 M/M/1 有解析解；反过来，现实服务几乎都不无记忆，这正是需要模拟的地方（7.5）。

    7.2 Little 定律：\(L=\lambda W\)#

    系统内平均人数 \(L\)、到达率 \(\lambda\)、平均逗留时间 \(W\) 之间，存在一个近乎哲学的守恒式：

    \[ L=\lambda W . \]

    推导（图形论证）。在时间轴上，每位顾客的逗留是一根长度为 \(W_i\) 的横条；把所有横条竖起来堆叠，就得到系统人数曲线 \(N(t)\)。于是

    \[ \int_0^T N(t)\,\mathrm dt=\sum_i W_i \quad\Longrightarrow\quad \underbrace{\frac1T\int_0^T N(t)\,\mathrm dt}_{L} =\frac{\sum_i W_i}{T} =\underbrace{\frac{(\lambda T)}{T}}_{\lambda}\cdot \underbrace{\bar W}_{W}, \]

    （\(\lambda T\) 为 \(T\) 内到达人数。）稳态下两边取极限即得 \(L=\lambda W\)。推导没用到任何分布假设——它对任何排队规则、任何服务分布都成立，因此也是模拟器的免费自检：下面模拟出的 \(L\) 与 \(\lambda W\) 应当自动相等。

    7.3 事件调度法（DES）#

    给随机系统计时，有两种推进方式：时间步进（按固定 \(\Delta t\) 扫描，第 11 章交通流用）与事件调度——状态只在事件（到达、离开）时刻变化，时钟直接跳到下一事件。事件稀疏时 DES 极高效：一小时的银行营业，可能只需处理几千个事件而不是十亿个 \(\Delta t\)。

    M/M/1 的模拟器骨架（完整代码见 notebook）只有两个分支：

    while t < T:
    if next_arr < next_dep:              # —— 到达事件
        t = next_arr
        if in_service is None:           # 台空：立即开始服务
            in_service = t; Wq.append(0.0)
            next_dep = t + rng.exponential(1/mu)
        else:
            queue.append(t)              # 入队
        next_arr = t + rng.exponential(1/lam)
    else:                                # —— 离开事件
        t = next_dep
        W.append(t - in_service)         # 逗留 = 离开 − 到达
        if queue:
            in_service = queue.popleft() # 队头补位（保留其到达时刻！）
            Wq.append(t - in_service)
            next_dep = t + rng.exponential(1/mu)
        else:
            in_service = None; next_dep = np.inf

    两个记分约定：\(W_q\)=开始服务−到达（在服务开始时记）、\(W\)=离开−到达（在离开时记）。一个实现细节值得划重点：in_service 必须保存顾客的到达时刻而不是服务开始时刻——否则 \(W\) 会悄悄退化成纯服务时长（本笔记初稿就踩了这个坑，\(\bar W\) 输出恰好 \(1/\mu=1.0\)，一眼锁定）。

    整个模拟器的控制流是一张事件循环图——DES 的"心跳"：

    flowchart TB A["初始化：t = 0，生成首个到达事件"] --> B["从未来事件表取最早的事件"] B --> C{"到达 还是 离开？"} C -- 到达 --> D["台空：立即开始服务，记 Wq = 0<br/>台忙：排入队列"] D --> E["生成下一到达时刻，放入事件表"] C -- 离开 --> F["记 W = t − 该顾客到达时刻<br/>队列非空：队首补位，记其 Wq"] F --> G["生成新的服务完成时刻，放入事件表"] E --> H["时钟跳到最近事件时刻"] G --> H H --> I{"模拟时长到 T 了吗？"} I -- 否 --> B I -- 是 --> J["输出 Wq、W、L 及误差棒"]

    7.4 模拟对撞解析：M/M/1#

    M/M/1 是排队论里罕见的可解模型：由无记忆性，系统是生灭过程，稳态队长的几何分布 \(P_n=(1-\rho)\rho^n\)（\(\rho=\lambda/\mu<1\) 为利用率）。于是

    \[ L=\sum_n n(1-\rho)\rho^n=\frac{\rho}{1-\rho},\qquad W=\frac{L}{\lambda}\ \text{(Little！)}=\frac{1}{\mu-\lambda},\qquad W_q=W-\frac{1}{\mu}=\frac{\rho}{\mu-\lambda}. \]

    取 \(\lambda=0.8,\ \mu=1\)（\(\rho=0.8\)）：理论 \(W_q=4,\ W=5,\ L=4\)。20 个独立 replica（各 \(T=20000\)，丢弃前 500 人）：

    量 模拟 理论
    \(W_q\) \(3.995\pm0.280\) 4.00
    \(W\) \(4.982\pm0.293\) 5.00
    \(L\) \(3.986\) \(\lambda W=4.00\)

    \(L\) 与 \(\lambda W\) 在模拟内部自动相等——Little 定律的内建校验通过；模拟值与解析值在误差棒内握手——模拟器验证（validation）完成。

    瞬态与 burn-in：模拟从"空系统"出发，累计平均 \(W_q\) 要爬过一段初始瞬态才进入稳态（前 100 人均值 13.25，全体 4.52）。铁律：稳态指标必须删掉前段样本；删除量的判断靠绘图肉眼 + 多 replica 间标准差是否稳定：

    7.5 变异性是敌人#

    利用率 \(\rho=0.8\)、总服务能力相同的三个系统，平均排队等待差出一大截：

    系统 配置 理论 \(W_q\) 模拟
    M/M/1 单台 \(\mu=1\) 4.00 3.969
    M/M/2 两台各 \(\mu=0.5\) 3.56 3.465
    M/G/1 单台，Erlang-3 服务（均值 1） 2.67 2.676

    两个方向的改善都指向同一件事——压波动：M/M/2 比 M/M/1 好，因为两台"互补"削平了到达侧的随机峰（忙时一台空闲另一台顶着）；Erlang-3 服务比指数服务好，因为 \(k\) 阶 Erlang 的方差只有 \(1/k\) 倍（5.5 节卷积的方差可加），服务时长更"整齐"。

    拓展

    M/G/1 的 Pollaczek–Khinchine 公式把"变异性是敌人"写成一行：\(W_q=\dfrac{\lambda\,E[S^2]}{2(1-\rho)}\)——等待只看服务的二阶矩 \(E[S^2]=\text{Var}+\text{mean}^2\)。Erlang-3（均值 1，\(E[S^2]=4/3\)）代入得 \(W_q=0.8\times\frac43/(2\times0.2)=2.67\)，与模拟严丝合缝。多台 M/M/c 的 Erlang C 公式给出"到达需等待的概率"，进而 \(W_q=C/(\text{总服务率}-\lambda)\)；三台的呼叫中心怎么配人力，就是它在管。

    7.6 小结#

    • 解析与模拟的分工：M/M/1 这类"无记忆玩具"给洞察（\(\rho\to1\) 时 \(W_q\propto 1/(1-\rho)\) 爆炸——容量留余量）；真实系统（优先级、顾客放弃、反馈、非平稳到达）解析无门，模拟通吃。
    • 稳态模拟三步：删瞬态 → 长时间跑/多 replica → replica 间标准差当误差棒（2.4 节 CLT 语法）。
    • 两个免费校验：Little 定律自检 + 已知解析解的基准对撞。
    • 下一章换个玩法：模拟不再只当"测量仪"，而是当优化引擎——把目标函数交给随机搜索，模拟退火与遗传算法登场。
