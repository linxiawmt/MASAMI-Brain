    推荐使用路径#

    • 每学期开始：先查 zju-icicles 找教材/历年卷/攻略
    • 想学编程/CS：csdiy.wiki 定路线 → freeCodeCamp 或 OSSU 打底 → hello-algo 练算法
    • 专业课作业：装 CoolProp 替代查表 → 传热/热力题直接算 → 想深入看 CFDPython
    • AI 入门：d2l-zh 与李宏毅苹果书二选一为主教材 → 南瓜书补推导 → nn-zero-to-hero 建直觉
    • 大三大四：SRTP/毕设选方向时看「七、交叉发力点」和「六、科研拓展」
