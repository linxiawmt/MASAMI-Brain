# 自动控制原理

全书 9 章：前 8 章经典控制理论（建模、时域、根轨迹、频域、校正、离散、非线性），第 9 章状态空间分析与综合。本版特色是 MATLAB 与 Python 应用技术并行，笔记里每段代码都给 **MATLAB / Python 双 tab** 对照——MATLAB 按课程标准，Python 用 `python-control` 库实跑验证过。
