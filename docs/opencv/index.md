# OpenCV 轻松入门

李立宗《OpenCV轻松入门：面向Python》全书 **19 章**精读笔记。
每章三件套：网页笔记 + 跟随代码 notebook + **实跑生成**的效果插图（运行结果全部来自本机 `picture*.jpg` 素材的真实运行，非书页截图）。

!!! note "运行环境"
    conda 环境 `machinelearn`（Python 3.10 + OpenCV 4.13），素材在 `数字图像处理-python` 根目录，代码使用相对路径读取。
