# 第 5 章 Logistic回归

> **本章解决**：怎么用一条"最佳拟合直线"做二分类——把每个特征乘上回归系数求和，代入 Sigmoid 函数压到 0~1 之间，大于 0.5 判 1 类、小于 0.5 判 0 类；而找最佳回归系数这件事，交给最优化算法（梯度上升、随机梯度上升）来解决。

这会是激动人心的一章，因为我们将首次接触到**最优化算法（optimization algorithm）**。日常生活中其实到处是最优化问题：如何在最短时间内从 A 点到达 B 点？如何投入最少工作量却获得最大效益？如何设计发动机使得油耗最少而功率最大？本章介绍几个最优化算法，并利用它们训练出一个**非线性函数**用于分类。

不熟悉回归也没关系（第 8 章起会深入介绍）。假设现在有一些数据点，用一条直线对这些点进行拟合（该线称为**最佳拟合直线**），这个拟合过程就称作**回归（regression）**。利用 Logistic 回归进行分类的主要思想：**根据现有数据对分类边界线建立回归公式，以此进行分类**。这里的"回归"一词源于最佳拟合，表示要找到最佳拟合参数集。训练分类器时的做法就是寻找最佳拟合参数，使用的是最优化算法。

## 5.1 基于Logistic回归和Sigmoid函数的分类

!!! note "原书优缺点表"
    | Logistic 回归 | |
    | --- | --- |
    | **优点** | 计算代价不高，易于理解和实现 |
    | **缺点** | 容易欠拟合，分类精度可能不高 |
    | **适用数据类型** | 数值型和标称型数据 |

我们想要的函数应该是：能接受所有的输入然后预测出类别。例如两个类的情况下，函数输出 0 或 1。具有这种性质的函数你或许见过，它叫**海维塞德阶跃函数（Heaviside step function）**，或者直接称**单位阶跃函数（unit step function）**。然而阶跃函数的问题在于：它在跳跃点上从 0 **瞬间**跳跃到 1，这个瞬间跳跃过程有时很难处理。

幸好，另一个函数也具有类似的性质（能输出 0 或 1），且数学上更易处理——这就是 **Sigmoid 函数**，具体的计算公式如下：

\[
\sigma(z) = \frac{1}{1 + e^{-z}}
\]

从图上看：当 \(z = 0\) 时，Sigmoid 函数值为 **0.5**；随着 \(z\) 增大，对应的 Sigmoid 值将逼近于 **1**；随着 \(z\) 减小，Sigmoid 值将逼近于 **0**。如果横坐标刻度足够大（图 5-1 下图），Sigmoid 函数看起来就很像一个阶跃函数。

!!! note "拓展：Sigmoid 的来历与好性质"
    Sigmoid 函数是 **Logistic 分布的累积分布函数**，名字来自形状像字母 S（sigmoid 意为"S 形的"）。它在数学上处处连续、处处可微，这正是阶跃函数做不到的。它有一个非常好用的一阶导数：

    \[
    \sigma'(z) = \sigma(z)\left(1 - \sigma(z)\right)
    \]

    即导数可以用函数值本身表达，后面推导梯度时全靠这一条（见 5.2.2 的拓展推导）。另外注意原书译者注：数学中，若实数域上的某函数可以用半开区间上**指示函数（indicator function）**的有限次线性组合表示，它就是阶跃函数——Sigmoid 只是"长得像"，并不属于阶跃函数一族。

确定了分类器的函数形式，实现 Logistic 回归分类器的做法是：**在每个特征上都乘一个回归系数，把所有结果值相加，将总和代入 Sigmoid 函数**，进而得到一个范围在 0~1 之间的数值。任何**大于 0.5** 的数据被分入 1 类，**小于 0.5** 即归入 0 类。所以 Logistic 回归也可以被看成一种**概率估计**。

!!! note "拓展：明明是分类，为什么叫'回归'"
    本书将 weight 译作"**回归系数**"，是为了与第 8 章局部加权线性回归中的"权重"一词区分，不会引起混淆时也简称"系数"。这个方法更学术的名字叫**对数几率回归（logit regression）**：它先按线性回归的方式算出 \(z = w^{T}x\)，再用 Sigmoid 把 \(z\) 映射成"属于类别 1 的概率"——本质上是对"是/否"这类二值结果做回归，最后再按 0.5 的门槛切成两类。"输出的是概率"这个视角很重要：它让 Logistic 回归能给出置信程度，也是从分类走向"预测数值"（第 8 章）的天然过渡。

现在的问题变成了：**最佳回归系数是多少？如何确定它们的大小？**下一节解答。

## 5.2 基于最优化方法的最佳回归系数确定

Sigmoid 函数的输入记为 \(z\)，由下面公式得出：

\[
z = w_0 x_0 + w_1 x_1 + w_2 x_2 + \dots + w_n x_n
\]

如果采用向量的写法，上述公式可以写成 \(z = w^{T}x\)——将两个数值向量对应元素相乘然后全部加起来即得到 \(z\) 值。向量 \(x\) 是分类器的输入数据，向量 \(w\) 就是我们要找的**最佳参数（系数）**，它使得分类器尽可能精确。为了寻找该最佳参数，需要用到最优化理论的一些知识。

本节路线：先介绍**梯度上升法**并求得数据集的最佳参数 → 展示如何绘制**决策边界图**把分类效果可视化 → 最后学习**随机梯度上升算法**以及如何改进它。

### 5.2.1 梯度上升法

第一个最优化算法叫**梯度上升法（gradient ascent）**。它基于的思想：**要找到某函数的最大值，最好的方法是沿着该函数的梯度方向探寻**。如果梯度记为 ∇，则函数 \(f(x, y)\) 的梯度由下式表示：

\[
\nabla f(x, y) =
\begin{pmatrix}
\dfrac{\partial f(x, y)}{\partial x} \\[2mm]
\dfrac{\partial f(x, y)}{\partial y}
\end{pmatrix}
\]

这是机器学习中最容易造成混淆的地方之一，但数学上并不难，需要做的只是牢记符号的意义：这个梯度意味着要**沿 x 的方向移动 \(\dfrac{\partial f(x,y)}{\partial x}\)，沿 y 的方向移动 \(\dfrac{\partial f(x,y)}{\partial y}\)**。其中函数 \(f(x, y)\) 必须要在待计算的点上**有定义并且可微**。

<figure>
  <img src="../images/ch05/fig-5-2.png" class="lq-img" />
  <figcaption>图 5-2 梯度上升算法到达每个点后都会重新估计移动方向：从 P0 开始，计算该点的梯度，移动到 P1；在 P1 再次计算梯度，沿新方向移动到 P2……如此循环迭代，直到满足停止条件（截自原书）</figcaption>
</figure>

梯度算子总是指向**函数值增长最快的方向**——这里说的是移动**方向**，没提移动**量的大小**。该量值称为**步长（step size）**，记作 \(\alpha\)。用向量表示的话，梯度上升算法的迭代公式如下：

\[
w := w + \alpha \nabla_w f(w)
\]

该公式将一直被迭代执行，直至达到某个**停止条件**为止，比如迭代次数达到某个指定值，或算法达到某个允许的误差范围。

!!! note "拓展：为什么沿梯度方向'上升最快'"
    用一阶泰勒展开看：在当前点 \(w\) 附近，\(f(w + \Delta w) \approx f(w) + \nabla f(w)^{T}\Delta w\)。固定步长 \(\lVert \Delta w \rVert\) 时，要让增量 \(\nabla f^{T}\Delta w\) 最大，\(\Delta w\) 必须与梯度同方向（夹角 0°，余弦最大）。所以"沿梯度走"不是经验法则，是数学结论。同理，若步长 \(\alpha\) 取得过大，一阶近似失效，点会在谷两侧来回弹甚至发散——这就是"步长要当超参数调"的原因。

!!! note "侧栏：梯度下降算法"
    你最经常听到的应该是**梯度下降（gradient descent）**，它与梯度上升一模一样，只是公式中的加法变成减法：

    \[
    w := w - \alpha \nabla_w f(w)
    \]

    **梯度上升用来求函数的最大值，梯度下降用来求函数的最小值。**同一个算法换个符号，把"爬山"变成"下山"。

### 5.2.2 训练算法：使用梯度上升找到最佳参数

<figure>
  <img src="../images/ch05/fig-5-3.png" class="lq-img" />
  <figcaption>图 5-3 一个简单数据集：100 个样本点，每个点两个数值型特征 X1 和 X2（截自原书）</figcaption>
</figure>

在此数据集上，我们将用梯度上升法找到最佳回归系数——也就是拟合出 Logistic 回归模型的最佳参数。梯度上升法的伪代码如下：

```text
每个回归系数初始化为 1
重复 R 次：
    计算整个数据集的梯度
    使用 alpha × gradient 更新回归系数的向量
返回回归系数
```

下面的代码是梯度上升算法的具体实现。打开文本编辑器，创建一个名为 logRegres.py 的文件，输入下列代码（原书 Python 2 已改写为 Python 3 可直接运行）：

```python
# ===== 书 5.2.2 节 程序清单5-1：Logistic回归梯度上升优化算法 =====
from numpy import *

def loadDataSet():
    dataMat = []; labelMat = []                    # 特征矩阵、类别标签列表
    fr = open('testSet.txt')                       # 逐行读取文本文件
    for line in fr.readlines():
        lineArr = line.strip().split()             # 每行前两个值是 X1、X2，第三个是类别标签
        dataMat.append([1.0, float(lineArr[0]), float(lineArr[1])])  # X0 恒置 1.0
        labelMat.append(int(lineArr[2]))
    return dataMat, labelMat

def sigmoid(inX):
    return 1.0 / (1 + exp(-inX))                   # Sigmoid：接受任意实数，输出 0~1

def gradAscent(dataMatIn, classLabels):
    dataMatrix = asmatrix(dataMatIn)               # 转换为 NumPy 矩阵（原书用 mat()，见下框勘误）
    labelMat = asmatrix(classLabels).transpose()   # 1×100 行向量转置成 100×1 列向量
    m, n = shape(dataMatrix)                       # m=100 个样本，n=3 个特征（含 X0）
    alpha = 0.001                                  # 向目标移动的步长
    maxCycles = 500                                # 迭代次数
    weights = ones((n, 1))                         # 每个回归系数初始化为 1（3×1 列向量）
    for k in range(maxCycles):                     # 重复 R 次（这里 R = 500）
        h = sigmoid(dataMatrix * weights)          # 矩阵相乘：100×3 · 3×1 = 100×1 列向量
        error = (labelMat - h)                     # 真实类别与预测类别的差值（100×1）
        weights = weights + alpha * dataMatrix.transpose() * error  # 按梯度更新回归系数
    return weights
```

!!! warning "环境适配：numpy 2.x 已移除 mat()"
    原书代码写作 `mat(dataMatIn)`（`from numpy import *` 下的 NumPy 矩阵转换函数）。**NumPy 2.0 起该函数别名已被移除**，笔记改用等价的 `asmatrix()`。注意 `matrix` 矩阵类型本身目前仍可用，但官方早已不推荐——新代码更建议全程用 ndarray（本书第 9 章起的代码就是这样做的）。

代码开头提供了便利函数 `loadDataSet()`，功能是打开文本文件 testSet.txt 并逐行读取：每行前两个值分别是 X1 和 X2，第三个值是数据对应的类别标签；为方便计算，函数还把 X0 的值设为 1.0。接下来的函数就是 5.2 节提到的 `sigmoid()`。

梯度上升的实际工作在 `gradAscent()` 里完成，它有两个参数：

- **dataMatIn**：一个 2 维 NumPy 数组，**每列代表一个不同的特征，每行代表一个训练样本**。现在用的 100 个样本的简单数据集，包含两个特征 X1、X2，再加上第 0 维特征 X0，所以 dataMatIn 里存放的是 **100×3 的矩阵**；
- **classLabels**：类别标签，是一个 1×100 的行向量。为便于矩阵运算，需要将该行向量**转置**成列向量再赋给 labelMat。

这是本书首次使用 NumPy 矩阵——如果你对矩阵数学不太熟悉，一些运算会不易理解。NumPy 对 2 维数组和矩阵都提供操作支持，**如果混淆了数据类型和对应的操作，执行结果将与预期截然不同**（本书附录 A 给出了 NumPy 矩阵的介绍）。变量 alpha 是向目标移动的步长，maxCycles 是迭代次数。for 循环迭代完成后，返回训练好的回归系数。

需要强调的是 `h = sigmoid(dataMatrix * weights)` 是**矩阵运算**：变量 h 不是一个数，而是一个**列向量**，元素个数等于样本个数（这里是 100）。对应地，运算 `dataMatrix * weights` 代表的不止一次乘积——事实上该运算包含了 **300 次乘积**（100 个样本 × 3 个特征）。

至于 `error = (labelMat - h)` 与更新式为什么长那样，原书略去了推导、留给有兴趣的读者。定性地说：这是在计算**真实类别与预测类别的差值**，接下来按该差值的方向调整回归系数。

!!! note "拓展：把书中'留给读者'的推导补上——更新公式就是对数似然的梯度"
    把 \(h_i = \sigma(w^{T}x_i)\) 看成样本 \(x_i\) 属于类别 1 的概率，一次看到全部样本的对数似然为：

    \[
    L(w) = \sum_{i} \left[ y_i \ln h_i + (1 - y_i)\ln(1 - h_i) \right]
    \]

    对 \(w\) 求导（利用 \(\sigma' = \sigma(1-\sigma)\) 化简），可以推出：

    \[
    \frac{\partial L}{\partial w} = X^{T}(y - h)
    \]

    右边恰好就是代码里的 `dataMatrix.transpose() * error`（\(y\) 对应 labelMat，\(h\) 是预测值）。所以这五行循环代码并不是"拍脑袋的启发式"——**梯度上升法在最大化对数似然**，更新公式严格就是它的梯度乘步长。这也解释了为什么误差项只取 \(y - h\) 这么简单。

实际效果如何？在 Python 提示符下敲入下面的代码（实跑输出与原书**逐位一致**——梯度上升是确定性算法）：


### 5.2.3 分析数据：画出决策边界

上面已经解出了一组回归系数，它确定了不同类别数据之间的分隔线。怎样画出该分隔线，让优化过程便于理解？打开 logRegres.py 并添加如下代码：

```python
# ===== 书 5.2.3 节 程序清单5-2：画出数据集和 Logistic回归最佳拟合直线 =====
import matplotlib.pyplot as plt

def plotBestFit(weights):
    dataMat, labelMat = loadDataSet()              # 重新取一遍数据用于画散点
    dataArr = array(dataMat)                       # 转成数组，便于按行列取值
    n = shape(dataArr)[0]                          # 样本个数
    xcord1 = []; ycord1 = []                       # 类别 1 的 X1、X2 坐标
    xcord2 = []; ycord2 = []                       # 类别 0 的 X1、X2 坐标
    for i in range(n):
        if int(labelMat[i]) == 1:
            xcord1.append(dataArr[i, 1]); ycord1.append(dataArr[i, 2])
        else:
            xcord2.append(dataArr[i, 1]); ycord2.append(dataArr[i, 2])
    fig = plt.figure()
    ax = fig.add_subplot(111)
    ax.scatter(xcord1, ycord1, s=30, c='red', marker='s')    # 类别 1：红色方块
    ax.scatter(xcord2, ycord2, s=30, c='green')              # 类别 0：绿色圆点
    x = arange(-3.0, 3.0, 0.1)
    y = (-weights[0] - weights[1] * x) / weights[2]          # 令 Sigmoid 输入为 0 解出的直线
    ax.plot(x, y)                                            # 最佳拟合直线
    plt.xlabel('X1'); plt.ylabel('X2')
    plt.show()
```

程序清单 5-2 的代码直接用 Matplotlib 画出来。唯一要指出的是 `y = (-weights[0] - weights[1] * x) / weights[2]` 这一行：它**设置了 Sigmoid 函数的输入为 0**。回忆 5.2 节——0 是两个类别（类别 1 和类别 0）的分界处。因此我们设定：

\[
0 = w_0 x_0 + w_1 x_1 + w_2 x_2
\]

然后解出 X2 和 X1 的关系式（即分隔线的方程，注意 X0 = 1）：\(x_2 = \dfrac{-w_0 - w_1 x_1}{w_2}\)。

### 5.2.4 训练算法：随机梯度上升

梯度上升算法在**每次更新回归系数时都需要遍历整个数据集**——处理 100 个左右的数据集时尚可，如果有数十亿样本和成千上万的特征，计算复杂度就太高了。一种改进方法：**一次仅用一个样本点来更新回归系数**，该方法称为**随机梯度上升算法（stochastic gradient ascent）**。由于可以在新样本到来时对分类器进行**增量式（incremental）更新**，随机梯度上升是一个**在线学习（online learning）算法**。与"在线学习"相对应，一次处理所有数据被称作"**批处理（batch processing）**"。

!!! note "拓展：随机梯度 vs 批梯度，以及 mini-batch"
    本书这一对算法就是深度学习时代 **SGD（随机梯度下降）与全量批梯度**的原型：批梯度方向准但贵，随机梯度便宜但方向抖。现代实践常用的折中是 **mini-batch**——每次用一小撮（如 32、256 个）样本算梯度，兼得稳定与效率；这个思想在神经网络部分会反复出现。

随机梯度上升算法可以写成如下的伪代码：

```text
所有回归系数初始化为 1
对数据集中每个样本
    计算该样本的梯度
    使用 alpha × gradient 更新回归系数值
返回回归系数值
```

以下是随机梯度上升算法的实现代码：

```python
# ===== 书 5.2.4 节 程序清单5-3：随机梯度上升 =====
def stocGradAscent0(dataMatrix, classLabels):
    m, n = shape(dataMatrix)
    alpha = 0.01                                   # 固定步长（比梯度上升的 0.001 大一个量级）
    weights = ones(n)                              # 一维数组：全程没有矩阵转换过程
    for i in range(m):                             # 每次只用第 i 个样本更新系数
        h = sigmoid(sum(dataMatrix[i] * weights))  # h 是数值，不是列向量
        error = classLabels[i] - h                 # error 也是数值
        weights = weights + alpha * error * dataMatrix[i]
    return weights
```

可以看到，随机梯度上升与梯度上升在代码上很相似，但有两个区别：

1. 后者的变量 h 和误差 error 都是**向量**，前者则**全是数值**；
2. 前者没有矩阵的转换过程，所有变量的数据类型都是 NumPy **数组**。

在 Python 提示符下验证该方法（单轮遍历是**确定性**的，任何人跑都得到同一组数）：

```python

>>> weights = stocGradAscent0(array(dataArr), labelMat)
>>> weights
array([ 1.01702007,  0.85914348, -0.36579921])

```

图 5-6 展示了 200 次遍历中回归系数的变化情况。其中的**系数 2**（即 X2 对应的 w2）只经过了 50 次迭代就达到了稳定值，但**系数 1 和 0** 则需要更多次的迭代。另外值得注意的是：在大波动停止后还有一些**小的周期性波动**。不难理解其原因——数据集中存在一些**不能正确分类的样本点**（数据集并非线性可分），每次迭代时会引发系数的剧烈改变。我们期望算法能避免来回波动，从而收敛到某个值；另外，收敛速度也需要加快。

对于图 5-6 存在的问题，可以通过修改程序清单 5-3 的随机梯度上升算法来解决：

```python
# ===== 书 5.2.4 节 程序清单5-4：改进的随机梯度上升 =====
def stocGradAscent1(dataMatrix, classLabels, numIter=150):
    m, n = shape(dataMatrix)
    weights = ones(n)
    for j in range(numIter):                       # 迭代次数默认 150，可由第 3 个参数修改
        dataIndex = list(range(m))                 # Python 3 改写：range 需转 list 才能 del 元素
        for i in range(m):
            alpha = 4 / (1.0 + j + i) + 0.0001     # 改进①：alpha 随迭代减小，但常数项保底不为 0
            randIndex = int(random.uniform(0, len(dataIndex)))  # 改进②：随机选取样本来更新
            h = sigmoid(sum(dataMatrix[randIndex] * weights))
            error = classLabels[randIndex] - h
            weights = weights + alpha * error * dataMatrix[randIndex]
            del(dataIndex[randIndex])              # 用过即删，本轮不再重复抽取
    return weights
```

程序清单 5-4 与程序清单 5-3 类似，但增加了两处改进。

**第一处改进：alpha 每次迭代时需要调整**。一方面，alpha 在每次迭代都会调整，这会缓解图 5-6 上的数据波动或高频波动；另一方面，虽然 alpha 随迭代次数不断减小，但**永远不会减小到 0**——因为式中还存在常数项 0.0001。必须这样做的原因：保证多次迭代之后新数据仍然具有一定的影响。如果要处理的问题是**动态变化**的，可以适当加大这个常数项，确保新值获得更大的回归系数。另一点值得注意：在降低 alpha 的函数中，alpha 每次减少 \(1/(j+i)\)，其中 j 是迭代次数、i 是样本点的下标。这样**当 j ≪ max(i) 时，alpha 就不是严格下降的**——避免参数严格下降也常见于模拟退火等其他优化算法中。

!!! note "原书译者注：区分两种'下标'"
    要注意区分这里的下标与样本编号：编号表示样本在矩阵中的位置（代码中为 randIndex），而下标 i 表示**本次迭代中第 i 个被选出来的样本**。同一个样本可能被选中多次，也有些样本一次都选不中——这正是"随机"的含义。

!!! note "拓展：这种步长有名字"
    \(\alpha = 4/(1+j+i) + 0.0001\) 属于**随迭代衰减的学习率**。随机逼近理论（Robbins–Monro 条件）要求：要让随机迭代收敛，学习率需满足 \(\sum_t \alpha_t = \infty\)（衰减够慢，能跑遍整个空间）且 \(\sum_t \alpha_t^2 < \infty\)（衰减够快，能压住随机噪声）。\(1/t\) 型衰减恰好两条都满足；常数项 0.0001 严格来说会破坏第二条，但换来的是"永远对新数据保留响应"，工程上利大于弊。

**第二处改进：随机选取样本来更新回归系数**。这将减少周期性的波动（如图 5-6 中的波动）。具体实现方法与第 3 章类似：每次随机从列表中选出一个值，然后从列表中删掉该值（再进行下一次迭代）。此外，改进算法还增加了**迭代次数作为第 3 个参数**：如果该参数没有给定，算法将默认迭代 150 次；如果给定，则按新参数值迭代。

### 5.3.1 准备数据：处理数据中的缺失值

数据中的缺失值是个非常棘手的问题，有很多文献都致力于解决它。数据缺失究竟带来了什么问题？假设有 100 个样本和 20 个特征，这些数据都是机器收集回来的。若机器上的某个传感器损坏导致一个特征无效时该怎么办？此时是否要扔掉整个数据？另外 19 个特征怎么办？它们是否还可用？答案是肯定的——**有时候数据相当昂贵，扔掉和重新获取都不可取**，所以必须采用一些方法来解决这个问题。

可选的做法有：

- 使用可用特征的**均值**来填补缺失值；
- 使用**特殊值**来填补缺失值，如 -1；
- **忽略**有缺失值的样本；
- 使用**相似样本的均值**添补缺失值；
- 使用另外的机器学习算法**预测**缺失值。

现在对要用的数据集进行预处理，使其可以顺利地使用分类算法。预处理阶段需要做两件事：

**第一，所有的缺失值必须用一个实数值来替换**——因为我们使用的 NumPy 数据类型不允许包含缺失值。这里选择**实数 0** 来替换所有缺失值，恰好能适用于 Logistic 回归。这样做的直觉在于：我们需要的是一个**在更新时不会影响系数的值**。回归系数的更新公式如下：

\[
w := w + \alpha \, X^{T}(y - h)
\]

如果 dataMatrix 的某特征对应值为 0，那么按分量看，该特征的系数将不做更新——因为更新量里的这一项 \(\alpha \cdot error \cdot x_j\) 中 \(x_j = 0\)，乘积直接归零。另外，由于 \(\sigma(0) = 0.5\)，即它对结果的预测**不具有任何倾向性**，因此上述做法也不会对误差项造成任何影响。基于上述原因，将缺失值用 0 代替**既可以保留现有数据，也不需要对优化算法进行修改**。此外，该数据集中的特征取值一般不为 0，因此在某种意义上说它也满足"特殊值"这个要求。

**第二，如果在测试数据集中发现一条数据的类别标签已经缺失，那么简单的做法是将该条数据丢弃**。这是因为类别标签与特征不同，很难确定采用某个合适的值来替换。采用 Logistic 回归进行分类时这种做法是合理的，而如果采用类似 kNN 的方法就可能不太可行。

!!! note "拓展：填 0 只对'乘系数再求和'的模型免费"
    "缺失值填 0 不影响模型"并不是普适结论——它对 Logistic 回归这类**线性加权模型**成立（0 乘任何系数都归零、且 \(\sigma(0)=0.5\) 无倾向）。换成 kNN 就不行了：kNN 依赖**距离计算**，把缺失填成 0 会人为把该维的距离拉近，等于偷偷改了几何关系。选择哪种填补方式必须结合下游算法的数学性质，这正是原书说"没有标准答案，取决于实际应用"的含义。

原始数据集经过预处理之后保存成两个文件：horseColicTest.txt 和 horseColicTraining.txt。如果想对原始数据和预处理后的数据做个比较，可以在 http://archive.ics.uci.edu/ml/datasets/Horse+Colic 浏览这些数据。实跑核对：预处理后的两个文件分别有 **299 行（训练）和 67 行（测试）**，每行 22 个制表符分隔的字段（21 个特征 + 1 个类别标签）。

现在我们有了一个"干净"可用的数据集和一个不错的优化算法，下面把这些部分融合在一起训练出一个分类器，来预测病马的生死问题。

### 5.3.2 测试算法：用 Logistic回归进行分类

本章前面几节介绍了优化算法，但还没有在分类上做任何实际尝试。使用 Logistic 回归进行分类并不需要做很多工作：**把测试集上每个特征向量乘以最优化方法得来的回归系数，将该乘积结果求和，最后输入到 Sigmoid 函数中**。如果对应的 Sigmoid 值大于 0.5 就预测类别标签为 1，否则为 0。

下面看看实际运行效果，打开文本编辑器并将下列代码添加到 logRegres.py 文件中：

```python
# ===== 书 5.3.2 节 程序清单5-5：Logistic回归分类函数 =====
def classifyVector(inX, weights):
    prob = sigmoid(sum(inX * weights))             # 特征向量 × 系数求和，代入 Sigmoid
    if prob > 0.5: return 1.0                      # 大于 0.5 判 1（存活），否则判 0
    else: return 0.0

def colicTest():
    frTrain = open('horseColicTraining.txt')       # 训练集与测试集分别打开
    frTest = open('horseColicTest.txt')
    trainingSet = []; trainingLabels = []
    for line in frTrain.readlines():
        currLine = line.strip().split('\t')        # 该数据集以制表符分隔
        lineArr = []
        for i in range(21):                        # 前 21 列是特征
            lineArr.append(float(currLine[i]))
        trainingSet.append(lineArr)
        trainingLabels.append(float(currLine[21])) # 第 22 列是类别标签
    trainWeights = stocGradAscent1(array(trainingSet), trainingLabels, 500)  # 500 次迭代训练
    errorCount = 0; numTestVec = 0.0
    for line in frTest.readlines():
        numTestVec += 1.0
        currLine = line.strip().split('\t')
        lineArr = []
        for i in range(21):
            lineArr.append(float(currLine[i]))
        if int(classifyVector(array(lineArr), trainWeights)) != int(currLine[21]):
            errorCount += 1                        # 预测类别与真实类别不一致即记一次错
    errorRate = (float(errorCount) / numTestVec)
    print("the error rate of this test is: %f" % errorRate)
    return errorRate

def multiTest():
    numTests = 10; errorSum = 0.0
    for k in range(numTests):                      # 调用 colicTest() 10 次并求平均
        errorSum += colicTest()
    print("after %d iterations the average error rate is: %f"
          % (numTests, errorSum / float(numTests)))
```

!!! note "运行环境"
    本节代码要从数据文件读数据，文件名一律写相对路径（如 `'horseColicTraining.txt'`）。**运行时工作目录需在数据文件所在目录**（本站配套数据位于 `_ml_data\Ch05\`，内含 testSet.txt、horseColicTraining.txt、horseColicTest.txt）。拿不准时先 `import os; print(os.getcwd())` 检查。

程序清单 5-5 的第一个函数是 `classifyVector()`，它以回归系数和特征向量作为输入来计算对应的 Sigmoid 值：如果 Sigmoid 值大于 0.5 函数返回 1，否则返回 0。

接下来的函数是 `colicTest()`，用于打开测试集和训练集并对数据做格式化处理。该函数首先导入训练集——同前面一样，数据的最后一列仍然是类别标签。数据最初有**三个类别标签**，分别代表马的三种情况："仍存活"、"已经死亡"和"已经安乐死"。为方便起见，这里将"已经死亡"和"已经安乐死"合并成"**未能存活**"这个标签。数据导入之后，便可以使用 `stocGradAscent1()` 来计算回归系数向量。这里可以自由设定迭代次数——例如在训练集上使用 **500 次迭代**，实验结果表明这比默认迭代 150 次的效果更好。系数计算完成之后，导入测试集并计算分类错误率。

整体看来，`colicTest()` 具有完全独立的功能，**多次运行得到的结果可能稍有不同**，这是因为其中有随机的成分（`stocGradAscent1()` 的随机选样）。如果在 `stocGradAscent1()` 函数中回归系数已经完全收敛，那么结果才将是确定的。最后一个函数是 `multiTest()`，其功能是调用 `colicTest()` 10 次并求结果的平均值。

## 5.4 本章小结

Logistic 回归的目的是寻找一个非线性函数 **Sigmoid 的最佳拟合参数**，求解过程可以由最优化算法来完成。在最优化算法中，最常用的就是**梯度上升算法**，而梯度上升算法又可以简化为**随机梯度上升算法**。

- 随机梯度上升算法与梯度上升算法的效果相当，但**占用更少的计算资源**；
- 随机梯度上升是一个**在线算法**：可以在新数据到来时就完成参数更新，而不需要重新读取整个数据集来进行批处理运算；
- 机器学习的一个重要问题是如何**处理缺失数据**——这个问题没有标准答案，取决于实际应用中的需求，现有一些解决方案各有优缺点。

下一章将介绍与 Logistic 回归类似的另一种分类算法：**支持向量机**，它被认为是目前最好的现成算法之一。

## 坑与陷阱

!!! danger "8 个容易踩的坑"
    1. **`mat()` 在 NumPy 2.x 已被移除**：原书的 `mat(dataMatIn)` 直接照抄会报 `AttributeError: np.mat was removed in the NumPy 2.0 release`。改用 `asmatrix()`；更彻底的做法是全程 ndarray（matrix 类型本身也在弃用路上）。
    2. **sigmoid 大数值上溢**：`exp(-inX)` 在 inX 为大负数时可能触发 `RuntimeWarning: overflow encountered in exp`。此时结果会饱和到 0 或 1，分类一般不受影响，但要知道警告从哪来。数值稳定写法：`if inX >= 0: return 1/(1+exp(-inX))`，否则 `return exp(inX)/(1+exp(inX))`——两个分支里指数恒为负数，永不溢出。
    3. **Python 3 里 `del(dataIndex[randIndex])` 会报错**：`range(m)` 返回的是不可变序列，不支持删除。程序清单 5-4 必须写成 `dataIndex = list(range(m))`——这是原书 Python 2 代码最隐蔽的一处改写点。
    4. **`reload` 不是 Python 3 内置**：原书反复用 `reload(logRegres)` 刷新模块，Python 3 需 `from importlib import reload`；脚本式开发直接重跑即可。
    5. **两种数据的分隔符不同**：testSet.txt 是空格分隔（`split()` 即可），病马数据是**制表符分隔**（必须 `split('\t')`）。分隔符用错，`float()` 当场抛 ValueError。
    6. **相对路径按当前工作目录解析**：代码里只写了文件名，工作目录不在数据所在处就 FileNotFoundError。先 `os.getcwd()` 确认（见 5.3.2 的"运行环境"注）。
    7. **随机算法的结果每次都不同**：`stocGradAscent1()` 和 `colicTest()` 含随机选样，单次错误率在 0.28~0.42 间波动是正常现象。报告性能用 `multiTest()` 的 10 次平均；想复现实验可固定随机种子（如 `numpy.random.seed(2)`）。
    8. **matrix 与 ndarray 的运算语义不同**：`*` 在 matrix 上是矩阵乘法、在 ndarray 上是逐元素乘；h 是 100×1 的列向量而不是数。混淆两者"执行结果将与预期截然不同"（原书原话），用错时先 `type()` 检查手里的变量到底是哪种。

## 速览

1. Logistic 回归：特征乘回归系数求和得 \(z = w^{T}x\)，代入 Sigmoid \(\sigma(z) = 1/(1+e^{-z})\) 压到 0~1，大于 0.5 判 1 类、小于判 0 类；也可看成概率估计。优点：计算代价不高、易理解易实现；缺点：易欠拟合、精度可能不高；适用数值型和标称型数据。
2. 海维塞德阶跃函数能输出 0/1 但瞬间跳跃难处理；Sigmoid 性质类似且数学上更易处理：\(z=0\) 时值 0.5，\(z \to \pm\infty\) 分别趋于 1、0，横轴刻度足够大时形似阶跃函数。
3. 梯度上升：沿梯度方向迭代找最大值，\(w := w + \alpha\nabla_w f(w)\)；梯度下降把加号变减号、求最小值；步长 \(\alpha\) 是移动量，停止条件为迭代次数或误差范围。
4. gradAscent：步长 0.001、迭代 500 次、全数据集矩阵运算（每次迭代含 300 次乘法）；testSet 上实跑系数 `[4.12414349, 0.48007329, -0.6168482]`，与书逐位一致，训练集错分 4/100。
5. 决策边界：令 Sigmoid 输入为 0，即 \(0 = w_0x_0 + w_1x_1 + w_2x_2\)，解出 \(x_2 = (-w_0 - w_1x_1)/w_2\) 画直线；传参用 `weights.getA()` 把 matrix 转 ndarray。
6. 随机梯度上升：一次仅用一个样本更新系数，是**在线学习**算法（对应批处理）；单轮遍历系数 `[1.01702007, 0.85914348, -0.36579921]`（确定性），错分约 1/3，拟合欠佳。
7. 改进两点：alpha 动态衰减 `4/(1.0+j+i)+0.0001`（永不为 0、j ≪ max(i) 时非严格下降）+ 随机选样更新（消除周期波动）；默认迭代 150 次，收敛比固定 alpha 快得多。
8. 病马实例：368 样本、28 特征、30% 缺失；缺失特征填 0（不更新系数、\(\sigma(0)=0.5\) 无倾向、保留数据不改算法），测试集标签缺失的样本丢弃；预处理后训练 299 行 / 测试 67 行。
9. 分类的落地就一步：`classifyVector` 把特征向量乘系数求和代入 Sigmoid，大于 0.5 判 1；训练用 `stocGradAscent1(…, 500)`（500 次优于默认 150 次）。
10. multiTest() 跑 10 次取平均：实跑平均错误率 0.349254 ≈ 35%（书 35%；30% 数据缺失下并不差），调迭代次数与步长可降到 20% 左右；该数据集第 7 章再用。
