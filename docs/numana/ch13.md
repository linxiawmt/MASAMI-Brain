## 13.1 一阶方程组与 Runge–Kutta 四阶方法

### 13.1.1 问题形式

$m$ 个一阶方程耦合的初值问题：

\[
\frac{du_1}{dt}=f_1(t,u_1,\dots,u_m),\quad \dots,\quad \frac{du_m}{dt}=f_m(t,u_1,\dots,u_m),\qquad a\le t\le b
\]

初值 $u_1(a)=\alpha_1,\ \dots,\ u_m(a)=\alpha_m$。

写成向量形式最省事：记 $\mathbf u=(u_1,\dots,u_m)^{\mathsf T}$、$\mathbf f=(f_1,\dots,f_m)^{\mathsf T}$、$\boldsymbol\alpha=(\alpha_1,\dots,\alpha_m)^{\mathsf T}$，则

\[
\boxed{\ \frac{d\mathbf u}{dt}=\mathbf f(t,\mathbf u),\qquad \mathbf u(a)=\boldsymbol\alpha\ }
\]

### 13.1.2 经典 RK4 的向量形式

\[
\begin{aligned}
\mathbf w_0&=\boldsymbol\alpha\\
\mathbf k_1&=h\,\mathbf f(t_j,\mathbf w_j)\\
\mathbf k_2&=h\,\mathbf f\!\left(t_j+\tfrac h2,\ \mathbf w_j+\tfrac12\mathbf k_1\right)\\
\mathbf k_3&=h\,\mathbf f\!\left(t_j+\tfrac h2,\ \mathbf w_j+\tfrac12\mathbf k_2\right)\\
\mathbf k_4&=h\,\mathbf f\!\left(t_j+h,\ \mathbf w_j+\mathbf k_3\right)\\
\mathbf w_{j+1}&=\mathbf w_j+\tfrac16\left(\mathbf k_1+2\mathbf k_2+2\mathbf k_3+\mathbf k_4\right)
\end{aligned}
\]

标量形式的每个方程独立执行同一套公式，只是第 $i$ 个分量用 $f_i$ 且其余分量同时参与：

\[
k_{1,i}=hf_i(t_j,w_{1,j},\dots,w_{m,j}),\quad
k_{2,i}=hf_i\!\left(t_j+\tfrac h2,\ w_{1,j}+\tfrac12 k_{1,1},\ \dots,\ w_{m,j}+\tfrac12 k_{1,m}\right),\ \dots
\]

```matlab
function [t, W] = rk4sys(f, a, b, alpha, N)
% RK4 求解一阶方程组 u' = f(t,u)，u(a)=alpha
h = (b - a) / N;  t = (a:h:b).';  W = zeros(N+1, numel(alpha));
W(1,:) = alpha(:).';
for j = 1:N
    k1 = h * f(t(j),        W(j,:)).';
    k2 = h * f(t(j)+h/2,    W(j,:) + 0.5*k1.').';
    k3 = h * f(t(j)+h/2,    W(j,:) + 0.5*k2.').';
    k4 = h * f(t(j)+h,      W(j,:) + k3.').';
    W(j+1,:) = W(j,:) + (k1 + 2*k2 + 2*k3 + k4).'/6;
end
end
```

### 13.1.3 定理：RK4 具有四阶精度

**定理.** 若 $\mathbf f$ 关于 $\mathbf u$ 满足 Lipschitz 条件且足够光滑，则经典 RK4 的**局部截断误差**为 $O(h^5)$，即整体（全局）误差为 $O(h^4)$。

**证明（阶条件法）.** 设 $s$ 级 Runge–Kutta 方法

\[
\mathbf k_i=\mathbf f\!\Big(t+c_ih,\ \mathbf w+h\sum_{j=1}^{s}a_{ij}\mathbf k_j\Big),\qquad
\mathbf w_{n+1}=\mathbf w_n+h\sum_{i=1}^{s}b_i\mathbf k_i .
\]

把数值解在 $t_n$ 处作 Taylor 展开，与精确解的展开逐项比较。记 $F=\mathbf f$，$F_t=\partial_t\mathbf f$，$F_u=\partial_{\mathbf u}\mathbf f$，则精确解满足

\[
\mathbf u'=F,\qquad
\mathbf u''=F_t+F_uF,\qquad
\mathbf u'''=F_{tt}+2F_{tu}F+F_{uu}(F,F)+F_u(F_t+F_uF),\ \dots
\]

数值解展开到 $h^4$ 后与上式匹配，等价于下列**阶条件**（$c_i=\sum_j a_{ij}$）：

\[
\sum_i b_i=1,\qquad
\sum_i b_ic_i=\tfrac12,\qquad
\sum_i b_ic_i^2=\tfrac13,\qquad
\sum_{i,j}b_ia_{ij}c_j=\tfrac16,
\]

\[
\sum_i b_ic_i^3=\tfrac14,\qquad
\sum_{i,j}b_ic_ia_{ij}c_j=\tfrac18,\qquad
\sum_{i,j}b_ia_{ij}c_j^2=\tfrac1{12},\qquad
\sum_{i,j,k}b_ia_{ij}a_{jk}c_k=\tfrac1{24}.
\]

对经典 RK4：

\[
b=\Big(\tfrac16,\tfrac13,\tfrac13,\tfrac16\Big),\quad
c=\Big(0,\tfrac12,\tfrac12,1\Big),\quad
A=\begin{pmatrix}0&0&0&0\\ \tfrac12&0&0&0\\ 0&\tfrac12&0&0\\ 0&0&1&0\end{pmatrix}.
\]

逐条验证（记 $b_1=\tfrac16,b_2=b_3=\tfrac13,b_4=\tfrac16$）：

\[
\textstyle\sum b_ic_i=\tfrac13\cdot\tfrac12+\tfrac13\cdot\tfrac12+\tfrac16\cdot1=\tfrac12\ \checkmark
\]

\[
\textstyle\sum b_ic_i^2=\tfrac13\cdot\tfrac14+\tfrac13\cdot\tfrac14+\tfrac16\cdot1=\tfrac13\ \checkmark
\]

\[
\textstyle\sum b_ia_{ij}c_j=b_3\cdot\tfrac12\cdot\tfrac12+b_4\cdot 1\cdot\tfrac12=\tfrac1{12}+\tfrac1{12}=\tfrac16\ \checkmark
\]

\[
\textstyle\sum b_ic_i^3=\tfrac13\cdot\tfrac18+\tfrac13\cdot\tfrac18+\tfrac16=\tfrac14\ \checkmark
\]

\[
\textstyle\sum b_ic_i(Ac)_i=\tfrac13\cdot\tfrac12\cdot\tfrac14+\tfrac16\cdot1\cdot\tfrac12=\tfrac1{24}+\tfrac1{12}=\tfrac18\ \checkmark
\]

\[
\textstyle\sum b_i(Ac^2)_i=\tfrac13\cdot\tfrac18+\tfrac16\cdot\tfrac14=\tfrac1{12}\ \checkmark
\]

\[
\textstyle\sum b_i(AAc)_i=\tfrac16\cdot\tfrac14=\tfrac1{24}\ \checkmark
\]

八个条件全部满足，故 $h^4$ 项与精确解一致，局部误差 $O(h^5)$。由稳定性（Lipschitz）得全局误差 $O(h^4)$。$\blacksquare$

## 13.2 高阶方程化为一阶方程组

$m$ 阶初值问题

\[
y^{(m)}(t)=f\big(t,y,y',\dots,y^{(m-1)}\big),\qquad
y(a)=\alpha_1,\ y'(a)=\alpha_2,\ \dots,\ y^{(m-1)}(a)=\alpha_m .
\]

**变换.** 令

\[
u_1=y,\quad u_2=y',\quad \dots,\quad u_m=y^{(m-1)},
\]

则

\[
\frac{du_1}{dt}=u_2,\quad \frac{du_2}{dt}=u_3,\quad \dots,\quad \frac{du_{m-1}}{dt}=u_m,\quad
\frac{du_m}{dt}=f(t,u_1,\dots,u_m),
\]

初值 $u_i(a)=\alpha_i$。

**等价性.** 若 $y$ 是原 $m$ 阶问题的解，则 $\mathbf u=(y,y',\dots,y^{(m-1)})$ 满足上述方程组——逐式求导即得。反之，若 $\mathbf u$ 是方程组的解，则 $u_1'=u_2=u_1''=\dots=u_1^{(m-1)}=u_m$，故 $u_1^{(m)}=u_m'=f(t,u_1,\dots,u_1^{(m-1)})$，且 $u_1^{(k)}(a)=\alpha_{k+1}$。两个问题的解一一对应。$\blacksquare$

```matlab
% 例：y'' + 2y' + 5y = 0, y(0)=1, y'(0)=0  →  u1=y, u2=y'
f = @(t,u) [u(2); -2*u(2) - 5*u(1)];
[t, U] = rk4sys(f, 0, 5, [1 0], 200);
plot(t, U(:,1)), xlabel('t'), ylabel('y')
```

## 13.3 两点边值问题

\[
y''=f(x,y,y'),\qquad a\le x\le b,\qquad y(a)=\alpha,\quad y(b)=\beta .
\]

与初值问题不同：条件分在两端，$y'(a)$ 未知——这正是后面打靶法的出发点。

### 13.3.1 定理：存在唯一性

**定理.** 设 $f$ 在

\[
D=\{(x,y,y'):\ a\le x\le b,\ -\infty<y<\infty,\ -\infty<y'<\infty\}
\]

上连续，且 $f_y,\ f_{y'}$ 也在 $D$ 上连续。若

1. $f_y(x,y,y')>0$ 对一切 $(x,y,y')\in D$ 成立；
2. 存在常数 $M$，使 $|f_{y'}(x,y,y')|\le M$ 对一切 $(x,y,y')\in D$ 成立，

则该边值问题有唯一解。

**证明.** 设 $y_1,y_2$ 是任意两个解，令

\[
z(x)=y_1(x)-y_2(x).
\]

则 $z(a)=z(b)=0$，且

\[
z''=f(x,y_1,y_1')-f(x,y_2,y_2').
\]

对右端沿直线 $(y_2,y_2')\to(y_1,y_1')$ 应用**中值定理**（一元函数 $s\mapsto f(x,y_2+sz,y_2'+sz')$ 在 $[0,1]$ 上）：

\[
z''(x)=A(x)z'(x)+B(x)z(x),
\]

其中

\[
A(x)=\int_0^1 f_{y'}\big(x,\ y_2+sz,\ y_2'+sz'\big)\,ds,\qquad
B(x)=\int_0^1 f_{y}\big(x,\ y_2+sz,\ y_2'+sz'\big)\,ds .
\]

由条件 1、2：

\[
B(x)>0,\qquad |A(x)|\le M .
\]

下面证明 $z\equiv0$。

若 $z$ 在 $(a,b)$ 内部某点 $x_0$ 取到**正的最大值**，则

\[
z(x_0)>0,\qquad z'(x_0)=0,\qquad z''(x_0)\le0 .
\]

代入方程：

\[
0\ \ge\ z''(x_0)=A(x_0)\underbrace{z'(x_0)}_{=0}+B(x_0)\underbrace{z(x_0)}_{>0}\ >\ 0,
\]

矛盾。故 $z$ 在内部无正最大值。又 $z(a)=z(b)=0$，连续函数的最大值不能在端点取正，于是

\[
z(x)\le 0,\qquad x\in[a,b].
\]

对 $-z$ 重复上述论证（$-z$ 同样满足 $(-z)''=A(-z)'+B(-z)$，$B>0$），得 $-z\le0$，即 $z\ge0$。

综上 $z\equiv0$，即 $y_1\equiv y_2$：解唯一。存在性由 $f$ 连续与常微分方程基本定理保证。$\blacksquare$

!!! note "证明的骨架"
    三步：**作差 → 中值定理化为线性方程 → 最大值原理**。$f_y>0$ 保证 $B>0$ 从而在正最大值处右端必为正，矛盾；$|f_{y'}|\le M$ 只用于保证 $A$ 有界（上式其实没用到 $M$，它用于存在性证明与打靶法的稳定性分析）。

### 13.3.2 例：验证唯一性

讨论

\[
y''+e^{-xy}+\sin y'=0,\qquad 1\le x\le2,\qquad y(1)=y(2)=0 .
\]

改写为标准形式：$f(x,y,y')=-e^{-xy}-\sin y'$。于是

\[
f_y=xe^{-xy}>0\quad(1\le x\le2),\qquad
|f_{y'}|=|\!-\cos y'|\le1 .
\]

两个条件都满足，故有唯一解。

### 13.3.3 推论：线性边值问题

若

\[
y''=p(x)y'+q(x)y+r(x),\qquad y(a)=\alpha,\ y(b)=\beta,
\]

且 $p,q,r$ 在 $[a,b]$ 上连续、$q(x)>0$，则解唯一。

**证明.** 对照定理：$f=p(x)y'+q(x)y+r(x)$，

\[
f_y=q(x)>0,\qquad |f_{y'}|=|p(x)|\le \max_{[a,b]}|p|=:M
\]

（连续函数在闭区间上有界）。定理条件全部满足。$\blacksquare$

## 13.4 线性打靶法

### 13.4.1 构造

对线性边值问题

\[
y''=p(x)y'+q(x)y+r(x),\qquad y(a)=\alpha,\quad y(b)=\beta,
\]

考虑两个**初值问题**：

\[
\text{(I)}\quad
\begin{cases}
y_1''=p(x)y_1'+q(x)y_1+r(x)\\
y_1(a)=\alpha,\quad y_1'(a)=0
\end{cases}
\]

\[
\text{(II)}\quad
\begin{cases}
y_2''=p(x)y_2'+q(x)y_2\\
y_2(a)=0,\quad y_2'(a)=1
\end{cases}
\]

令

\[
y(x)=y_1(x)+\frac{\beta-y_1(b)}{y_2(b)}\,y_2(x).
\]

### 13.4.2 定理：构造解即边值问题的解

**证明.** 记 $c=\dfrac{\beta-y_1(b)}{y_2(b)}$，即 $y=y_1+cy_2$。

**满足方程：** 由线性性，

\[
\begin{aligned}
y''&=y_1''+cy_2''=\big(py_1'+qy_1+r\big)+c\big(py_2'+qy_2\big)\\
&=p\big(y_1'+cy_2'\big)+q\big(y_1+cy_2\big)+r=p\,y'+q\,y+r .
\end{aligned}
\]

**满足边界条件：**

\[
y(a)=y_1(a)+c\,y_2(a)=\alpha+c\cdot0=\alpha,
\]

\[
y(b)=y_1(b)+c\,y_2(b)=y_1(b)+\big(\beta-y_1(b)\big)=\beta .
\]

由 13.3.3 推论的唯一性，$y$ 就是该边值问题的唯一解。$\blacksquare$

### 13.4.3 引理：分母非零

**证明.** 反设 $y_2(b)=0$。则 $y_2$ 是齐次边值问题

\[
y''=py'+qy,\qquad y(a)=0,\quad y(b)=0
\]

的解；而 $\tilde y\equiv0$ 也是解。由唯一性（$q>0$）得 $y_2\equiv0$，与 $y_2'(a)=1$ 矛盾。故 $y_2(b)\neq0$。$\blacksquare$

**另一视角：** 齐次问题只有零解，等价于说 $y_2(b)$ 是"打靶算子"的非零行列式——这也解释了为什么线性打靶**一次**就能命中，而线性方程组的可解性由 $y_2(b)\neq0$ 保证。

### 13.4.4 算法与 MATLAB

```matlab
function [x, y] = shoot_linear(p, q, r, a, b, alpha, beta, N)
% 线性打靶法：y'' = p*y' + q*y + r, y(a)=alpha, y(b)=beta
h = (b-a)/N;  x = (a:h:b).';
% 两个初值问题都用 RK4 求解，状态取 [y; y']
f1 = @(t,u) [u(2); p(t)*u(2) + q(t)*u(1) + r(t)];
f2 = @(t,u) [u(2); p(t)*u(2) + q(t)*u(1)];
U1 = rk4sys(f1, a, b, [alpha; 0], N);
U2 = rk4sys(f2, a, b, [0; 1], N);
c  = (beta - U1(end,1)) / U2(end,1);
y  = U1(:,1) + c * U2(:,1);
end
```

!!! warning "稳定性"
    打靶法把边值问题变成初值问题，**继承了初值问题的不稳定性**：若齐次解含快速增长的模态，$y_1,y_2$ 的数值误差会被指数放大，$c$ 的计算随之失真。此时应改用有限差分法或多重打靶。

### 13.4.5 例

\[
y''=-\frac{2}{x}y'+\frac{2}{x^2}y+\frac{\sin(\ln x)}{x^2},\qquad 1\le x\le2,\quad y(1)=1,\ y(2)=2 .
\]

精确解

\[
y=c_1x+\frac{c_2}{x^2}-\frac{3}{10}\sin(\ln x)-\frac{1}{10}\cos(\ln x),
\qquad c_1\approx1.139,\ c_2\approx-0.0392 .
\]

用 $N=10$ 的 RK4 打靶，误差量级 $O(h^4)$，各节点上与精确解吻合到 $10^{-6}$ 以内。

```matlab
p = @(x) -2./x;  q = @(x) 2./x.^2;  r = @(x) sin(log(x))./x.^2;
[x, y] = shoot_linear(p, q, r, 1, 2, 1, 2, 10);
yex = 1.139*x - 0.0392./x.^2 - 0.3*sin(log(x)) - 0.1*cos(log(x));
max(abs(y - yex))
```

## 13.5 非线性打靶法

对

\[
y''=f(x,y,y'),\qquad y(a)=\alpha,\quad y(b)=\beta,
\]

固定 $y(a)=\alpha$，把 $y'(a)=t$ 当作待定参数，解初值问题

\[
y''=f(x,y,y'),\qquad y(a,t)=\alpha,\quad y'(a,t)=t .
\]

目标是求 $t$ 使

\[
F(t):=y(b,t)-\beta=0 .
\]

### 13.5.1 割线法

用差商代替导数，无需 $F'$：

\[
t_k=t_{k-1}-\frac{\big(y(b,t_{k-1})-\beta\big)\big(t_{k-1}-t_{k-2}\big)}{y(b,t_{k-1})-y(b,t_{k-2})},\qquad k=2,3,\dots
\]

每步解一次初值问题。

### 13.5.2 牛顿法：变分方程的推导

牛顿迭代

\[
t_k=t_{k-1}-\frac{y(b,t_{k-1})-\beta}{\dfrac{\partial y}{\partial t}(b,t_{k-1})}
\]

需要 $\partial y/\partial t$。把它写成 $z(x,t)=\dfrac{\partial y}{\partial t}(x,t)$，对初值问题**关于 $t$ 求导**。

原方程及初值：

\[
y''(x,t)=f\big(x,y(x,t),y'(x,t)\big),\qquad y(a,t)=\alpha,\quad y'(a,t)=t .
\]

对 $t$ 求偏导，左端 $\dfrac{\partial}{\partial t}y''=z''$；右端用链式法则（$f$ 不显含 $t$，故 $\partial f/\partial x\cdot\partial x/\partial t=0$）：

\[
\frac{\partial}{\partial t}f\big(x,y,y'\big)
=f_y\,\frac{\partial y}{\partial t}+f_{y'}\,\frac{\partial y'}{\partial t}
=f_y\,z+f_{y'}\,z' .
\]

初值求导：

\[
z(a,t)=\frac{\partial}{\partial t}y(a,t)=0,\qquad
z'(a,t)=\frac{\partial}{\partial t}y'(a,t)=1 .
\]

于是 $z$ 满足**变分方程**（线性！）

\[
\boxed{\ z''=f_y(x,y,y')\,z+f_{y'}(x,y,y')\,z',\qquad z(a)=0,\ z'(a)=1\ }
\]

牛顿迭代变为

\[
t_k=t_{k-1}-\frac{y(b,t_{k-1})-\beta}{z(b,t_{k-1})}.
\]

每步需解**两个**初值问题：$y$ 的（非线性）与 $z$ 的（线性，系数随 $y$ 变化）。

```matlab
function [t, x, y] = shoot_nonlinear(f, fy, fyp, a, b, alpha, beta, t0, tol, itmax)
% 非线性打靶（牛顿法），状态 [y; y'; z; z']
ff = @(x,u) [u(2); ...
             f(x,u(1),u(2)); ...
             u(4); ...
             fy(x,u(1),u(2))*u(3) + fyp(x,u(1),u(2))*u(4)];
t = t0;  N = 200;
for k = 1:itmax
    U = rk4sys(ff, a, b, [alpha; t; 0; 1], N);
    F  = U(end,1) - beta;         % y(b,t) - beta
    dz = U(end,3);                % z(b,t)
    t  = t - F/dz;
    if abs(F) < tol, break, end
end
x = linspace(a,b,N+1).';  y = U(:,1);
end
```

### 13.5.3 备注

- 割线法每步 1 次初值问题、收敛阶 $\approx1.618$；牛顿法每步 2 次、收敛阶 2。取舍看单次求解成本。
- 两者都要求 $z(b,t)\neq0$；若 $z(b,t)$ 接近 0，迭代会爆炸。
- 与线性打靶一样，**可能不稳定**。

## 13.6 线性边值问题的有限差分法

### 13.6.1 中心差分公式的推导

设 $y\in C^4$。在 $x_i$ 处 Taylor 展开：

\[
y(x_{i+1})=y_i+h y_i'+\frac{h^2}{2}y_i''+\frac{h^3}{6}y_i'''+\frac{h^4}{24}y_i^{(4)}+\frac{h^5}{120}y^{(5)}(\xi^+),
\]

\[
y(x_{i-1})=y_i-h y_i'+\frac{h^2}{2}y_i''-\frac{h^3}{6}y_i'''+\frac{h^4}{24}y_i^{(4)}-\frac{h^5}{120}y^{(5)}(\xi^-).
\]

**相加**（奇次项抵消）：

\[
y_{i+1}+y_{i-1}=2y_i+h^2y_i''+\frac{h^4}{12}y_i^{(4)}+O(h^6)
\]

\[
\Longrightarrow\quad
\boxed{\ y_i''=\frac{y_{i+1}-2y_i+y_{i-1}}{h^2}-\frac{h^2}{12}y^{(4)}(\xi_i),\qquad \xi_i\in(x_{i-1},x_{i+1})\ }
\]

**相减**（偶次项抵消）：

\[
y_{i+1}-y_{i-1}=2hy_i'+\frac{h^3}{3}y_i'''+O(h^5)
\]

\[
\Longrightarrow\quad
\boxed{\ y_i'=\frac{y_{i+1}-y_{i-1}}{2h}-\frac{h^2}{6}y'''(\eta_i),\qquad \eta_i\in(x_{i-1},x_{i+1})\ }
\]

两式的余项都由 Taylor 定理的中间值形式得到（把 $O(h^5)$ 项合并成某个中间点处的值）。

### 13.6.2 差分格式

把两式代入 $y''=py'+qy+r$：

\[
\frac{y_{i+1}-2y_i+y_{i-1}}{h^2}
=p_i\frac{y_{i+1}-y_{i-1}}{2h}+q_iy_i+r_i-\underbrace{\frac{h^2}{12}\Big[2p_iy'''(\eta_i)-y^{(4)}(\xi_i)\Big]}_{\text{截断误差}} .
\]

丢掉误差项，用 $w_i\approx y(x_i)$，两边乘 $h^2$：

\[
-\big(w_{i+1}-2w_i+w_{i-1}\big)+h p_i\frac{w_{i+1}-w_{i-1}}{2}+h^2q_iw_i=-h^2r_i
\]

整理成三对角形式：

\[
\boxed{\
\Big(-1-\frac{h p_i}{2}\Big)w_{i-1}+\big(2+h^2q_i\big)w_i+\Big(-1+\frac{h p_i}{2}\Big)w_{i+1}=-h^2r_i
\ }
\]

边界：$w_0=\alpha$，$w_{N+1}=\beta$；$i=1$ 与 $i=N$ 时把已知项移到右端。

矩阵形式 $A\mathbf w=\mathbf b$，$A$ 三对角：

\[
A=\begin{pmatrix}
2+h^2q_1 & -1+\frac{hp_1}{2} & & \\
-1-\frac{hp_2}{2} & 2+h^2q_2 & -1+\frac{hp_2}{2} & \\
& \ddots & \ddots & \ddots \\
& & -1-\frac{hp_N}{2} & 2+h^2q_N
\end{pmatrix}
\]

### 13.6.3 定理：步长足够小时解唯一

**定理.** 设 $p,q,r$ 连续、$q(x)\ge0$，$L=\max_{[a,b]}|p(x)|$。若

\[
h<\frac{2}{L},
\]

则差分方程组有唯一解。

**证明.** 只需证 $A$ 非奇异。考察第 $i$ 行的**严格对角占优**性。因 $hL<2$，有 $\dfrac{h|p_i|}{2}<1$，于是

\[
\Big|1+\frac{hp_i}{2}\Big|+\Big|1-\frac{hp_i}{2}\Big|=2
\qquad\Big(\text{因为 } 1\pm\tfrac{hp_i}{2}>0\Big).
\]

而对角元

\[
\big|2+h^2q_i\big|=2+h^2q_i>2=\Big|1+\frac{hp_i}{2}\Big|+\Big|1-\frac{hp_i}{2}\Big| .
\]

即 $A$ 的每一行都**严格对角占优**。由 Lévy–Desplanques 定理（严格对角占优矩阵非奇异），$\det A\neq0$，方程组有唯一解。$\blacksquare$

!!! note "另一种证法：离散最大值原理"
    设两解之差 $u$ 满足齐次方程、$u_0=u_{N+1}=0$。取 $|u_k|=\max_i|u_i|$，把第 $k$ 行移项：

    \[
    (2+h^2q_k)u_k=\Big(1+\tfrac{hp_k}{2}\Big)u_{k+1}+\Big(1-\tfrac{hp_k}{2}\Big)u_{k-1}.
    \]

    取绝对值并用 $|u_{k\pm1}|\le|u_k|$：$(2+h^2q_k)|u_k|\le2|u_k|$，因 $h^2q_k>0$ 得 $|u_k|=0$。同结论，且更直接。

### 13.6.4 算法与 MATLAB

```matlab
function [x, w] = fd_linear(p, q, r, a, b, alpha, beta, N)
% 线性边值问题有限差分：三对角系统
h = (b-a)/(N+1);  x = (a:h:b).';
i = (1:N).';  xi = x(i+1);
lower = -1 - h*p(xi)/2;      % w_{i-1} 系数
diag_ =  2 + h^2*q(xi);      % w_i   系数
upper = -1 + h*p(xi)/2;      % w_{i+1} 系数
rhs   = -h^2*r(xi);
rhs(1)   = rhs(1)   - lower(1)*alpha;      % 移项 w0 = alpha
rhs(end) = rhs(end) - upper(end)*beta;     % 移项 w_{N+1} = beta
A = diag(diag_) + diag(upper(1:end-1),1) + diag(lower(2:end),-1);
w = [alpha; A\rhs; beta];
end
```

### 13.6.5 例

同 13.4.5 的边值问题，取 $N=9$（$h=0.1$）：

```matlab
p = @(x) -2./x;  q = @(x) 2./x.^2;  r = @(x) sin(log(x))./x.^2;
[x, w] = fd_linear(p, q, r, 1, 2, 1, 2, 9);
```

与打靶法（$O(h^4)$）相比，差分法的截断误差是 $O(h^2)$，同等 $h$ 下精度低两阶；优点是**天然稳定**（不放大误差）。

!!! note "提高精度"
    课件指出：与其构造高阶格式，不如**减小 $h$**；也可用 Richardson 外推：若 $w_h$、$w_{h/2}$ 分别对应步长 $h,h/2$，则

    \[
    \tilde w=\frac{4w_{h/2}-w_h}{3}=y+O(h^4).
    \]

## 13.7 非线性边值问题的有限差分法

### 13.7.1 差分方程

把中心差分代入 $y''=f(x,y,y')$：

\[
\frac{y_{i+1}-2y_i+y_{i-1}}{h^2}
=f\!\left(x_i,\ y_i,\ \frac{y_{i+1}-y_{i-1}}{2h}-\frac{h^2}{6}y'''(\eta_i)\right)+\frac{h^2}{12}y^{(4)}(\xi_i)
\]

丢掉 $O(h^2)$ 项，得到

\[
\boxed{\
-\big(w_{i+1}-2w_i+w_{i-1}\big)+h^2f\!\left(x_i,\ w_i,\ \frac{w_{i+1}-w_{i-1}}{2h}\right)=0,\quad i=1,\dots,N
\ }
\]

$w_0=\alpha,\ w_{N+1}=\beta$。这是 $N$ 个未知量的**非线性**方程组，记作

\[
\mathbf G(\mathbf w)=\mathbf 0,\qquad
G_i(\mathbf w)=-w_{i+1}+2w_i-w_{i-1}+h^2f\!\left(x_i,w_i,\frac{w_{i+1}-w_{i-1}}{2h}\right).
\]

展开写（注意边界项：

\[
\begin{aligned}
2w_1-w_2+h^2f\!\Big(x_1,w_1,\frac{w_2-\alpha}{2h}\Big)-\alpha&=0,\\
-w_{i-1}+2w_i-w_{i+1}+h^2f\!\Big(x_i,w_i,\frac{w_{i+1}-w_{i-1}}{2h}\Big)&=0,\\
-w_{N-1}+2w_N+h^2f\!\Big(x_N,w_N,\frac{\beta-w_{N-1}}{2h}\Big)-\beta&=0 .
\end{aligned}
\]

### 13.7.2 Newton 迭代

\[
J(\mathbf w^{(k)})\,\Delta\mathbf w=-\mathbf G(\mathbf w^{(k)}),\qquad
\mathbf w^{(k+1)}=\mathbf w^{(k)}+\Delta\mathbf w,
\]

其中 Jacobian 仍是**三对角**。由链式法则（记 $f_y,f_{y'}$ 在 $(x_i,w_i,\frac{w_{i+1}-w_{i-1}}{2h})$ 处取值）：

\[
\frac{\partial G_i}{\partial w_{i-1}}=-1-\frac{h}{2}f_{y'},\qquad
\frac{\partial G_i}{\partial w_i}=2+h^2f_y,\qquad
\frac{\partial G_i}{\partial w_{i+1}}=-1+\frac{h}{2}f_{y'} .
\]

### 13.7.3 定理：步长足够小时解唯一

**定理.** 设 $f,f_y,f_{y'}$ 连续，$f_y\ge0$，$|f_{y'}|\le L$。若 $h<2/L$，则上述非线性差分方程组有唯一解。

**证明.** 设 $\mathbf u,\mathbf v$ 都是解。

由 $\mathbf G(\mathbf u)=\mathbf G(\mathbf v)=\mathbf 0$，对 $\mathbf G$ 沿线段 $\mathbf v+s(\mathbf u-\mathbf v)$ 用中值定理（逐分量）：

\[
0=\mathbf G(\mathbf u)-\mathbf G(\mathbf v)
=\Big[\int_0^1J\big(\mathbf v+s(\mathbf u-\mathbf v)\big)ds\Big](\mathbf u-\mathbf v)
=:M\,(\mathbf u-\mathbf v).
\]

矩阵 $M$ 是三对角的凸组合，其元素满足

\[
M_{i,i-1}=-1-\frac h2\overline{f_{y'}},\qquad
M_{i,i}=2+h^2\overline{f_y},\qquad
M_{i,i+1}=-1+\frac h2\overline{f_{y'}},
\]

其中横线表示沿线段的积分平均。因 $f_y\ge0$，$M_{i,i}\ge2$；因 $hL<2$，有 $\big|1\pm\frac h2\overline{f_{y'}}\big|=1\pm\frac h2\overline{f_{y'}}$，故

\[
|M_{i,i,i}|=2+h^2\overline{f_y}\ \ge\ 2\ =\ \Big|1+\frac h2\overline{f_{y'}}\Big|+\Big|1-\frac h2\overline{f_{y'}}\Big| .
\]

若某个 $\overline{f_y}>0$ 则严格大于；即便全为 0，也只需 $M$ 满足不可约对角占优——三对角阵显然是不可约的。于是 $M$ 非奇异，故 $\mathbf u-\mathbf v=\mathbf 0$。$\blacksquare$

### 13.7.4 MATLAB

```matlab
function [x, w] = fd_nonlinear(f, fy, fyp, a, b, alpha, beta, N, tol, itmax)
% 非线性边值问题：Newton 迭代解三对角系统
h = (b-a)/(N+1);  x = (a:h:b).';  xi = x(2:end-1);
w = linspace(alpha, beta, N+2).';      % 线性初值
for k = 1:itmax
    wi = w(2:end-1);  wp = w(3:end);  wm = w(1:end-2);
    d  = (wp - wm)/(2*h);
    G  = -(wp - 2*wi + wm) + h^2*f(xi, wi, d);
    Fy = fy(xi, wi, d);  Fp = fyp(xi, wi, d);
    lower = -1 - h*Fp/2;  diag_ = 2 + h^2*Fy;  upper = -1 + h*Fp/2;
    J = diag(diag_) + diag(upper(1:end-1),1) + diag(lower(2:end),-1);
    dw = J \ (-G);
    w(2:end-1) = w(2:end-1) + dw;
    if norm(dw, inf) < tol, break, end
end
end
```

## 13.8 椭圆型方程：Poisson 方程

\[
\nabla^2u\equiv\frac{\partial^2u}{\partial x^2}+\frac{\partial^2u}{\partial y^2}=f(x,y),
\qquad (x,y)\in R=(a,b)\times(c,d),
\]

边界 $S=\partial R$ 上 $u=g$。$f=0$ 时退化为 Laplace 方程。

### 13.8.1 五点差分格式的推导

取网格 $x_i=a+ih$（$i=0..n$），$y_j=c+jk$（$j=0..m$）。对 $x$、$y$ 分别用 13.6.1 的中心差分公式：

\[
\frac{\partial^2u}{\partial x^2}(x_i,y_j)=\frac{u_{i+1,j}-2u_{ij}+u_{i-1,j}}{h^2}-\frac{h^2}{12}\frac{\partial^4u}{\partial x^4}(\xi_i,y_j),
\]

\[
\frac{\partial^2u}{\partial y^2}(x_i,y_j)=\frac{u_{i,j+1}-2u_{ij}+u_{i,j-1}}{k^2}-\frac{k^2}{12}\frac{\partial^4u}{\partial y^4}(x_i,\eta_j).
\]

两式相加令其等于 $f_{ij}$：

\[
\frac{u_{i+1,j}-2u_{ij}+u_{i-1,j}}{h^2}+\frac{u_{i,j+1}-2u_{ij}+u_{i,j-1}}{k^2}
=f_{ij}+\frac{h^2}{12}u_{xxxx}+\frac{k^2}{12}u_{yyyy} .
\]

乘 $h^2$，记 $s=(h/k)^2$：

\[
\big(u_{i+1,j}-2u_{ij}+u_{i-1,j}\big)+s\big(u_{i,j+1}-2u_{ij}+u_{i,j-1}\big)=h^2f_{ij}+O(h^4)
\]

\[
\boxed{\
2\big(s+1\big)w_{ij}-\big(w_{i+1,j}+w_{i-1,j}\big)-s\big(w_{i,j+1}+w_{i,j-1}\big)=-h^2f_{ij}
\ }
\]

即每个内点与上下左右四个邻居相连（**五点格式**），局部截断误差 $O(h^2+k^2)$。

### 13.8.2 矩阵结构与对称正定性

若按行编号（$i$ 快、$j$ 慢），未知量排成 $\mathbf w=(w_{1,1},\dots,w_{n-1,1},w_{1,2},\dots)$，则

\[
A=\begin{pmatrix}
T & -I & & \\
-I & T & -I & \\
& \ddots & \ddots & \ddots \\
& & -I & T
\end{pmatrix},
\qquad
T=\begin{pmatrix}
2(1+s) & -1 & &\\
-1 & 2(1+s) & -1 &\\
& \ddots & \ddots & \ddots
\end{pmatrix}
\]

块三对角，$I$ 为 $(n-1)$ 阶单位阵。

**命题.** $A$ 对称正定。

**证明.** 对称性由结构直接看出。对任意非零 $\mathbf w$（对应内部网格函数，边界取 0），

\[
\mathbf w^{\mathsf T}A\mathbf w
=\sum_{i,j}\Big[(w_{i+1,j}-w_{ij})^2+s\,(w_{i,j+1}-w_{ij})^2\Big]\ \ge\ 0,
\]

等号成立当且仅当所有相邻差为 0，即 $w$ 为常数；而边界值为 0，故 $w\equiv0$，与 $\mathbf w\neq0$ 矛盾。故 $A$ 正定。$\blacksquare$

（正定性 $\Rightarrow$ 非奇异 $\Rightarrow$ 差分方程唯一可解；同时保证可用 Cholesky 或共轭梯度求解。）

### 13.8.3 MATLAB

```matlab
function [X, Y, W] = poisson_solve(f, g, a, b, c, d, n, m)
% Poisson 方程 -Δu = -f（这里按 u_xx+u_yy=f 实现），五点格式 + 直接解
h = (b-a)/n;  k = (d-c)/m;  s = (h/k)^2;
x = a + (0:n)*h;  y = c + (0:m)*k;  [X, Y] = meshgrid(x, y);
W = zeros(m+1, n+1);
W(1,:)   = g(X(1,:),   y(1));     % 下边界
W(end,:) = g(X(end,:), y(end));   % 上边界
W(:,1)   = g(x(1),   Y(:,1));     % 左边界
W(:,end) = g(x(end), Y(:,end));   % 右边界
nx = n-1;  ny = m-1;  N = nx*ny;
A = sparse(N,N);  rhs = zeros(N,1);
idx = @(i,j) (j-1)*nx + i;        % 按行编号
for j = 1:ny
    for i = 1:nx
        r = idx(i,j);
        A(r,r) = 2*(1+s);
        if i > 1,  A(r, idx(i-1,j)) = -1; else rhs(r) = rhs(r) + W(j+1,1);   end
        if i < nx, A(r, idx(i+1,j)) = -1; else rhs(r) = rhs(r) + W(j+1,end); end
        if j > 1,  A(r, idx(i,j-1)) = -s; else rhs(r) = rhs(r) + s*W(1,i+1); end
        if j < ny, A(r, idx(i,j+1)) = -s; else rhs(r) = rhs(r) + s*W(end,i+1); end
        rhs(r) = rhs(r) - h^2*f(x(i+1), y(j+1));
    end
end
sol = A \ rhs;
for j = 1:ny, W(j+1, 2:end-1) = sol((j-1)*nx + (1:nx)); end
end
```

## 13.9 抛物型方程：热传导方程

\[
\frac{\partial u}{\partial t}=\alpha^2\frac{\partial^2u}{\partial x^2},\qquad 0<x<l,\ t>0,
\]

\[
u(0,t)=u(l,t)=0,\qquad u(x,0)=f(x).
\]

### 13.9.1 显式（前向）格式

时间用**前向**差商、空间用**中心**差商：

\[
\frac{\partial u}{\partial t}(x_i,t_j)=\frac{u_i^{j+1}-u_i^{j}}{k}-\frac{k}{2}\frac{\partial^2u}{\partial t^2}(x_i,\mu_j),
\qquad
\frac{\partial^2u}{\partial x^2}=\frac{u_{i+1}^{j}-2u_i^{j}+u_{i-1}^{j}}{h^2}-\frac{h^2}{12}u_{xxxx}.
\]

代入热方程并丢掉误差项：

\[
\boxed{\
w_i^{j+1}=r\,w_{i-1}^{j}+(1-2r)\,w_i^{j}+r\,w_{i+1}^{j},\qquad r=\frac{\alpha^2k}{h^2}
\ }
\]

局部截断误差

\[
\tau_i^{j}=\frac{k}{2}u_{tt}(x_i,\mu_j)-\alpha^2\frac{h^2}{12}u_{xxxx}(\xi_i,t_j)=O(k+h^2).
\]

**注意**：格式显式，$w_i^{j+1}$ 可直接算出；但 $r$ 不能任意大。

### 13.9.2 定理：稳定性条件 r ≤ 1/2

**定理.** 上述显式格式按 $L^2$（von Neumann）意义稳定，当且仅当

\[
r=\frac{\alpha^2k}{h^2}\le\frac12 .
\]

**证明（von Neumann 方法）.** 设误差按 Fourier 模态传播，令

\[
w_i^{j}=\lambda^{j}e^{\mathrm i i\theta}\qquad(\theta\in[-\pi,\pi]).
\]

代入差分格式：

\[
\lambda^{j+1}e^{\mathrm i i\theta}
=r\lambda^{j}e^{\mathrm i(i-1)\theta}+(1-2r)\lambda^{j}e^{\mathrm i i\theta}+r\lambda^{j}e^{\mathrm i(i+1)\theta}.
\]

两边约去 $\lambda^je^{\mathrm i i\theta}$：

\[
\lambda=r e^{-\mathrm i\theta}+(1-2r)+r e^{\mathrm i\theta}
=1-2r+2r\cos\theta
=1-2r(1-\cos\theta)
=1-4r\sin^2\frac{\theta}{2}.
\]

稳定性要求对一切 $\theta$ 有 $|\lambda|\le1$：

\[
-1\ \le\ 1-4r\sin^2\frac{\theta}{2}\ \le\ 1 .
\]

右端恒成立（因 $r>0,\ \sin^2\ge0$）。左端化为

\[
4r\sin^2\frac{\theta}{2}\ \le\ 2
\quad\Longleftrightarrow\quad
r\ \le\ \frac{1}{2\sin^2(\theta/2)} .
\]

对 $\theta\in[-\pi,\pi]$ 取最坏情形 $\theta=\pi$（$\sin^2=1$），得

\[
r\le\frac12 .
\]

若 $r>\frac12$，取 $\theta=\pi$ 得 $\lambda=1-4r<-1$，$|\lambda|>1$，误差按 $\lambda^j$ 指数放大，格式不稳定。$\blacksquare$

!!! note "物理直觉"
    $r\le1/2$ 等价于 $k\le\dfrac{h^2}{2\alpha^2}$：时间步长必须小于扩散穿过一个网格间距所需时间的一半。网格加密一倍，时间步要缩小到 $1/4$——显式格式的典型代价。

### 13.9.3 MATLAB

```matlab
function [x, t, W] = heat_explicit(alpha2, l, T, f, m, N)
% 热方程 u_t = alpha2*u_xx，显式格式（要求 r <= 0.5）
h = l/m;  k = T/N;  r = alpha2*k/h^2;
if r > 0.5, warning('r = %.3f > 0.5，格式不稳定', r); end
x = (0:m)*h;  t = (0:N)*k;  W = zeros(m+1, N+1);
W(:,1) = f(x).';  W(1,:) = 0;  W(end,:) = 0;
for j = 1:N
    W(2:m, j+1) = r*W(1:m-1, j) + (1-2*r)*W(2:m, j) + r*W(3:m+1, j);
end
end
```

## 13.10 双曲型方程：波动方程

\[
\frac{\partial^2u}{\partial t^2}=\alpha^2\frac{\partial^2u}{\partial x^2},\qquad 0<x<l,\ t>0,
\]

\[
u(0,t)=u(l,t)=0,\qquad u(x,0)=f(x),\qquad u_t(x,0)=g(x).
\]

### 13.10.1 显式格式

对 $x$、$t$ 都用中心差分：

\[
\frac{u_i^{j+1}-2u_i^{j}+u_i^{j-1}}{k^2}=\alpha^2\frac{u_{i+1}^{j}-2u_i^{j}+u_{i-1}^{j}}{h^2}+O(h^2+k^2),
\]

记 $r=\alpha k/h$：

\[
\boxed{\
w_i^{j+1}=2(1-r^2)w_i^{j}+r^2\big(w_{i+1}^{j}+w_{i-1}^{j}\big)-w_i^{j-1}
\ }
\]

启动需要两层：$w_i^0=f(x_i)$，以及由 $u_t(x,0)=g$ 用中心差分得到

\[
w_i^{1}=\frac{r^2}{2}\big(w_{i+1}^{0}+w_{i-1}^{0}\big)+(1-r^2)w_i^{0}+k\,g(x_i)+O(k^3).
\]

### 13.10.2 定理：CFL 条件 r ≤ 1

**定理.** 上述格式稳定当且仅当

\[
r=\frac{\alpha k}{h}\le1 .
\]

**证明.** 仍用 von Neumann 方法。令 $w_i^j=\lambda^je^{\mathrm i i\theta}$ 代入：

\[
\lambda^2e^{\mathrm i i\theta}
=2(1-r^2)\lambda e^{\mathrm i i\theta}
+r^2\lambda\big(e^{\mathrm i(i+1)\theta}+e^{\mathrm i(i-1)\theta}\big)-e^{\mathrm i i\theta}.
\]

约去 $e^{\mathrm i i\theta}$：

\[
\lambda^2=2(1-r^2)\lambda+2r^2\cos\theta-1 .
\]

即

\[
\lambda^2-2\mu\lambda+1=0,\qquad
\mu:=1-r^2+r^2\cos\theta=1-2r^2\sin^2\frac{\theta}{2}.
\]

两根

\[
\lambda_{\pm}=\mu\pm\sqrt{\mu^2-1}.
\]

- 若 $|\mu|\le1$：判别式 $\le0$，$\lambda_\pm=\mu\pm \mathrm i\sqrt{1-\mu^2}$，故 $|\lambda_\pm|^2=\mu^2+(1-\mu^2)=1$。

- 若 $|\mu|>1$：判别式 $>0$，$\lambda_\pm$ 为实根且 $\lambda_+\lambda_-=1$，故 $|\lambda_+|>1$ 或 $|\lambda_-|>1$。

因此稳定性 $\iff|\mu|\le1$ 对一切 $\theta$ 成立。而

\[
\mu=1-2r^2\sin^2\frac{\theta}{2}\in\big[1-2r^2,\ 1\big],
\]

$|\mu|\le1\iff 2r^2\sin^2\frac{\theta}{2}\le2\iff r^2\sin^2\frac{\theta}{2}\le1$ 对所有 $\theta$，取 $\theta=\pi$ 得

\[
r\le1 .
\]

$\blacksquare$

!!! note "CFL 条件的含义"
    $r=\alpha k/h\le1$ 即 $k\le h/\alpha$：数值依赖域（$|x-x_i|\le\alpha t$）必须覆盖真解的依赖域。这是显式双曲格式的**因果性**要求，与抛物型 $r\le1/2$ 同源（都来自 von Neumann 分析），但物理意义不同。

### 13.10.3 MATLAB

```matlab
function [x, t, W] = wave_explicit(alpha, l, T, f, g, m, N)
% 波动方程 u_tt = alpha^2 u_xx，显式格式（要求 r <= 1）
h = l/m;  k = T/N;  r = alpha*k/h;
if r > 1, warning('r = %.3f > 1，格式不稳定', r); end
x = (0:m)*h;  t = (0:N)*k;  W = zeros(m+1, N+1);
W(:,1) = f(x).';  W(1,:) = 0;  W(end,:) = 0;
W(2:m,2) = 0.5*r^2*(W(3:m+1,1)+W(1:m-1,1)) + (1-r^2)*W(2:m,1) + k*g(x(2:m)).';
for j = 2:N
    W(2:m,j+1) = 2*(1-r^2)*W(2:m,j) + r^2*(W(3:m+1,j)+W(1:m-1,j)) - W(2:m,j-1);
end
end
```

## 坑与陷阱

!!! danger "十条"
    1. **不要用打靶法解刚性边值问题**：初值问题的不稳定性会被指数放大；此时用有限差分。
    2. **$y_2(b)\neq0$ 是线性打靶的前提**，$z(b,t)\neq0$ 是牛顿打靶的前提；接近 0 时结果不可信。
    3. **线性打靶只需解两个初值问题**（一次命中），非线性打靶要迭代——别混。
    4. **RK4 用在方程组上时，$k_2$ 的第二个分量必须用 $k_{1,i}$ 的全部分量**，不能只用自己的。
    5. **差分法的 $h$ 不必等于打靶的 $h$**；两者误差阶不同（$O(h^2)$ vs $O(h^4)$）。
    6. **$h<2/L$ 是唯一性的充分条件**，不是稳定的充分条件；$L=\max|p|$ 要在整个区间上取。
    7. **Poisson 的五点格式要求矩形区域**；非矩形区域需用有限元或不规则网格。
    8. **热方程显式格式必须满足 $r\le1/2$**，否则数值解会振荡发散——检查 $r$ 再跑。
    9. **波动方程启动层**要用 $u_t(x,0)=g$ 的中心差分构造，误差 $O(k^3)$，不能用一阶前向（会破坏整体二阶精度）。
    10. **边界条件 $g$ 的处理**：差分方程右端要把已知边界项移到左边，漏掉一项整个解都会偏。

## 速览

1. 一阶方程组用向量 RK4；$m$ 阶方程令 $u_k=y^{(k-1)}$ 降为一阶系统。
2. RK4 四阶精度来自 8 个 Butcher 阶条件全部满足。
3. BVP 唯一性：$f_y>0$ + $|f_{y'}|\le M$ ⇒ 作差 + 中值定理 + 最大值原理。
4. 线性打靶：$y=y_1+c y_2$，$c=(\beta-y_1(b))/y_2(b)$，一次求解即可。
5. 非线性打靶：把 $y'(a)=t$ 当参数，割线法或牛顿法求 $F(t)=y(b,t)-\beta=0$。
6. 牛顿打靶每步解两个初值问题：$y$ 的与变分方程 $z''=f_yz+f_{y'}z'$ 的。
7. 中心差分：$y''$ 截断误差 $-h^2y^{(4)}/12$，$y'$ 截断误差 $-h^2y'''/6$。
8. 有限差分线性系统三对角，$h<2/L$ 时严格对角占优 ⇒ 唯一可解。
9. 非线性差分用 Newton，Jacobian 三对角，$h<2/L$ 时唯一。
10. Poisson 五点格式 $O(h^2+k^2)$；热方程显式 $r\le1/2$；波动方程 $r\le1$（均 von Neumann 推出）。
