# 第 10 章 数值微分

> 内容：前向、后向与中心差商，一般多点公式，三点与五点公式，高阶导数近似，舍入误差与最优步长，Richardson 外推。
> 课件给出结论的定理，这里补完整推导；伪代码改写为 MATLAB。

数值微分是数值积分（第 11 章）的逆问题：积分把函数值"抹平"，微分把函数值"放大"。同一个差商，步长取大了截断误差大，取小了舍入误差大——这是全书第一个真正**不稳定**的方法，也是理解"误差权衡"的最好例子。

## 10.1 差商与差分公式

### 10.1.1 从导数定义到差商

导数定义为

\[
f'(x_0)=\lim_{h\to 0}\frac{f(x_0+h)-f(x_0)}{h}.
\]

最直接的想法是"取一个很小的 \(h\)，把极限换成除法"。但极限过程被删掉后，剩下的误差有多少、\(h\) 该取多小，都必须定量回答。

### 10.1.2 前向差商

设 \(x_0\in(a,b)\)，\(f\in C^2[a,b]\)，\(x_0+h\in[a,b]\)。在 \(x_0\) 处作一阶 Taylor 展开，余项用 Lagrange 形式：

\[
f(x_0+h)=f(x_0)+f'(x_0)h+\frac{f''(\xi)}{2}h^2,\qquad \xi\in(x_0,x_0+h).
\]

整理得

\[
\boxed{\
f'(x_0)=\frac{f(x_0+h)-f(x_0)}{h}-\frac{h}{2}f''(\xi)
\ }
\]

右端第一项就是前向差商，第二项是**截断误差**。若 \(|f''(x)|\le M\) 在 \([x_0,x_0+h]\) 上成立，则

\[
\left|f'(x_0)-\frac{f(x_0+h)-f(x_0)}{h}\right|\le \frac{M|h|}{2}=O(h).
\]

所以前向差商是一阶公式：步长减半，误差约减半。

### 10.1.3 后向差商

仍取 \(h>0\)，在 \(x_0-h\) 处展开：

\[
f(x_0-h)=f(x_0)-f'(x_0)h+\frac{f''(\xi)}{2}h^2,\qquad \xi\in(x_0-h,x_0).
\]

于是

\[
\boxed{\
f'(x_0)=\frac{f(x_0)-f(x_0-h)}{h}+\frac{h}{2}f''(\xi)
\ }
\]

后向差商同样是一阶公式，只是误差主项符号相反。

!!! note "课件里的统一写法"
    课件把 \(h\) 的符号也交给公式：同一个商

    \[
    \frac{f(x_0+h)-f(x_0)}{h}
    \]

    在 \(h>0\) 时叫前向差商，在 \(h<0\) 时叫后向差商。两种情形的一阶误差界都是 \(M|h|/2\)。

### 10.1.4 中心差商

设 \(f\in C^3[x_0-h,x_0+h]\)。把 \(x_0+h\) 与 \(x_0-h\) 两端的函数值都用上，可把一阶项消掉。令

\[
F(h)=f(x_0+h)-f(x_0-h).
\]

则 \(F(0)=0\)，\(F'(0)=2f'(x_0)\)，\(F''(0)=0\)，且

\[
F'''(h)=f'''(x_0+h)+f'''(x_0-h).
\]

对 \(F\) 在 \(0\) 处作三阶 Taylor 展开（Lagrange 余项）：

\[
F(h)=F(0)+F'(0)h+\frac{F''(0)}{2}h^2+\frac{F'''(\theta h)}{6}h^3
=2f'(x_0)h+\frac{h^3}{6}\big[f'''(x_0+\theta h)+f'''(x_0-\theta h)\big],
\]

其中 \(\theta\in(0,1)\)。两边除以 \(2h\)：

\[
\frac{f(x_0+h)-f(x_0-h)}{2h}
=f'(x_0)+\frac{h^2}{12}\big[f'''(x_0+\theta h)+f'''(x_0-\theta h)\big].
\]

因为 \(f'''\) 连续，方括号中的平均值等于区间内某点的函数值（介值定理）：存在 \(\xi\in(x_0-h,x_0+h)\)，使

\[
\frac{f'''(x_0+\theta h)+f'''(x_0-\theta h)}{2}=f'''(\xi).
\]

代回即得

\[
\boxed{\
f'(x_0)=\frac{f(x_0+h)-f(x_0-h)}{2h}-\frac{h^2}{6}f'''(\xi)
\ }
\]

中心差商是**二阶公式**：步长减半，误差约降到四分之一。代价是误差项从 \(f''\) 变成了 \(f'''\)，对光滑性的要求提高一阶。

!!! note "为什么正好消掉一阶项"
    \(F(h)\) 是奇函数：\(F(-h)=-F(h)\)。奇函数的 Taylor 展开只含奇次幂，\(h^2\) 项自动为零，所以最低的非零误差项是 \(h^3\)，除以 \(2h\) 后成为 \(h^2\)。

### 10.1.5 例：对数函数的导数

用前向差商近似 \(f(x)=\ln x\) 在 \(x_0=1.8\) 处的导数。真值为

\[
f'(1.8)=\frac{1}{1.8}=0.5555556.
\]

误差界为 \(|h|/(2\cdot 1.8^2)\)：

| \(h\) | \(f(1.8+h)\) | 前向差商 | 实际误差 | 误差界 |
| --- | --- | --- | --- | --- |
| 0.1 | 0.64185389 | 0.5406722 | 0.0148834 | 0.0154321 |
| 0.05 | 0.61518564 | 0.5479795 | 0.0075761 | 0.0077160 |
| 0.01 | 0.59332685 | 0.5540180 | 0.0015376 | 0.0015432 |

误差界略大于实际误差，符合预期；误差随 \(h\) 线性下降，也验证了一阶收敛。

## 10.2 一般导数近似公式

### 10.2.1 从插值多项式出发

取 \(n+1\) 个互异节点 \(x_0,\dots,x_n\)，设 \(f\in C^{n+1}(I)\)，作 Lagrange 插值多项式 \(P_n\)。插值余项为

\[
f(x)=P_n(x)+\frac{\omega(x)}{(n+1)!}f^{(n+1)}(\xi(x)),
\qquad \omega(x)=\prod_{k=0}^{n}(x-x_k).
\]

两边求导：

\[
f'(x)=P_n'(x)+\frac{\omega'(x)}{(n+1)!}f^{(n+1)}(\xi(x))
+\frac{\omega(x)}{(n+1)!}\frac{d}{dx}f^{(n+1)}(\xi(x)).
\]

在节点 \(x=x_j\) 处，\(\omega(x_j)=0\)，最后一项消失；又

\[
P_n'(x_j)=\sum_{k=0}^{n}f(x_k)L_k'(x_j),
\qquad
\omega'(x_j)=\prod_{\substack{k=0\\ k\ne j}}^{n}(x_j-x_k).
\]

于是得到 \((n+1)\) 点公式

\[
\boxed{\
f'(x_j)=\sum_{k=0}^{n}f(x_k)L_k'(x_j)
+\frac{f^{(n+1)}(\xi_j)}{(n+1)!}\prod_{\substack{k=0\\ k\ne j}}^{n}(x_j-x_k)
\ }
\]

其中 \(\xi_j\) 位于包含这些节点的区间内。

!!! note "余项求导的严格化"
    形式上对 \(f^{(n+1)}(\xi(x))\) 求导需要 \(\xi(x)\) 可导，而插值余项定理并不保证这一点。严格的做法是令

    \[
    E(x)=f(x)-P_n(x)=\omega(x)q(x),
    \]

    其中 \(q\) 在节点处用极限 \(q(x_j)=E'(x_j)/\omega'(x_j)\) 连续延拓。由差商中值定理，

    \[
    q(x_j)=f[x_0,\dots,x_n,x_j]=\frac{f^{(n+1)}(\xi_j)}{(n+1)!}.
    \]

    又 \(E'(x_j)=\omega'(x_j)q(x_j)\)，因为 \(\omega(x_j)=0\)。这正是上面的公式。

### 10.2.2 误差项

误差项为

\[
E_j=\frac{f^{(n+1)}(\xi_j)}{(n+1)!}\prod_{k\ne j}(x_j-x_k).
\]

它由两部分组成：**函数的光滑性**（\(f^{(n+1)}\)）和**节点几何**（连乘积）。节点一旦选定，连乘积就是常数，可以预先算好。

### 10.2.3 误差系数

对等距节点 \(x_k=x_0+kh\)，有 \(x_j-x_k=(j-k)h\)，所以

\[
\prod_{k\ne j}(x_j-x_k)
=h^n\prod_{k\ne j}(j-k)
=(-1)^{n-j}j!\,(n-j)!\,h^n.
\]

因此

\[
\boxed{\
E_j=\frac{(-1)^{n-j}j!(n-j)!}{(n+1)!}h^n f^{(n+1)}(\xi_j)
=\frac{(-1)^{n-j}h^n}{(n+1)\binom{n}{j}}f^{(n+1)}(\xi_j)
\ }
\]

这个公式把误差系数完全显式化了。验证两个常用情形：

- \(n=2\)：\(j=0,2\) 时系数为 \(h^2/3\)，\(j=1\) 时为 \(-h^2/6\)。
- \(n=4\)：\(j=0\) 时系数为 \(h^4/5\)，\(j=2\) 时为 \(h^4/30\)。

后文三点、五点公式的误差项就是它的特例，不需要再逐项 Taylor 展开。

### 10.2.4 权的计算

由 \(L_k\) 的定义，对 \(k\ne j\) 有

\[
L_k'(x_j)=\frac{1}{x_k-x_j}
\prod_{\substack{m=0\\ m\ne k,j}}^{n}\frac{x_j-x_m}{x_k-x_m}.
\]

对等距节点，\((x_j-x_m)/(x_k-x_m)=(j-m)/(k-m)\)，于是

\[
w_k=L_k'(x_j)=\frac{1}{h(k-j)}
\prod_{\substack{m=0\\ m\ne k,j}}^{n}\frac{j-m}{k-m}.
\]

另外，由 \(\sum_k L_k(x)=1\) 得 \(\sum_k L_k'(x)=0\)，所以

\[
L_j'(x_j)=-\sum_{k\ne j}L_k'(x_j).
\]

实际计算时只需算 \(n\) 个 \(L_k'(x_j)\)，最后一个用"权之和为零"补出，既省一次求值也自动满足一致性。

## 10.3 三点公式

### 10.3.1 基函数的导数

取 \(n=2\)，三个节点 \(x_0,x_1,x_2\)。基函数为

\[
L_0(x)=\frac{(x-x_1)(x-x_2)}{(x_0-x_1)(x_0-x_2)},
\]

求导得

\[
L_0'(x)=\frac{2x-x_1-x_2}{(x_0-x_1)(x_0-x_2)}.
\]

同理

\[
L_1'(x)=\frac{2x-x_0-x_2}{(x_1-x_0)(x_1-x_2)},
\qquad
L_2'(x)=\frac{2x-x_0-x_1}{(x_2-x_0)(x_2-x_1)}.
\]

代入 \((n+1)\) 点公式，取 \(n=2\)：

\[
f'(x_j)=\sum_{k=0}^{2}f(x_k)L_k'(x_j)
+\frac{f'''(\xi_j)}{6}\prod_{k\ne j}(x_j-x_k),
\qquad j=0,1,2.
\]

下面取等距节点 \(x_1=x_0+h\)，\(x_2=x_0+2h\)，逐个算。

### 10.3.2 三种形式

**左端点 \(x_j=x_0\)。** 三个权为

\[
L_0'(x_0)=\frac{-3h}{2h^2}=-\frac{3}{2h},
\qquad
L_1'(x_0)=\frac{-2h}{-h^2}=\frac{2}{h},
\qquad
L_2'(x_0)=\frac{-h}{2h^2}=-\frac{1}{2h}.
\]

误差系数为

\[
\frac{1}{6}(x_0-x_1)(x_0-x_2)=\frac{1}{6}(-h)(-2h)=\frac{h^2}{3}.
\]

所以

\[
\boxed{\
f'(x_0)=\frac{1}{2h}\big[-3f(x_0)+4f(x_0+h)-f(x_0+2h)\big]
+\frac{h^2}{3}f'''(\xi_0)
\ }
\]

**中点 \(x_j=x_1\)。** 同理

\[
L_0'(x_1)=-\frac{1}{2h},\qquad
L_1'(x_1)=0,\qquad
L_2'(x_1)=\frac{1}{2h},
\]

误差系数为 \((h)(-h)/6=-h^2/6\)，故

\[
\boxed{\
f'(x_0)=\frac{1}{2h}\big[f(x_0+h)-f(x_0-h)\big]
-\frac{h^2}{6}f'''(\xi_1)
\ }
\]

这正是 10.1.4 的中心差商。

**右端点 \(x_j=x_2\)。** 权为

\[
L_0'(x_2)=\frac{1}{2h},\qquad
L_1'(x_2)=-\frac{2}{h},\qquad
L_2'(x_2)=\frac{3}{2h},
\]

误差系数仍为 \(h^2/3\)，故

\[
\boxed{\
f'(x_0)=\frac{1}{2h}\big[f(x_0-2h)-4f(x_0-h)+3f(x_0)\big]
+\frac{h^2}{3}f'''(\xi_2)
\ }
\]

右端点公式也可以由左端点公式把 \(h\) 换成 \(-h\) 直接得到。

### 10.3.3 中点与端点的比较

三个公式都是 \(O(h^2)\)，但误差系数不同：

| 公式 | 用到的点 | 误差主项 | 函数求值次数 |
| --- | --- | --- | --- |
| 左端点 | \(x_0,\ x_0+h,\ x_0+2h\) | \(+\dfrac{h^2}{3}f'''(\xi)\) | 3 |
| 中点 | \(x_0-h,\ x_0,\ x_0+h\) | \(-\dfrac{h^2}{6}f'''(\xi)\) | 2 |
| 右端点 | \(x_0-2h,\ x_0-h,\ x_0\) | \(+\dfrac{h^2}{3}f'''(\xi)\) | 3 |

中点的误差系数只有端点的**一半**，而且只需要两次函数求值（\(x_0\) 处的值不用算）。原因是中点用了 \(x_0\) 两侧的信息，误差主项部分抵消；端点只用单侧信息，抵消不充分。

这就是"能中心差分就不要单侧差分"的定量依据。只有边界上没有两侧数据时，才被迫用端点公式。

### 10.3.4 五点公式

同样由 \((n+1)\) 点公式取 \(n=4\)，可得两个常用五点公式。

**五点端点公式**（节点 \(x_0,x_0+h,\dots,x_0+4h\)）：

\[
f'(x_0)=\frac{1}{12h}\big[-25f(x_0)+48f(x_0+h)-36f(x_0+2h)
+16f(x_0+3h)-3f(x_0+4h)\big]
+\frac{h^4}{5}f^{(5)}(\xi)
\]

**五点中点公式**（节点 \(x_0-2h,\dots,x_0+2h\)）：

\[
f'(x_0)=\frac{1}{12h}\big[f(x_0-2h)-8f(x_0-h)+8f(x_0+h)-f(x_0+2h)\big]
+\frac{h^4}{30}f^{(5)}(\xi)
\]

误差系数可直接用 10.2.3 的公式核对：\(n=4\) 时，端点 \(j=0\) 的系数是 \(h^4/5\)，中点 \(j=2\) 的系数是 \(h^4/30\)——与上面完全一致。

### 10.3.5 数值对比

对 \(f(x)=xe^x\)，在 \(x=2.0\) 处 \(f'(2)=3e^2=22.167168\)。各公式的绝对误差：

| 公式 | \(h\) | 绝对误差 |
| --- | --- | --- |
| 三点端点 | 0.1 | \(1.35\times10^{-1}\) |
| 三点端点 | \(-0.1\) | \(1.13\times10^{-1}\) |
| 三点中点 | 0.1 | \(6.16\times10^{-2}\) |
| 三点中点 | 0.2 | \(2.47\times10^{-1}\) |
| 五点中点 | 0.1 | \(1.69\times10^{-4}\) |

三点中点比三点端点好一个量级；五点中点又把误差降了约三个量级。但五点公式每次要算四个新函数值，而且对 \(f^{(5)}\) 有要求——精度是用求值次数和光滑性换来的。

### 10.3.6 MATLAB 实现

```matlab
function d = three_point(f, x0, h, side)
% 三点公式求 f'(x0)，side 取 'mid'、'forward'、'backward'
% 三者截断误差均为 O(h^2)
switch side
    case 'mid'      % 中点公式，误差 -h^2/6 * f'''
        d = (f(x0 + h) - f(x0 - h)) / (2*h);
    case 'forward'  % 前向端点公式，误差 +h^2/3 * f'''
        d = (-3*f(x0) + 4*f(x0 + h) - f(x0 + 2*h)) / (2*h);
    case 'backward' % 后向端点公式，误差 +h^2/3 * f'''
        d = (f(x0 - 2*h) - 4*f(x0 - h) + 3*f(x0)) / (2*h);
    otherwise
        error('side 必须是 mid、forward 或 backward');
end
end
```

## 10.4 高阶导数近似

### 10.4.1 二阶中心差分

设 \(f\in C^4[x_0-h,x_0+h]\)。把 \(f(x_0+h)\) 与 \(f(x_0-h)\) 都在 \(x_0\) 处展开到四阶：

\[
f(x_0+h)=f(x_0)+f'(x_0)h+\frac{f''(x_0)}{2}h^2
+\frac{f'''(x_0)}{6}h^3+\frac{f^{(4)}(\xi_1)}{24}h^4,
\]

\[
f(x_0-h)=f(x_0)-f'(x_0)h+\frac{f''(x_0)}{2}h^2
-\frac{f'''(x_0)}{6}h^3+\frac{f^{(4)}(\xi_{-1})}{24}h^4.
\]

两式相加，一阶项和三阶项抵消：

\[
f(x_0+h)+f(x_0-h)=2f(x_0)+f''(x_0)h^2
+\frac{h^4}{24}\big[f^{(4)}(\xi_1)+f^{(4)}(\xi_{-1})\big].
\]

解出 \(f''(x_0)\)：

\[
f''(x_0)=\frac{f(x_0-h)-2f(x_0)+f(x_0+h)}{h^2}
-\frac{h^2}{24}\big[f^{(4)}(\xi_1)+f^{(4)}(\xi_{-1})\big].
\]

因为 \(f^{(4)}\) 连续，它在两点的平均值介于二者之间，由介值定理存在 \(\xi\in(x_0-h,x_0+h)\)，使

\[
f^{(4)}(\xi)=\frac{f^{(4)}(\xi_1)+f^{(4)}(\xi_{-1})}{2}.
\]

于是得到**二阶导数中点公式**：

\[
\boxed{\
f''(x_0)=\frac{f(x_0-h)-2f(x_0)+f(x_0+h)}{h^2}
-\frac{h^2}{12}f^{(4)}(\xi)
\ }
\]

误差为 \(O(h^2)\)。注意它不是 \(O(h^4)\)：分子中的 \(h^2\) 被分母的 \(h^2\) 除掉，剩下 \(h^2\) 量级的误差。

!!! note "与第 11 章的呼应"
    第 11 章推导 Simpson 公式的 \(h^5/90\) 误差时，用的正是这个二阶导数中点公式（见 [第 11 章](ch11.md) 11.3.2）。Simpson 公式"对三次多项式精确"的结论，本质上来自这里的 \(f^{(4)}\) 余项。

### 10.4.2 前向二阶差分

若只有右侧数据，可用

\[
f''(x_0)\approx\frac{f(x_0+2h)-2f(x_0+h)+f(x_0)}{h^2}.
\]

展开验证：

\[
f(x_0+2h)-2f(x_0+h)+f(x_0)
=f''(x_0)h^2+f'''(x_0)h^3+O(h^4),
\]

除以 \(h^2\) 后误差为 \(O(h)\)。单侧二阶差分只有一阶精度，比中心差分低一阶。

### 10.4.3 差分表法

对等距节点 \(x_i=x_0+ih\)，记 \(f_i=f(x_i)\)。前向差分定义为

\[
\Delta f_i=f_{i+1}-f_i,
\qquad
\Delta^k f_i=\Delta^{k-1}f_{i+1}-\Delta^{k-1}f_i.
\]

差分表按对角线逐层生成：

| \(f_i\) | \(\Delta f_i\) | \(\Delta^2 f_i\) | \(\Delta^3 f_i\) | \(\Delta^4 f_i\) |
| --- | --- | --- | --- | --- |
| \(f_0\) | | | | |
| \(f_1\) | \(\Delta f_0\) | | | |
| \(f_2\) | \(\Delta f_1\) | \(\Delta^2 f_0\) | | |
| \(f_3\) | \(\Delta f_2\) | \(\Delta^2 f_1\) | \(\Delta^3 f_0\) | |
| \(f_4\) | \(\Delta f_3\) | \(\Delta^2 f_2\) | \(\Delta^3 f_1\) | \(\Delta^4 f_0\) |

差分与导数通过二项式展开联系：

\[
\Delta^k f_i=\sum_{j=0}^{k}(-1)^{k-j}\binom{k}{j}f_{i+j}.
\]

对每个 \(f_{i+j}\) 在 \(x_i\) 处作 Taylor 展开，按 \(h^m\) 合并：

\[
\Delta^k f_i=\sum_{m\ge 0}\frac{h^m}{m!}f^{(m)}(x_i)
\sum_{j=0}^{k}(-1)^{k-j}\binom{k}{j}j^m.
\]

内层和有一个标准性质：

\[
\sum_{j=0}^{k}(-1)^{k-j}\binom{k}{j}j^m=
\begin{cases}
0, & m<k,\\
k!, & m=k.
\end{cases}
\]

（这是第二类 Stirling 数与差分的关系；也可由 \((e^t-1)^k\) 的展开直接看出。）因此

\[
\Delta^k f_i=h^k f^{(k)}(x_i)+O(h^{k+1}),
\]

从而

\[
\boxed{\
f^{(k)}(x_i)=\frac{\Delta^k f_i}{h^k}+O(h)
\ }
\]

**差分表法**就是：把表中第 \(k\) 列的对角元除以 \(h^k\)，得到 \(x_i\) 处 \(k\) 阶导数的近似。它只需要加减法，适合手算和等距数据；但误差只有 \(O(h)\)。

若改用中心差分

\[
\delta^2 f_i=f_{i+1}-2f_i+f_{i-1},
\]

则

\[
\delta^2 f_i=h^2f''(x_i)+\frac{h^4}{12}f^{(4)}(x_i)+O(h^6),
\]

于是

\[
\boxed{\
f''(x_i)=\frac{\delta^2 f_i}{h^2}+O(h^2)
\ }
\]

中心差分把精度提高了一阶，代价是需要两侧数据。一般地，对称中心差分近似偶数阶导数都有 \(O(h^2)\) 精度。

### 10.4.4 奇数阶中心差分

三阶导数可用四点对称格式：

\[
f'''(x_i)=\frac{f_{i+2}-2f_{i+1}+2f_{i-1}-f_{i-2}}{2h^3}+O(h^2).
\]

验证时把四个 Taylor 展开相加：常数项、\(h\) 项、\(h^2\) 项、\(h^4\) 项都抵消，只剩 \(2h^3f'''\) 和更高阶项，除以 \(2h^3\) 即得。奇数阶中心差分的误差也是 \(O(h^2)\)。

### 10.4.5 数值例子

对 \(f(x)=xe^x\)，已知

| \(x\) | 1.8 | 1.9 | 2.0 | 2.1 | 2.2 |
| --- | --- | --- | --- | --- | --- |
| \(f(x)\) | 10.889365 | 12.703199 | 14.778112 | 17.148957 | 19.855030 |

真值 \(f''(2)=4e^2=29.556224\)。用二阶中点公式：

\[
f''(2)\approx\frac{f(1.9)-2f(2.0)+f(2.1)}{0.01}=29.593200,
\]

误差为 \(-3.70\times10^{-2}\)；取 \(h=0.2\)：

\[
f''(2)\approx\frac{f(1.8)-2f(2.0)+f(2.2)}{0.04}=29.704275,
\]

误差为 \(-1.48\times10^{-1}\)。\(h\) 从 0.1 增到 0.2，误差约增到四倍，符合 \(O(h^2)\)。

## 10.5 舍入误差的影响

### 10.5.1 总误差

以三点中点公式为例。设 \(f\in C^3\)，实际计算得到的是 \(\tilde f(x_0\pm h)\)，与真值的关系为

\[
f(x_0+h)=\tilde f(x_0+h)+e(x_0+h),
\qquad
f(x_0-h)=\tilde f(x_0-h)+e(x_0-h).
\]

把 \(f=\tilde f+e\) 代入中点公式：

\[
\frac{\tilde f(x_0+h)-\tilde f(x_0-h)}{2h}
=\frac{f(x_0+h)-f(x_0-h)}{2h}
-\frac{e(x_0+h)-e(x_0-h)}{2h}.
\]

再用中点公式的截断误差式，得

\[
f'(x_0)-\frac{\tilde f(x_0+h)-\tilde f(x_0-h)}{2h}
=\frac{e(x_0+h)-e(x_0-h)}{2h}
-\frac{h^2}{6}f'''(\xi).
\]

设 \(|e(x_0\pm h)|\le\varepsilon\)，\(|f'''|\le M\)，则

\[
\boxed{\
\left|f'(x_0)-\frac{\tilde f(x_0+h)-\tilde f(x_0-h)}{2h}\right|
\le \frac{\varepsilon}{h}+\frac{Mh^2}{6}
\ }
\]

右端第一项是**舍入误差**，第二项是**截断误差**。前者随 \(h\) 减小而增大，后者随 \(h\) 减小而减小。

### 10.5.2 最优步长

记总误差上界为

\[
e(h)=\frac{\varepsilon}{h}+\frac{Mh^2}{6}.
\]

求导：

\[
e'(h)=-\frac{\varepsilon}{h^2}+\frac{Mh}{3}.
\]

令 \(e'(h)=0\)：

\[
\frac{Mh}{3}=\frac{\varepsilon}{h^2}
\quad\Longrightarrow\quad
h^3=\frac{3\varepsilon}{M}
\quad\Longrightarrow\quad
\boxed{\ h^*=\left(\frac{3\varepsilon}{M}\right)^{1/3}\ }
\]

又 \(e''(h)=2\varepsilon/h^3+M/3>0\)，故这是极小值点。

把 \(h^*\) 代回，得到该误差界下的最小总误差：

\[
e(h^*)=\frac{\varepsilon}{h^*}+\frac{M(h^*)^2}{6}
=\frac{3^{2/3}}{2}M^{1/3}\varepsilon^{2/3}
\approx 1.04\,M^{1/3}\varepsilon^{2/3}.
\]

值得注意的是：**最优也只能达到 \(\varepsilon^{2/3}\) 量级**，而不是 \(\varepsilon\)。这就是数值微分不稳定的定量表现——再好的步长也救不回全部精度。

### 10.5.3 一般阶公式

若截断误差为 \(Mh^p/C\)，总误差为

\[
e(h)=\frac{\varepsilon}{h}+\frac{Mh^p}{C}.
\]

求导并令其为零：

\[
-\frac{\varepsilon}{h^2}+\frac{pMh^{p-1}}{C}=0
\quad\Longrightarrow\quad
h^{p+1}=\frac{C\varepsilon}{pM},
\]

即

\[
\boxed{\ h^*=\left(\frac{C\varepsilon}{pM}\right)^{1/(p+1)}
\sim \varepsilon^{1/(p+1)}\ }
\]

两个常用特例：

- 前向差商 \(p=1\)，\(C=2\)：\(h^*=\sqrt{2\varepsilon/M}\sim\varepsilon^{1/2}\)。
- 中心差商 \(p=2\)，\(C=6\)：\(h^*=(3\varepsilon/M)^{1/3}\sim\varepsilon^{1/3}\)。

阶数越高，最优步长随 \(\varepsilon\) 下降得越慢，可用的 \(h\) 范围越大——这是高阶公式的另一个好处。

### 10.5.4 正弦函数的例子

用中点公式近似 \(f'(0.9)\)，\(f(x)=\sin x\)，真值 \(\cos0.9=0.62161\)。函数值只给到五位小数，取 \(\varepsilon=5\times10^{-6}\)。在 \([0.8,1.0]\) 上

\[
M=\max|f'''|=\max|\cos x|=\cos0.8\approx0.69671.
\]

理论最优步长

\[
h^*=\left(\frac{3\times5\times10^{-6}}{0.69671}\right)^{1/3}\approx0.028.
\]

实际计算结果：

| \(h\) | 近似值 | 误差（近似值减真值） |
| --- | --- | --- |
| 0.001 | 0.62500 | 0.00339 |
| 0.002 | 0.62250 | 0.00089 |
| 0.005 | 0.62200 | 0.00039 |
| 0.010 | 0.62150 | \(-0.00011\) |
| 0.020 | 0.62150 | \(-0.00011\) |
| 0.050 | 0.62140 | \(-0.00021\) |
| 0.100 | 0.62055 | \(-0.00106\) |

误差在 \(h=0.01\sim0.02\) 附近最小，与 \(h^*\approx0.028\) 相符。\(h=0.001\) 时误差反而增大到 \(3.39\times10^{-3}\)，这就是舍入误差 \(\varepsilon/h\) 开始占主导。

!!! warning "最优步长在实践中不可直接使用"
    公式 \(h^*=(3\varepsilon/M)^{1/3}\) 需要知道 \(M=\max|f'''|\)，而实际计算中往往没有这个信息。它的价值在于给出**数量级**：不要盲目把 \(h\) 取到 \(10^{-12}\)，否则结果会被舍入误差吞掉。

### 10.5.5 不稳定性

所有数值微分公式都要除以 \(h\) 的某个幂：

- 一阶导数除以 \(h\)；
- 二阶导数除以 \(h^2\)；
- \(k\) 阶导数除以 \(h^k\)。

除以小数会放大误差。设函数值有扰动 \(\varepsilon\)，则 \(k\) 阶导数的舍入误差量级为 \(\varepsilon/h^k\)。因此：

- 数值微分是**不稳定**问题：减小 \(h\) 降低截断误差，却同时放大舍入误差；
- 阶数越高，放大越厉害，高阶导数的数值计算尤其困难；
- 这也是为什么微分方程数值解中，通常避免直接对数据做数值微分，而用积分形式或弱形式。

## 10.6 Richardson 外推

### 10.6.1 误差展开

设某个近似公式的误差可以展开成 \(h\) 的幂级数：

\[
M=N_1(h)+K_1h^{\alpha_1}+K_2h^{\alpha_2}+\cdots,
\qquad 0<\alpha_1<\alpha_2<\cdots
\]

其中 \(M\) 是要求的精确值（例如某个导数值），\(K_i\) 与 \(h\) 无关。把 \(h\) 换成 \(h/2\)：

\[
M=N_1(h/2)+K_1\left(\frac{h}{2}\right)^{\alpha_1}
+K_2\left(\frac{h}{2}\right)^{\alpha_2}+\cdots
\]

两式相减可以消去 \(M\)，但要消去的是 \(K_1\) 项。

### 10.6.2 消去一阶项

先看最简单的情形 \(\alpha_1=1\)。计算 \(2N_1(h/2)-N_1(h)\)：

\[
\begin{aligned}
2N_1(h/2)-N_1(h)
&=2M-2K_1\frac{h}{2}-2K_2\frac{h^2}{4}-\cdots
-M+K_1h+K_2h^2+\cdots\\
&=M+\frac{K_2}{2}h^2+\frac{3K_3}{4}h^3+\cdots
\end{aligned}
\]

一阶项果然消掉了。定义

\[
\boxed{\
N_2(h)=2N_1(h/2)-N_1(h)
=N_1(h/2)+\frac{N_1(h/2)-N_1(h)}{2^1-1}
\ }
\]

则

\[
M=N_2(h)+O(h^2).
\]

也就是说，用两个一阶近似做一次简单的外推，就得到了二阶近似，而且没有增加新的函数求值。

### 10.6.3 一般递推

设当前近似 \(N_{j-1}(h)\) 的误差展开为

\[
M=N_{j-1}(h)+K_1h^{\alpha_1}+K_2h^{\alpha_2}+\cdots
\]

其中 \(\alpha_1\) 是当前的最低幂次。定义

\[
\boxed{\
N_j(h)=N_{j-1}(h/2)
+\frac{N_{j-1}(h/2)-N_{j-1}(h)}{2^{\alpha_1}-1}
\ }
\]

**证明消项。** 把展开代入：

\[
N_j(h)=M-K_1\left(\frac{h}{2}\right)^{\alpha_1}
+\frac{K_1h^{\alpha_1}\left(1-2^{-\alpha_1}\right)}{2^{\alpha_1}-1}
+O(h^{\alpha_2}).
\]

利用恒等式

\[
1-2^{-\alpha_1}=\frac{2^{\alpha_1}-1}{2^{\alpha_1}},
\]

第二项的系数化为 \(K_1h^{\alpha_1}2^{-\alpha_1}\)，与第一项恰好抵消。因此

\[
M=N_j(h)+O(h^{\alpha_2}),
\]

即新公式的误差阶升到下一个幂次 \(\alpha_2\)。

### 10.6.4 外推表

取步长序列 \(h_k=h_0/2^{k-1}\)，把不同步长、不同外推列排成三角表。记 \(D_{k,1}=N_1(h_k)\)，则

\[
\boxed{\
D_{k,j}=D_{k,j-1}
+\frac{D_{k,j-1}-D_{k-1,j-1}}{2^{\alpha_{j-1}}-1},
\qquad k\ge j\ge 2
\ }
\]

其中 \(\alpha_{j-1}\) 是第 \(j-1\) 列尚未消去的最低幂次。

对**中心差商**，误差只含偶次幂：

\[
\frac{f(x_0+h)-f(x_0-h)}{2h}
=f'(x_0)+\frac{h^2}{6}f'''(x_0)
+\frac{h^4}{120}f^{(5)}(x_0)+\cdots
\]

所以 \(\alpha_j=2j\)，分母为

\[
2^{2(j-1)}-1=4^{j-1}-1.
\]

递推变成

\[
D_{k,j}=D_{k,j-1}
+\frac{D_{k,j-1}-D_{k-1,j-1}}{4^{j-1}-1}.
\]

这与第 11 章 Romberg 积分的递推公式**完全同构**（见 [第 11 章](ch11.md) 11.6.2）：Romberg 消的是复合梯形误差中的 \(h^2,h^4,\dots\)，这里消的是中心差商误差中的 \(h^2,h^4,\dots\)。两者都是 Richardson 外推，只是"原料"不同——一个是积分近似值，一个是导数近似值。

对**前向差商**，误差含所有整数幂 \(h,h^2,h^3,\dots\)，所以分母依次是

\[
2^1-1=1,\qquad 2^2-1=3,\qquad 2^3-1=7,\qquad 2^4-1=15,\dots
\]

第一列外推的系数是 1，之后与 Romberg 的 \(3,15,63,\dots\) 不同。

### 10.6.5 例子：对数函数的导数

仍取 \(f(x)=\ln x\)，\(x_0=1.8\)。前向差商给出

\[
N_1(0.1)=0.5406722,\qquad N_1(0.05)=0.5479795.
\]

做一次外推：

\[
N_2(0.1)=N_1(0.05)+\frac{N_1(0.05)-N_1(0.1)}{2^1-1}
=0.5479795+0.0073073=0.5552868.
\]

真值 \(f'(1.8)=0.5555556\)，外推值的误差为

\[
0.5555556-0.5552868=2.7\times10^{-4}.
\]

对照原始误差：\(h=0.1\) 时约 \(1.5\times10^{-2}\)，\(h=0.05\) 时约 \(7.7\times10^{-3}\)。一次外推把误差降了约 30 倍，而函数求值次数没有增加——只用了已有的两个近似值。

### 10.6.6 MATLAB 实现

中心差商版 Richardson 外推：

```matlab
function [D, h] = richardson_central(f, x0, h0, n)
% 对中心差商做 Richardson 外推，返回 n×n 表 D
% D(k,1) 是步长 h0/2^(k-1) 的中心差商
% D(k,j) 依次消去 h^2, h^4, ...，精度为 O(h^(2j))
D = zeros(n, n);
h = h0;
for k = 1:n
    D(k,1) = (f(x0 + h) - f(x0 - h)) / (2*h);
    for j = 2:k
        % 中心差分误差幂次为 2,4,6,...，分母为 4^(j-1)-1
        D(k,j) = D(k,j-1) + (D(k,j-1) - D(k-1,j-1)) / (4^(j-1) - 1);
    end
    h = h/2;
end
end
```

单独的中心差商与三点公式实现：

```matlab
function d = central_diff(f, x0, h)
% 中心差商：f'(x0) ≈ [f(x0+h) - f(x0-h)] / (2h)
% 截断误差 O(h^2)；h 过小会被舍入误差 ε/h 淹没
d = (f(x0 + h) - f(x0 - h)) / (2*h);
end
```

!!! warning "外推不是万能的"
    外推要求误差确实能展成 \(h\) 的幂级数。若函数不够光滑（例如只有二阶连续导数），或者误差中含 \(h\log h\)、非整数幂，用错 \(\alpha\) 不仅不能消项，还可能放大误差。此外，外推表越往右，越依赖左边相邻项，舍入误差也会沿表传播。实际使用时应当比较最后两个对角元：若二者之差仍大于容差，说明尚未收敛，或者舍入误差已经占主导。

## 坑与陷阱

!!! danger "八条"
    1. **步长不是越小越好**：总误差约为 \(\varepsilon/h+Mh^p/C\)，最优步长 \(h^*\sim\varepsilon^{1/(p+1)}\)。把 \(h\) 取到 \(10^{-12}\) 只会得到噪声。
    2. **中心差商是二阶，不是一阶**：误差主项是 \(-h^2f'''/6\)；前向、后向差商才是一阶，误差主项为 \(-hf''/2\)。
    3. **端点公式的误差系数是 \(h^2/3\)，中点是 \(-h^2/6\)**：中点误差约为端点的一半，而且少算一次函数值。能用中点就不要用端点。
    4. **二阶中心差分的误差是 \(O(h^2)\)，不是 \(O(h^4)\)**：分子 \(f(x-h)-2f(x)+f(x+h)\) 本身的误差是 \(O(h^4)\)，除以 \(h^2\) 后只剩 \(O(h^2)\)。
    5. **差分表 \(\Delta^k f_i/h^k\) 只有 \(O(h)\)**：它方便手算，但不要误以为是高阶公式；要 \(O(h^2)\) 得用中心差分。
    6. **高阶导数对舍入误差更敏感**：误差放大约 \(\varepsilon/h^k\)，\(k\) 越大越不稳定。逐阶用差分表求导会累积误差。
    7. **外推只能消去展开式中真实存在的幂次**：中心差商消 \(h^2,h^4,\dots\)，前向差商消 \(h,h^2,\dots\)。用错幂次会适得其反。
    8. **数值微分是不稳定问题**：这是全书第一个不稳定方法。不要把它当作"万能求导器"，能解析求导就解析求导，能用积分形式就用积分形式。

## 速览

1. 前向差商：\([f(x_0+h)-f(x_0)]/h\)，误差 \(-hf''(\xi)/2\)，一阶。
2. 后向差商：\([f(x_0)-f(x_0-h)]/h\)，误差 \(+hf''(\xi)/2\)，一阶。
3. 中心差商：\([f(x_0+h)-f(x_0-h)]/(2h)\)，误差 \(-h^2f'''(\xi)/6\)，二阶。
4. \((n+1)\) 点公式：权为 \(L_k'(x_j)\)，误差为 \(f^{(n+1)}(\xi_j)\prod_{k\ne j}(x_j-x_k)/(n+1)!\)。
5. 等距误差系数：\(E_j=(-1)^{n-j}h^n f^{(n+1)}(\xi_j)/[(n+1)\binom{n}{j}]\)。
6. 三点公式：中点 \([f_1-f_{-1}]/(2h)-h^2f'''/6\)；端点 \([-3f_0+4f_1-f_2]/(2h)+h^2f'''/3\)。
7. 五点公式：中点误差 \(h^4f^{(5)}/30\)，端点误差 \(h^4f^{(5)}/5\)。
8. 二阶中心差分：\([f(x-h)-2f(x)+f(x+h)]/h^2\)，误差 \(-h^2f^{(4)}(\xi)/12\)。
9. 总误差 \(\varepsilon/h+Mh^p/C\)，最优 \(h^*=(C\varepsilon/(pM))^{1/(p+1)}\)。
10. Richardson：\(N_j(h)=N_{j-1}(h/2)+[N_{j-1}(h/2)-N_{j-1}(h)]/(2^{\alpha_{j-1}}-1)\)，中心差商的分母为 \(4^{j-1}-1\)，与 Romberg 同构。
