## 2.1 微积分复习

求根方法的每一步几乎都靠这几条定理。先把它们串成一条逻辑链：**极值定理 → Rolle 定理 → 中值定理**；**介值定理**负责"存在"，**Taylor 定理**负责"误差"。

### 2.1.1 极值定理

**定理（极值定理）.** 若 \(f\in C[a,b]\)，则 \(f\) 在 \([a,b]\) 上有界，并且存在 \(u,v\in[a,b]\)，使

\[
f(u)=\max_{x\in[a,b]}f(x),\qquad f(v)=\min_{x\in[a,b]}f(x).
\]

**证明.** 记 \(M=\sup_{[a,b]}f\)。先证 \(M<\infty\)：若 \(f\) 无上界，则可取 \(x_n\in[a,b]\) 使 \(f(x_n)>n\)。由 Bolzano–Weierstrass 定理，存在子列 \(x_{n_k}\to x_*\in[a,b]\)；连续性给出 \(f(x_{n_k})\to f(x_*)\)，与 \(f(x_{n_k})\to\infty\) 矛盾。

再取 \(y_n\in[a,b]\) 使 \(f(y_n)\to M\)。同样取收敛子列 \(y_{n_k}\to u\in[a,b]\)，连续性给出

\[
f(u)=\lim_{k\to\infty}f(y_{n_k})=M.
\]

最小值对 \(-f\) 用同样论证。\(\blacksquare\)

!!! note "为什么必须闭区间"
    \(f(x)=x\) 在 \((0,1)\) 上连续但取不到上确界 \(1\)；\(f(x)=1/x\) 在 \((0,1]\) 上无界。极值定理的两个条件——**闭**与**有界**——缺一不可。

### 2.1.2 Rolle 定理

**定理（Rolle）.** 设 \(f\in C[a,b]\)，在 \((a,b)\) 内可导，且 \(f(a)=f(b)\)。则存在 \(c\in(a,b)\)，使

\[
f'(c)=0.
\]

**证明.** 由极值定理，\(f\) 在 \([a,b]\) 上取得最大值 \(M\) 与最小值 \(m\)。

- 若 \(M=m\)，则 \(f\) 为常数，任取 \(c\in(a,b)\) 都有 \(f'(c)=0\)。
- 若 \(M>m\)，因为 \(f(a)=f(b)\)，最大值与最小值不可能同时只在两个端点取得。于是至少有一个极值点在内部 \(c\in(a,b)\)。由 Fermat 引理（内部极值点处导数为零），\(f'(c)=0\)。

\(\blacksquare\)

### 2.1.3 中值定理

**定理（Lagrange 中值定理）.** 设 \(f\in C[a,b]\)，在 \((a,b)\) 内可导。则存在 \(c\in(a,b)\)，使

\[
f'(c)=\frac{f(b)-f(a)}{b-a}.
\]

**证明.** 构造辅助函数

\[
h(x)=f(x)-f(a)-\frac{f(b)-f(a)}{b-a}(x-a).
\]

它满足 \(h(a)=h(b)=0\)，且在 \((a,b)\) 内可导。由 Rolle 定理，存在 \(c\in(a,b)\) 使 \(h'(c)=0\)，即

\[
f'(c)-\frac{f(b)-f(a)}{b-a}=0.
\]

\(\blacksquare\)

**常用推论.** 若 \(|f'(x)|\le M\) 在区间上成立，则对该区间内任意 \(x,y\)，

\[
|f(x)-f(y)|\le M|x-y|.
\]

这条推论是后面所有"压缩""误差不放大"论证的来源。

### 2.1.4 介值定理

**定理（介值定理）.** 设 \(f\in C[a,b]\)，且 \(K\) 介于 \(f(a)\) 与 \(f(b)\) 之间。则存在 \(c\in(a,b)\)，使 \(f(c)=K\)。

**证明.** 只证 \(f(a)<K<f(b)\) 的情形，其余情形对 \(-f\) 或交换端点即可。令

\[
S=\{x\in[a,b]:f(x)\le K\},\qquad c=\sup S.
\]

因为 \(a\in S\)，\(S\) 非空；又 \(S\subset[a,b]\)，故 \(c\in[a,b]\)。

若 \(f(c)<K\)，由连续性存在 \(\delta>0\)，使 \(f(x)<K\) 对 \(x\in[c,c+\delta)\cap[a,b]\) 成立。这些点都属于 \(S\)，与 \(c\) 是上确界矛盾（注意 \(f(b)>K\)，所以 \(c\ne b\)）。

若 \(f(c)>K\)，同样存在 \(\delta>0\)，使 \(f(x)>K\) 对 \(x\in(c-\delta,c]\) 成立。于是 \(c-\delta\) 也是 \(S\) 的上界，与 \(c\) 是最小上界矛盾（注意 \(f(a)<K\)，所以 \(c\ne a\)）。

因此只能有 \(f(c)=K\)。\(\blacksquare\)

!!! note "存在性定理的共同套路"
    二分法用介值定理保证"括号里一定有根"；不动点存在性用介值定理保证"\(g(x)-x\) 一定穿过零"。它们都不保证唯一性，唯一性要靠单调性或压缩条件。

### 2.1.5 带 Lagrange 余项的 Taylor 定理

**定理.** 设 \(f\in C^{n+1}[a,b]\)，\(x_0\in[a,b]\)。对任意 \(x\in[a,b]\)，存在 \(\xi\) 介于 \(x_0\) 与 \(x\) 之间，使

\[
f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k+\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}.
\]

证明方法是固定 \(x\)，对余项构造辅助函数并反复使用 Rolle 定理。Newton 法只用到 \(n=1\) 的情形：

\[
f(x)=f(x_0)+f'(x_0)(x-x_0)+\frac{f''(\xi)}{2}(x-x_0)^2.
\]

这条一阶展开是 Newton 法"推导"与"二次收敛证明"的共同发动机。

### 2.1.6 这些定理在后文的分工

| 定理 | 一句话 | 用在哪里 |
| --- | --- | --- |
| 极值定理 | 闭区间连续函数取得最大最小值 | Rolle 的证明、误差合并上界 |
| Rolle 定理 | 两端相等则内部有水平切线 | 证明中值定理、Taylor 余项 |
| 中值定理 | 割线斜率等于某点切线斜率 | 压缩映射、误差估计、收敛阶 |
| 介值定理 | 连续函数取遍中间值 | 二分法存在性、不动点存在性 |
| Taylor 定理 | 多项式加余项逼近函数 | Newton 推导与二次收敛 |

## 2.2 求根问题与二分法

### 2.2.1 问题的提法

求方程

\[
f(x)=0
\]

的根，也叫函数 \(f\) 的零点。非线性方程通常没有闭式解，只能迭代逼近。

最朴素的存在性判据是**括号条件**：若 \(f\in C[a,b]\) 且

\[
f(a)f(b)<0,
\]

则由介值定理，\((a,b)\) 内至少有一个根。注意这只是"至少一个"：可能多个，也可能因为重根而不变号（例如 \(f(x)=x^2\) 在 \([-1,1]\) 上只有一个偶重根，但两端同号，二分法根本无法启动）。

### 2.2.2 二分法

每一步把括号区间对半砍，保留"函数值异号"的那一半。设当前区间为 \([a,b]\)，取中点 \(p=(a+b)/2\)：

- 若 \(f(a)f(p)<0\)，根在 \([a,p]\)，令 \(b=p\)；
- 若 \(f(p)f(b)<0\)，根在 \([p,b]\)，令 \(a=p\)；
- 若 \(f(p)=0\)，恰好命中。

```matlab
function [p, iter, ok] = bisect(f, a, b, tol, maxit)
% 二分法求 f(x)=0 在 [a,b] 内的一个根
% f    函数句柄
% a,b  初始括号，要求 f(a)*f(b) < 0
% tol  区间半长容差；maxit 最大迭代次数
if nargin < 4, tol = 1e-10; end
if nargin < 5, maxit = 200; end

fa = f(a); fb = f(b);
if fa * fb >= 0
    error('二分法要求 f(a) 与 f(b) 异号');
end

for iter = 1:maxit
    p = (a + b) / 2;          % 中点
    fp = f(p);
    if fp == 0 || (b - a) / 2 < tol
        ok = true;            % 命中或区间已足够小
        return
    end
    if fa * fp > 0
        a = p; fa = fp;       % 根在右半区间
    else
        b = p;                % 根在左半区间
    end
end

ok = false;                   % 达到最大迭代次数仍未满足容差
end
```

### 2.2.3 收敛性定理与误差界

**定理.** 设 \(f\in C[a,b]\)，\(f(a)f(b)<0\)。二分法产生的序列 \(\{p_n\}_{n=1}^{\infty}\) 收敛到某个根 \(p\in(a,b)\)，并且

\[
\boxed{\ |p_n-p|\le \frac{b-a}{2^n}\ }
\]

对一切 \(n\ge1\) 成立。

**证明.** 记初始区间为 \([a_1,b_1]=[a,b]\)，第 \(n\) 步的区间为 \([a_n,b_n]\)，中点为 \(p_n=(a_n+b_n)/2\)。由算法的取舍规则，每一步都保持

\[
f(a_n)f(b_n)<0.
\]

并且区间是嵌套的：\([a_{n+1},b_{n+1}]\subset[a_n,b_n]\)。区间长度满足

\[
b_n-a_n=\frac{b-a}{2^{n-1}}.
\]

这是对 \(n\) 的归纳：\(n=1\) 时显然；每取一次中点，新区间长度恰好是旧区间的一半。长度趋于零，由嵌套区间定理，存在唯一的 \(p\) 属于所有 \([a_n,b_n]\)，且 \(a_n\to p,\ b_n\to p\)。

若 \(f(p)\ne0\)，由连续性，\(f\) 在 \(p\) 的某个邻域内保持与 \(f(p)\) 相同的符号；但当 \(n\) 足够大时 \(a_n,b_n\) 都落入该邻域，于是 \(f(a_n)\) 与 \(f(b_n)\) 同号，矛盾。因此 \(f(p)=0\)。

因为 \(p\) 与 \(p_n\) 都在 \([a_n,b_n]\) 内，而 \(p_n\) 是中点，所以

\[
|p_n-p|\le \frac{b_n-a_n}{2}=\frac{b-a}{2^n}.
\]

右边趋于零，故 \(p_n\to p\)。\(\blacksquare\)

**需要多少步？** 给定容差 \(\varepsilon>0\)，要使误差不超过 \(\varepsilon\)，只需

\[
\frac{b-a}{2^n}\le\varepsilon \quad\Longleftrightarrow\quad n\ge \left\lceil \log_2\frac{b-a}{\varepsilon}\right\rceil .
\]

误差上界按 \(1/2\) 等比缩小，因此二分法是**线性收敛**的；每迭代一次，误差上界减半，大约多获得一位二进制有效数字。

### 2.2.4 例：三次方程

证明 \(f(x)=x^3+4x^2-10=0\) 在 \([1,2]\) 内有根，并用二分法求到 \(10^{-4}\)。

\(f(1)=1+4-10=-5<0\)，\(f(2)=8+16-10=14>0\)，由介值定理有根。取 \(\varepsilon=10^{-4}\)，需要

\[
n\ge\left\lceil\log_2\frac{1}{10^{-4}}\right\rceil=\lceil13.2877\rceil=14.
\]

第 13 步时区间半长为 \(2^{-13}\approx1.22\times10^{-4}\)，仍大于 \(10^{-4}\)；到第 14 步才满足要求：

| \(n\) | \(a_n\) | \(b_n\) | \(p_n\) | \(f(p_n)\) |
| --- | --- | --- | --- | --- |
| 13 | 1.364990235 | 1.365234375 | 1.365112305 | \(-0.00194\) |
| 14 | 1.365112305 | 1.365234375 | 1.365173340 | \(-0.000936\) |

真实根约为 \(1.365230013\)。第 13 步的实际误差约 \(1.18\times10^{-4}\)，略大于容差——这正是"误差界"而不是"实际误差"的体现。

### 2.2.5 优缺点

!!! warning "二分法的三句话"
    1. **绝对可靠**：只要初始括号成立，就一定收敛，不需要导数，不怕函数光滑性差。
    2. **绝对慢**：每步只把误差上界减半，线性收敛；要 \(10^{-10}\) 精度大约需要三十多次迭代。
    3. **可能误伤**：中点附近本来很好的近似值，可能因为区间取舍被整个丢掉。

因此二分法通常不单独使用，而是用来**提供一个可靠的初始括号或初值**，再交给 Newton、割线等快速方法。

## 2.3 不动点迭代

### 2.3.1 从方程到不动点形式

把方程 \(f(x)=0\) 改写成等价形式

\[
x=g(x).
\]

若 \(p=g(p)\)，则称 \(p\) 是 \(g\) 的**不动点**。改写方式不唯一，而不同的 \(g\) 会带来完全不同的收敛速度，甚至一个收敛、一个发散。

**例：** \(x^2-x-1=0\) 的正根 \(\phi=(1+\sqrt5)/2\approx1.618034\)。两种改写：

\[
x=\sqrt{x+1}=:g_1(x),\qquad x=1+\frac1x=:g_2(x).
\]

在不动点处，

\[
g_1'(\phi)=\frac{1}{2\sqrt{\phi+1}}=\frac{1}{2\phi}\approx0.309,\qquad g_2'(\phi)=-\frac{1}{\phi^2}\approx-0.382.
\]

两者都满足 \(|g'(\phi)|<1\)，都会收敛；\(g_1\) 的压缩因子更小，收敛更快；\(g_2\) 的导数为负，误差会左右摆动。

**例：** \(x^3+4x^2-10=0\) 的五种改写（课件取 \(x_0=1.5\)）：

| 改写 | 在根处的导数大小 | 迭代表现 |
| --- | --- | --- |
| \(g_1(x)=x-x^3-4x^2+10\) | 约 \(15.5\) | 发散 |
| \(g_2(x)=\sqrt{10/x-4x}\) | 约 \(3.43\) | 发散 |
| \(g_3(x)=\frac12\sqrt{10-x^3}\) | 约 \(0.512\) | 31 次收敛 |
| \(g_4(x)=\sqrt{10/(4+x)}\) | 约 \(0.127\) | 12 次收敛 |
| \(g_5(x)=x-\dfrac{x^3+4x^2-10}{3x^2+8x}\) | \(0\) | 5 次收敛，二次 |

最后一个 \(g_5\) 正是 Newton 迭代——它不是"碰巧构造得好"，而是因为 \(g_5'(p)=0\)。这预告了 2.4 与 2.5 的核心结论：**收敛速度由 \(g'\) 在不动点处的值决定**。

### 2.3.2 不动点的存在性

**定理.** 若 \(g\in C[a,b]\)，且对一切 \(x\in[a,b]\) 有 \(g(x)\in[a,b]\)，则 \(g\) 在 \([a,b]\) 内至少有一个不动点。

**证明.** 令

\[
h(x)=g(x)-x.
\]

则 \(h\) 在 \([a,b]\) 上连续。若 \(g(a)=a\) 或 \(g(b)=b\)，已经找到不动点。否则，由 \(g(x)\in[a,b]\) 可知

\[
g(a)>a,\qquad g(b)<b,
\]

即

\[
h(a)=g(a)-a>0,\qquad h(b)=g(b)-b<0.
\]

由介值定理，存在 \(p\in(a,b)\) 使 \(h(p)=0\)，即 \(g(p)=p\)。\(\blacksquare\)

### 2.3.3 不动点的唯一性

**定理.** 在存在性定理的条件下，若 \(g\) 在 \((a,b)\) 内可导，且存在常数 \(k<1\)，使

\[
|g'(x)|\le k,\qquad \forall x\in[a,b],
\]

则 \(g\) 在 \([a,b]\) 内的不动点唯一。

**证明.** 反设 \(p\ne q\) 都是不动点。由中值定理，存在 \(\xi\) 介于 \(p,q\) 之间，使

\[
|p-q|=|g(p)-g(q)|=|g'(\xi)||p-q|\le k|p-q|<|p-q|,
\]

矛盾。故 \(p=q\)。\(\blacksquare\)

### 2.3.4 收敛性定理（压缩映射）

**定理（不动点定理）.** 设 \(g\in C[a,b]\)，\(g(x)\in[a,b]\) 对一切 \(x\in[a,b]\) 成立；又设 \(g\) 在 \((a,b)\) 内可导，且

\[
|g'(x)|\le k<1,\qquad \forall x\in[a,b].
\]

则对任意初值 \(p_0\in[a,b]\)，迭代

\[
p_n=g(p_{n-1}),\qquad n\ge1
\]

收敛到 \(g\) 在 \([a,b]\) 内的唯一不动点 \(p\)，并且

\[
\boxed{\ |p_n-p|\le k^n|p_0-p|\ }.
\]

**证明.** 存在性与唯一性已由 2.3.2、2.3.3 给出。因为 \(g\) 把 \([a,b]\) 映到自身，所以所有 \(p_n\) 都留在 \([a,b]\) 内。

对每一步用中值定理：

\[
|p_n-p|=|g(p_{n-1})-g(p)|=|g'(\xi_n)||p_{n-1}-p|\le k|p_{n-1}-p|.
\]

递推 \(n\) 次：

\[
|p_n-p|\le k|p_{n-1}-p|\le k^2|p_{n-2}-p|\le\cdots\le k^n|p_0-p|.
\]

因为 \(0\le k<1\)，所以 \(k^n\to0\)，故 \(p_n\to p\)。\(\blacksquare\)

!!! note "条件只是充分的"
    \(|g'(p)|<1\) 只能保证**局部**收敛：由 \(g'\) 连续，可在 \(p\) 附近取一个小区间使 \(|g'|\le k<1\)。若要"任意初值都收敛"，必须像定理那样在整个区间上有一致的压缩常数 \(k<1\)，并且 \(g\) 把区间映到自身。

### 2.3.5 误差估计：先验与后验

定理给出的 \(k^n|p_0-p|\) 需要知道真实误差 \(|p_0-p|\)，实际不可用。下面两个估计只依赖迭代值。

**先验估计（priori）.**

\[
\boxed{\ |p_n-p|\le \frac{k^n}{1-k}|p_1-p_0|\ }
\]

**证明.** 对 \(j\ge1\)，由压缩性

\[
|p_{j+1}-p_j|\le k|p_j-p_{j-1}|\le\cdots\le k^j|p_1-p_0|.
\]

于是对 \(m>n\ge1\)，用三角不等式和等比求和：

\[
|p_m-p_n|\le\sum_{j=n}^{m-1}|p_{j+1}-p_j| \le\sum_{j=n}^{m-1}k^j|p_1-p_0| \le\frac{k^n}{1-k}|p_1-p_0|.
\]

令 \(m\to\infty\)，左边趋于 \(|p-p_n|\)，即得结论。\(\blacksquare\)

**后验估计（posteriori）.**

\[
\boxed{\ |p_n-p|\le \frac{k}{1-k}|p_n-p_{n-1}|\ }
\]

**证明.** 对 \(m>n\)，

\[
|p_m-p_n|\le\sum_{j=n}^{m-1}|p_{j+1}-p_j| \le\sum_{j=n}^{m-1}k^{j-n+1}|p_n-p_{n-1}| \le\frac{k}{1-k}|p_n-p_{n-1}|.
\]

令 \(m\to\infty\) 即得。\(\blacksquare\)

!!! note "先验 vs 后验"
    **先验**在迭代前就能用（只要知道 \(k\) 和 \(|p_1-p_0|\)），适合预估工作量；**后验**用当前步长 \(|p_n-p_{n-1}|\) 估计误差，适合做停止判据。两者都说明：误差按 \(k^n\) 等比衰减，\(k\) 越接近 1 越慢。

### 2.3.6 不动点迭代算法

```matlab
function [p, iter, ok] = fixed_point(g, p0, tol, maxit)
% 不动点迭代 p = g(p)
% g     迭代函数句柄
% p0    初值；tol 相邻迭代差容差；maxit 最大迭代次数
if nargin < 3, tol = 1e-10; end
if nargin < 4, maxit = 200; end

for iter = 1:maxit
    p = g(p0);
    if abs(p - p0) < tol
        ok = true;            % 相邻迭代差足够小
        return
    end
    p0 = p;
end

p = p0;
ok = false;
end
```

!!! warning "停止判据不等于误差"
    \(|p_n-p_{n-1}|<\varepsilon\) 只说明"这一步走得小"，不说明离根近。若 \(k\) 很接近 1，步长可以很小而误差仍然很大。严谨的误差控制要用后验估计 \(\frac{k}{1-k}|p_n-p_{n-1}|\)，或者同时检查 \(|f(p_n)|\)。

### 2.3.7 收敛快慢由导数决定

若 \(g'(p)\ne0\)，则误差近似按

\[
|p_n-p|\approx|g'(p)|^n|p_0-p|
\]

衰减，收敛是线性的，渐近常数为 \(|g'(p)|\)。因此：

- \(|g'(p)|\) 越小越快；\(g_3\) 的 \(0.512\) 对应 31 次，\(g_4\) 的 \(0.127\) 对应 12 次，与 \(\log\varepsilon/\log k\) 的量级一致；
- \(g'(p)<0\) 时误差变号，迭代值在根两侧来回跳（\(g_2\) 的 \(-0.382\) 就是这种摆动）；
- 若 \(g'(p)=0\)，线性项消失，收敛至少是二次的——这就是下一节 Newton 法的目标。

## 2.4 Newton 法

### 2.4.1 推导：用切线代替曲线

设 \(f\in C^2[a,b]\)，\(p\) 是根，\(p_{n-1}\) 是当前近似。把 \(f\) 在 \(p_{n-1}\) 处作一阶 Taylor 展开，并在 \(x=p\) 处取值：

\[
0=f(p)=f(p_{n-1})+f'(p_{n-1})(p-p_{n-1})+\frac{f''(\xi_n)}{2}(p-p_{n-1})^2.
\]

当 \(p_{n-1}\) 离 \(p\) 足够近时，二次项是高阶小量，丢掉它：

\[
0\approx f(p_{n-1})+f'(p_{n-1})(p-p_{n-1}).
\]

解出 \(p\)，作为新的近似 \(p_n\)：

\[
\boxed{\ p_n=p_{n-1}-\frac{f(p_{n-1})}{f'(p_{n-1})}\ }
\]

几何上，\(p_n\) 是曲线 \(y=f(x)\) 在点 \((p_{n-1},f(p_{n-1}))\) 处切线与 \(x\) 轴的交点，所以 Newton 法也叫**切线法**。

### 2.4.2 Newton 算法

```matlab
function [p, iter, ok] = newton(f, df, p0, tol, maxit)
% Newton 法求 f(x)=0
% f, df  函数值与导数的句柄
% p0     初值；tol 步长容差；maxit 最大迭代次数
if nargin < 4, tol = 1e-10; end
if nargin < 5, maxit = 200; end

for iter = 1:maxit
    fp  = f(p0);
    dfp = df(p0);
    if abs(dfp) < 1e-14
        p = p0; ok = false;   % 导数过小，切线几乎水平
        return
    end
    p = p0 - fp / dfp;        % 切线零点
    if abs(p - p0) < tol || abs(f(p)) < tol
        ok = true;
        return
    end
    p0 = p;
end

p = p0;
ok = false;
end
```

### 2.4.3 局部收敛定理

**定理.** 设 \(f\in C^2[a,b]\)，\(p\in(a,b)\) 满足 \(f(p)=0\) 且 \(f'(p)\ne0\)。则存在 \(\delta>0\)，使对任意初值 \(p_0\in[p-\delta,p+\delta]\)，Newton 迭代收敛到 \(p\)。

**证明.** 把 Newton 迭代写成不动点迭代 \(p_n=g(p_{n-1})\)，其中

\[
g(x)=x-\frac{f(x)}{f'(x)}.
\]

**第一步：确定 \(g\) 的定义域。** 因为 \(f'\) 连续且 \(f'(p)\ne0\)，存在 \(\delta_1>0\)，使 \(f'(x)\ne0\) 在 \(I_1=[p-\delta_1,p+\delta_1]\subset[a,b]\) 上成立。于是 \(g\) 在 \(I_1\) 上有定义且连续。

**第二步：计算 \(g'\)。** 在 \(I_1\) 上，

\[
g'(x)=1-\frac{[f'(x)]^2-f(x)f''(x)}{[f'(x)]^2}=\frac{f(x)f''(x)}{[f'(x)]^2}.
\]

因为 \(f\in C^2[a,b]\)，所以 \(g\in C^1(I_1)\)。又 \(f(p)=0\)，故

\[
g'(p)=\frac{f(p)f''(p)}{[f'(p)]^2}=0.
\]

**第三步：在 \(p\) 附近取一致的压缩常数。** 取任意 \(k\in(0,1)\)。由 \(g'\) 连续、\(g'(p)=0\)，存在 \(0<\delta<\delta_1\)，使

\[
|g'(x)|\le k,\qquad \forall x\in I=[p-\delta,p+\delta].
\]

**第四步：验证 \(g\) 把 \(I\) 映到自身。** 对 \(x\in I\)，由中值定理，存在 \(\xi\) 介于 \(x,p\) 之间，使

\[
|g(x)-p|=|g(x)-g(p)|=|g'(\xi)||x-p|\le k|x-p|<|x-p|\le\delta.
\]

所以 \(g(x)\in I\)。现在 \(g\) 满足不动点定理的全部条件，故 Newton 迭代对任意 \(p_0\in I\) 收敛到 \(p\)。\(\blacksquare\)

!!! warning "这是局部定理"
    定理只保证"初值足够靠近根"时收敛，而且证明没有给出 \(\delta\) 的可计算大小。实际使用时仍要靠括号、试算或二分法提供好的初值。

### 2.4.4 二次收敛定理及证明

**定理.** 在 2.4.3 的条件下，Newton 迭代至少二次收敛。更具体地，记 \(e_n=p_n-p\)，则

\[
\boxed{\ e_{n+1}=-\frac{f''(\xi_n)}{2f'(p_n)}e_n^2\ }
\]

其中 \(\xi_n\) 介于 \(p_n\) 与 \(p\) 之间。若 \(f'\) 在根附近不为零，则

\[
\lim_{n\to\infty}\frac{|e_{n+1}|}{|e_n|^2}=\frac{|f''(p)|}{2|f'(p)|}.
\]

**证明.** 把 \(f(p)\) 在 \(p_n\) 处作一阶 Taylor 展开，并利用 \(f(p)=0\)：

\[
0=f(p)=f(p_n)+f'(p_n)(p-p_n)+\frac{f''(\xi_n)}{2}(p-p_n)^2.
\]

两边除以 \(f'(p_n)\)：

\[
\frac{f(p_n)}{f'(p_n)}+(p-p_n)+\frac{f''(\xi_n)}{2f'(p_n)}(p-p_n)^2=0.
\]

移项并注意 \(p_n-\frac{f(p_n)}{f'(p_n)}=p_{n+1}\)：

\[
p_{n+1}-p=-\frac{f''(\xi_n)}{2f'(p_n)}(p_n-p)^2,
\]

即

\[
e_{n+1}=-\frac{f''(\xi_n)}{2f'(p_n)}e_n^2.
\]

在包含迭代值的区间上记

\[
M=\max|f''|,\qquad m=\min|f'|>0,
\]

则

\[
|e_{n+1}|\le\frac{M}{2m}|e_n|^2.
\]

当 \(n\to\infty\) 时 \(p_n\to p\)，从而 \(\xi_n\to p\)；由 \(f',f''\) 的连续性，系数趋于 \(\frac{|f''(p)|}{2|f'(p)|}\)。\(\blacksquare\)

**正确数字翻倍.** 令 \(a_n=\frac{M}{2m}|e_n|\)，则 \(a_{n+1}\le a_n^2\)。若 \(a_0<1\)，则

\[
a_n\le a_0^{2^n}.
\]

每迭代一次，误差的指数翻倍；一旦进入 \(a_n<0.1\)，下一步就到 \(10^{-2}\)，再下一步 \(10^{-4}\)，再下一步 \(10^{-8}\)。这就是 Newton 法"几步到位"的原因。

### 2.4.5 与不动点迭代的对比

对 \(f(x)=\cos x-x=0\)，根 \(p\approx0.7390851332\)。取 \(p_0=\pi/4\)：

| \(n\) | 不动点 \(p_n\) | 相邻误差比 | Newton \(p_n\) | Newton 相邻误差 |
| --- | --- | --- | --- | --- |
| 1 | 0.707107 | — | 0.739536 | \(4.59\times10^{-2}\) |
| 2 | 0.760245 | 0.679 | 0.739085 | \(4.51\times10^{-4}\) |
| 3 | 0.724667 | 0.670 | 0.739085 | \(4\times10^{-8}\) |
| 4 | 0.748720 | 0.676 | 0.739085 | 约 \(0\) |

不动点迭代的误差比稳定在 \(0.67\) 附近，正是 \(|g'(p)|=|-\sin p|\approx0.6736\)；Newton 的误差则按平方骤降，第 3 步已经到 \(10^{-8}\)。

### 2.4.6 停止准则

常用三种判据（给定容差 \(\epsilon>0\)）：

\[
|p_N-p_{N-1}|<\epsilon,\qquad \frac{|p_N-p_{N-1}|}{|p_N|}<\epsilon\ (p_N\ne0),\qquad |f(p_N)|<\epsilon.
\]

三者都**不能**精确给出真实误差 \(|p_N-p|\)：

- 步长小可能只是函数很平，离根仍远；
- \(|f(p_N)|\) 小可能因为 \(f\) 在根附近很平，误差被放大；
- 相对判据在 \(p_N\) 接近零时会失效。

实际实现通常同时检查步长与 \(|f(p_N)|\)，并设置最大迭代次数。

### 2.4.7 Newton 法的缺点

!!! danger "五个常见失效场景"
    1. **需要导数**：每步都要算 \(f'(p_{n-1})\)；很多实际问题中导数比函数值贵得多，甚至没有解析式。
    2. **局部收敛**：初值不好可能发散、跑到别的根，或者进入循环。经典例子 \(f(x)=x^3-2x+2\)，从 \(p_0=0\) 出发在 \(0\) 与 \(1\) 之间循环。
    3. **导数接近零**：\(f'(p_{n-1})\approx0\) 时步长巨大，容易溢出；重根处 \(f'(p)=0\)，二次收敛退化为线性。
    4. **不保括号**：迭代值可能跳出当前有根区间，失去"一定收敛"的保障。
    5. **重根退化**：若 \(p\) 是 \(m\) 重根，则 \(g'(p)=1-1/m\ne0\)，只剩线性收敛（见 2.7.2）。

## 2.5 收敛阶与迭代误差分析

### 2.5.1 收敛阶的定义

设 \(\{p_n\}\) 收敛到 \(p\)，且 \(p_n\ne p\)。若存在常数 \(\alpha\ge1\) 与 \(\lambda>0\)，使

\[
\lim_{n\to\infty}\frac{|p_{n+1}-p|}{|p_n-p|^{\alpha}}=\lambda,
\]

则称序列**收敛阶为 \(\alpha\)**，\(\lambda\) 称为**渐近误差常数**。

- \(\alpha=1\)：线性收敛（通常要求 \(\lambda<1\)）；
- \(1<\alpha<2\)：超线性收敛；
- \(\alpha=2\)：二次收敛。

阶描述"误差指数如何变化"，渐近常数描述"前面的倍数"。同为线性收敛，\(\lambda=0.1\) 比 \(\lambda=0.9\) 快得多。

### 2.5.2 不动点迭代的阶

**定理（线性收敛）.** 设 \(g\in C[a,b]\)，\(g(x)\in[a,b]\)，\(g'\) 在 \((a,b)\) 内连续，且 \(|g'(x)|\le k<1\)。若 \(g'(p)\ne0\)，则对任意 \(p_0\ne p\)，迭代 \(p_n=g(p_{n-1})\) 只是线性收敛，且

\[
\lim_{n\to\infty}\frac{|p_{n+1}-p|}{|p_n-p|}=|g'(p)|.
\]

**证明.** 由中值定理，

\[
p_{n+1}-p=g(p_n)-g(p)=g'(\xi_n)(p_n-p),
\]

其中 \(\xi_n\) 介于 \(p_n\) 与 \(p\) 之间。因为 \(p_n\to p\)，所以 \(\xi_n\to p\)；又 \(g'\) 连续，故

\[
\lim_{n\to\infty}\frac{p_{n+1}-p}{p_n-p}=\lim_{n\to\infty}g'(\xi_n)=g'(p).
\]

取绝对值即得。\(\blacksquare\)

**定理（二次收敛）.** 设 \(p\) 是 \(x=g(x)\) 的解，\(g'(p)=0\)，且 \(g''\) 在包含 \(p\) 的某个开区间 \(I\) 上连续，满足 \(|g''(x)|\le M\)。则存在 \(\delta>0\)，使对 \(p_0\in[p-\delta,p+\delta]\)，迭代至少二次收敛，并且

\[
|p_{n+1}-p|\le\frac{M}{2}|p_n-p|^2.
\]

**证明.** 取 \(k\in(0,1)\) 与 \(\delta>0\)，使在 \(J=[p-\delta,p+\delta]\subset I\) 上有 \(|g'(x)|\le k\)（由 \(g'(p)=0\) 与连续性可取到）。由中值定理，对 \(x\in J\) 有 \(|g(x)-p|\le k|x-p|<|x-p|\le\delta\)，所以 \(g\) 把 \(J\) 映到自身，迭代值始终留在 \(J\) 内。对 \(x\in J\) 作一阶 Taylor 展开：

\[
g(x)=g(p)+g'(p)(x-p)+\frac{g''(\xi)}{2}(x-p)^2.
\]

代入 \(g(p)=p\)、\(g'(p)=0\)：

\[
g(x)=p+\frac{g''(\xi)}{2}(x-p)^2.
\]

令 \(x=p_n\)：

\[
p_{n+1}=g(p_n)=p+\frac{g''(\xi_n)}{2}(p_n-p)^2.
\]

于是

\[
|p_{n+1}-p|\le\frac{M}{2}|p_n-p|^2.
\]

若 \(g''\) 连续，则还可得到

\[
\lim_{n\to\infty}\frac{|p_{n+1}-p|}{|p_n-p|^2}=\frac{|g''(p)|}{2}.
\]

\(\blacksquare\)

!!! note "二次收敛的两个条件"
    必须同时有 \(g(p)=p\) 与 \(g'(p)=0\)。Newton 法正是构造了一个在根处导数为零的 \(g\)：
    \(g'(p)=\frac{f(p)f''(p)}{[f'(p)]^2}=0\)。如果 \(f'(p)=0\)，这个论证失效，Newton 退化。

### 2.5.3 线性与二次的实际差距

设渐近常数 \(\lambda=0.5\)。线性收敛的误差约为

\[
|e_n|\approx(0.5)^n|e_0|,
\]

二次收敛（\(e_{n+1}\approx0.5e_n^2\)）则约为

\[
|e_n|\approx(0.5)^{2^n-1}|e_0|.
\]

取 \(e_0=1\) 比较：

| \(n\) | 线性 \(0.5^n\) | 二次 \((0.5)^{2^n-1}\) |
| --- | --- | --- |
| 1 | \(5.0\times10^{-1}\) | \(5.0\times10^{-1}\) |
| 2 | \(2.5\times10^{-1}\) | \(1.25\times10^{-1}\) |
| 3 | \(1.25\times10^{-1}\) | \(7.8\times10^{-3}\) |
| 4 | \(6.25\times10^{-2}\) | \(3.1\times10^{-5}\) |
| 5 | \(3.13\times10^{-2}\) | \(4.7\times10^{-10}\) |

前两步差别不大，之后完全不在一个量级。这就是为什么 Newton 法值得为导数付出代价。

### 2.5.4 常见方法的阶

- 二分法：线性，误差上界每步减半；
- 不动点迭代：一般线性，常数 \(|g'(p)|\)；若 \(g'(p)=0\) 则二次；
- Newton 法：\(f'(p)\ne0\) 时二次；
- 割线法：超线性，阶 \(\phi\approx1.618\)（下一节）；
- 试位法：通常线性，且常数可能接近 1。

## 2.6 割线法

### 2.6.1 从 Newton 到割线

Newton 法每步要算 \(f'(p_{n-1})\)。若导数难求，可用最近两点的差商近似：

\[
f'(p_{n-1})\approx\frac{f(p_{n-1})-f(p_{n-2})}{p_{n-1}-p_{n-2}}.
\]

代入 Newton 公式：

\[
\boxed{\ p_n=p_{n-1}-\frac{f(p_{n-1})(p_{n-1}-p_{n-2})}{f(p_{n-1})-f(p_{n-2})}\ }
\]

这就是**割线法**。几何上，用经过 \((p_{n-2},f(p_{n-2}))\) 与 \((p_{n-1},f(p_{n-1}))\) 的割线与 \(x\) 轴的交点作为新近似。

割线法需要两个初值 \(p_0,p_1\)，每步只算一个新函数值 \(f(p_n)\)，不需要导数，也不保持括号。

### 2.6.2 误差递推

记 \(e_n=p_n-p\)。把割线步与 Newton 步比较。Newton 步 \(p_N=p_n-f(p_n)/f'(p_n)\) 的误差已知为

\[
p_N-p=-\frac{f''(\xi_n)}{2f'(p_n)}e_n^2.
\]

割线步与 Newton 步之差为

\[
p_{n+1}-p_N=-f(p_n)\left(\frac1{D_n}-\frac1{f'(p_n)}\right)=\frac{f(p_n)(D_n-f'(p_n))}{f'(p_n)D_n},
\]

其中 \(D_n=\frac{f(p_n)-f(p_{n-1})}{p_n-p_{n-1}}\) 是割线斜率。由 Taylor 展开，

\[
D_n=f'(p_n)+\frac{f''(\eta_n)}{2}(p_{n-1}-p_n).
\]

代回并用 \(f(p_n)\approx f'(p)e_n\)、\(p_{n-1}-p_n=e_{n-1}-e_n\approx e_{n-1}\)：

\[
p_{n+1}-p_N\approx\frac{f''(p)}{2f'(p)}e_n(e_{n-1}-e_n)\approx\frac{f''(p)}{2f'(p)}e_ne_{n-1}.
\]

第一项是 Newton 步本身的误差，为 \(O(e_n^2)\)，比 \(O(e_ne_{n-1})\) 更高阶，可以并入小量。因此

\[
\boxed{\ e_{n+1}\approx\frac{f''(p)}{2f'(p)}e_n e_{n-1}\ }
\]

直观地说，Newton 每步"平方"当前误差，割线则同时利用前两步的误差，所以每步的误差是前两步误差的乘积。

### 2.6.3 收敛阶为什么是 1.618

设

\[
e_{n+1}\approx A e_n e_{n-1}.
\]

若误差按幂律 \(e_n\approx C e_{n-1}^{r}\) 变化，则一方面

\[
e_{n+1}\approx A C e_{n-1}^{r+1},
\]

另一方面

\[
e_{n+1}\approx C e_n^{r}\approx C^{1+r}e_{n-1}^{r^2}.
\]

比较 \(e_{n-1}\) 的指数，得到

\[
r^2=r+1.
\]

其正根为

\[
\boxed{\ r=\phi=\frac{1+\sqrt5}{2}\approx1.618\ }
\]

即黄金分割比。因此割线法的收敛阶为 \(\phi\)，属于超线性收敛：比线性快，比 Newton 的二次慢。每步有效数字大约乘以 \(1.618\)。

!!! note "两个初值都要好"
    上述阶是局部结论，要求 \(f'(p)\ne0\)、\(f''\) 连续，且 \(p_0,p_1\) 都足够靠近 \(p\)。若两点相距太远，差商可能严重失真，割线法会发散。

### 2.6.4 割线法算法

```matlab
function [p, iter, ok] = secant(f, p0, p1, tol, maxit)
% 割线法求 f(x)=0，需要两个初值 p0, p1
if nargin < 4, tol = 1e-10; end
if nargin < 5, maxit = 200; end

f0 = f(p0); f1 = f(p1);
for iter = 1:maxit
    den = f1 - f0;
    if abs(den) < 1e-14
        p = p1; ok = false;   % 两点函数值几乎相同，割线水平
        return
    end
    p = p1 - f1 * (p1 - p0) / den;   % 割线零点
    if abs(p - p1) < tol || abs(f(p)) < tol
        ok = true;
        return
    end
    p0 = p1; f0 = f1;        % 滚动两点
    p1 = p;  f1 = f(p);
end

p = p1; ok = false;
end
```

### 2.6.5 优缺点

- **优点**：不需要导数；每步只算一个新函数值；阶 \(1.618\)，通常比二分法和不动点迭代快得多。
- **缺点**：需要两个初值；不保括号，可能发散；分母 \(f(p_n)-f(p_{n-1})\) 接近零时数值不稳定；对初值敏感。

如果已经有括号，又想要"比二分法快、又绝不丢根"，可以用下一节的试位法。

## 2.7 试位法与修正 Newton

### 2.7.1 试位法（false position / regula falsi）

试位法把割线法装进括号里：始终保留 \(f(a)f(b)<0\)，用割线与 \(x\) 轴的交点作为新近似。过 \((a,f(a))\)、\((b,f(b))\) 的割线零点为

\[
\boxed{\ p=b-\frac{f(b)(b-a)}{f(b)-f(a)}=\frac{a f(b)-b f(a)}{f(b)-f(a)}\ }
\]

然后按函数值符号缩小区间：

- 若 \(f(a)f(p)<0\)，根在 \([a,p]\)，令 \(b=p\)；
- 否则根在 \([p,b]\)，令 \(a=p\)。

```matlab
function [p, iter, ok] = false_position(f, a, b, tol, maxit)
% 试位法：保括号，用割线零点代替中点
if nargin < 4, tol = 1e-10; end
if nargin < 5, maxit = 200; end

fa = f(a); fb = f(b);
if fa * fb >= 0
    error('试位法要求 f(a) 与 f(b) 异号');
end

for iter = 1:maxit
    p = b - fb * (b - a) / (fb - fa);   % 割线零点
    fp = f(p);
    if fp == 0 || abs(b - a) < tol
        ok = true;
        return
    end
    if fa * fp > 0
        a = p; fa = fp;       % 根在右半区间
    else
        b = p; fb = fp;       % 根在左半区间
    end
end

ok = false;
end
```

**收敛性.** 只要初始括号成立且根唯一，试位法一定收敛（区间长度趋于零），但通常只是**线性**收敛。原因是它每次只替换一个端点，另一个端点可能长期不动，割线越来越"偏"，误差比可能接近 1，出现**单侧停滞**。

!!! note "Illinois 修正"
    若发现某一端连续多次被保留，就把该端的函数值乘以 \(1/2\)（Illinois 策略），等价于人为把割线拉向停滞端，可显著加速。这是工程实现中常用的补丁。

### 2.7.2 重根为什么让 Newton 变慢

设 \(p\) 是 \(f\) 的 \(m\) 重根，即

\[
f(x)=(x-p)^m h(x),\qquad h(p)\ne0.
\]

则

\[
f'(x)=(x-p)^{m-1}\big[m h(x)+(x-p)h'(x)\big].
\]

于是

\[
\frac{f(x)}{f'(x)}=\frac{(x-p)h(x)}{m h(x)+(x-p)h'(x)}\approx\frac{x-p}{m}.
\]

Newton 迭代

\[
g(x)=x-\frac{f(x)}{f'(x)}
\]

在 \(p\) 附近满足

\[
g(x)-p\approx(x-p)-\frac{x-p}{m}=\left(1-\frac1m\right)(x-p).
\]

所以

\[
\boxed{\ g'(p)=1-\frac1m\ }
\]

当 \(m=1\) 时 \(g'(p)=0\)，二次收敛；当 \(m\ge2\) 时 \(0<g'(p)<1\)，退化为线性收敛。重根越多，越慢。

### 2.7.3 修正 Newton：已知重数

若已知重数 \(m\)，把 Newton 公式改成

\[
\boxed{\ p_n=p_{n-1}-m\frac{f(p_{n-1})}{f'(p_{n-1})}\ }
\]

记对应的迭代函数为

\[
G(x)=x-m\frac{f(x)}{f'(x)}.
\]

则

\[
G'(x)=1-m+m\frac{f(x)f''(x)}{[f'(x)]^2}.
\]

由 2.7.2 的展开，

\[
\lim_{x\to p}\frac{f(x)f''(x)}{[f'(x)]^2}=\frac{m-1}{m},
\]

所以

\[
G'(p)=1-m+m\cdot\frac{m-1}{m}=0.
\]

由 2.5.2 的二次收敛定理，修正 Newton 在重根处恢复二次收敛。代价是必须知道 \(m\)。

### 2.7.4 修正 Newton：重数未知

若重数未知，可用不显含 \(m\) 的公式

\[
\boxed{\ p_n=p_{n-1}-\frac{f(p_{n-1})f'(p_{n-1})}{[f'(p_{n-1})]^2-f(p_{n-1})f''(p_{n-1})}\ }
\]

记

\[
G(x)=x-\frac{f(x)f'(x)}{[f'(x)]^2-f(x)f''(x)}.
\]

在 \(m\) 重根处，仍写 \(f=(x-p)^m h\)，\(h(p)\ne0\)。由 2.7.2 的展开，

\[
f(x)f'(x)\approx m h^2(x-p)^{2m-1},
\]

而分母

\[
[f'(x)]^2-f(x)f''(x)\approx m h^2(x-p)^{2m-2}.
\]

两式相除得

\[
\frac{f(x)f'(x)}{[f'(x)]^2-f(x)f''(x)}\approx x-p,
\]

所以 \(G(x)=x-(x-p)+O((x-p)^2)=p+O((x-p)^2)\)，即 \(G'(p)=0\)，仍是二次收敛。在单根处（\(m=1\)）它退化为普通 Newton 公式

\[
x-\frac{f(x)f'(x)}{[f'(x)]^2}=x-\frac{f(x)}{f'(x)}.
\]

代价是要计算 \(f''\)，且分母可能接近零。

!!! warning "别把三种“修正”混为一谈"
    - **重数已知**：乘 \(m\)，即 \(x-mf/f'\)；
    - **重数未知**：用 \(x-ff'/((f')^2-ff'')\)；
    - **简化 Newton / 弦方法**：把 \(f'(x_n)\) 固定为 \(f'(x_0)\)，即 \(x_{n+1}=x_n-f(x_n)/f'(x_0)\)，只有线性收敛，但每步省一次导数计算。

### 2.7.5 简化 Newton（固定斜率）

当导数计算很贵、但可以在初值处算一次时，可用

\[
p_n=p_{n-1}-\frac{f(p_{n-1})}{f'(p_0)}.
\]

几何上，所有切线都取同一个斜率，迭代是"平行切线"与 \(x\) 轴的交点。它的收敛是线性的，常数约为 \(|1-f'(p)/f'(p_0)|\)；初值好、导数变化不大时很实用。

## 2.8 加速收敛

### 2.8.1 线性收敛的几何误差模型

许多方法（不动点迭代、二分法、试位法）的误差最终表现为

\[
p_n=p+c\lambda^n+O(\lambda^{2n}),
\]

其中 \(|\lambda|<1\)。若只有这一项，能不能从三个相邻的迭代值直接"外推"出 \(p\)？Aitken 给出了答案。

### 2.8.2 Aitken 平方加速

设

\[
p_n=p+c\lambda^n.
\]

记一阶差分与二阶差分：

\[
\Delta p_n=p_{n+1}-p_n,\qquad \Delta^2 p_n=\Delta p_{n+1}-\Delta p_n=p_{n+2}-2p_{n+1}+p_n.
\]

由 \(p_n=p+c\lambda^n\) 得

\[
p_{n+1}-p_n=c\lambda^n(\lambda-1),\qquad p_{n+2}-2p_{n+1}+p_n=c\lambda^n(\lambda-1)^2.
\]

两式相除：

\[
\frac{(p_{n+1}-p_n)^2}{p_{n+2}-2p_{n+1}+p_n}=\frac{c^2\lambda^{2n}(\lambda-1)^2}{c\lambda^n(\lambda-1)^2}=c\lambda^n=p_n-p.
\]

因此

\[
\boxed{\ \hat p_n=p_n-\frac{(p_{n+1}-p_n)^2}{p_{n+2}-2p_{n+1}+p_n}\ }
\]

在纯几何误差模型下**精确等于** \(p\)。实际误差含更高阶项时，它消去主项，得到更快的序列。这就是 **Aitken \(\Delta^2\) 加速**。

!!! warning "分母是雷区"
    若 \(p_n\) 已经收敛到机器精度，\(\Delta^2p_n\) 是三个几乎相同的数做差分，可能变成 0 或舍入噪声，加速值会爆炸。实际使用时要设分母阈值，并在接近收敛时停止加速。

### 2.8.3 Steffensen 迭代

Aitken 只是"事后加速"：先算出 \(p_n,p_{n+1},p_{n+2}\)，再组合。**Steffensen 方法**把加速值立刻当作新的迭代值，反复执行：

给定 \(p_0\)，令

\[
q_1=g(p_0),\qquad q_2=g(q_1),
\]

\[
p_1=p_0-\frac{(q_1-p_0)^2}{q_2-2q_1+p_0}.
\]

一般地，

\[
\boxed{\ p_{n+1}=p_n-\frac{[g(p_n)-p_n]^2}{g(g(p_n))-2g(p_n)+p_n}\ }
\]

也就是说，每一步用 \(p_n,\ g(p_n),\ g(g(p_n))\) 做一次 Aitken 外推。

**为什么是二次收敛？** 记

\[
G(x)=x-\frac{[g(x)-x]^2}{g(g(x))-2g(x)+x}.
\]

设 \(g'(p)=a\ne1\)，并记 \(t=x-p\)。由 Taylor 展开，

\[
g(x)=p+at+O(t^2),\qquad g(g(x))=p+a^2t+O(t^2).
\]

于是

\[
g(x)-x=(a-1)t+O(t^2),
\]

\[
g(g(x))-2g(x)+x=(a-1)^2t+O(t^2).
\]

分子是 \((a-1)^2t^2+O(t^3)\)，分母是 \((a-1)^2t+O(t^2)\)，比值为 \(t+O(t^2)\)。因此

\[
G(x)=x-t+O(t^2)=p+O((x-p)^2).
\]

所以 \(G'(p)=0\)，由 2.5.2 的定理，Steffensen 迭代在 \(p\) 附近二次收敛。

!!! note "Steffensen 的卖点"
    它**不需要导数**，却能把一个线性收敛的不动点迭代改造成二次收敛；即使原不动点迭代因为 \(|g'(p)|>1\) 而发散，只要 \(g'(p)\ne1\) 且初值足够近，Steffensen 仍可能收敛。代价是每步要算两次 \(g\)。若 \(g'(p)=1\)，分母的主项消失，方法退化，需要改用 Newton 或其他手段。

### 2.8.4 Steffensen 算法

```matlab
function [p, iter, ok] = steffensen(g, p0, tol, maxit)
% Steffensen 加速：把 Aitken 外推嵌入不动点迭代
if nargin < 3, tol = 1e-10; end
if nargin < 4, maxit = 200; end

for iter = 1:maxit
    q1 = g(p0);
    q2 = g(q1);
    den = q2 - 2*q1 + p0;
    if abs(den) < 1e-14
        p = q1; ok = false;   % 分母过小，加速失效
        return
    end
    p = p0 - (q1 - p0)^2 / den;
    if abs(p - p0) < tol
        ok = true;
        return
    end
    p0 = p;
end

p = p0; ok = false;
end
```

## 2.9 方法对比与选用

| 方法 | 需要括号 | 需要导数 | 每步新函数值 | 收敛阶 | 主要风险 |
| --- | --- | --- | --- | --- | --- |
| 二分法 | 是 | 否 | 1 | 1（误差减半） | 慢；偶重根无法启动 |
| 不动点迭代 | 否 | 否 | 1 | 1（\(g'(p)\ne0\)） | \(k\) 接近 1 时极慢；可能发散 |
| Newton 法 | 否 | 是 | 2 | 2 | 局部；导数接近零；重根退化 |
| 割线法 | 否 | 否 | 1 | \(\phi\approx1.618\) | 需要两个好初值；可能发散 |
| 试位法 | 是 | 否 | 1 | 通常 1 | 单侧停滞，可能很慢 |
| Steffensen | 否 | 否 | 2 | 2 | \(g'(p)=1\) 时失效；分母过小 |
| 修正 Newton | 否 | 是（含 \(f''\)） | 2 或 3 | 2 | 需知道重数或计算 \(f''\) |

**选用顺序（经验）：**

1. 先画图或扫描，找括号或好初值；
2. 有括号且只求稳：二分法或试位法；
3. 导数容易求：Newton 法；
4. 导数难求：割线法；若已有括号，用试位法；
5. 已有线性收敛的不动点迭代：Aitken 事后加速或 Steffensen 改造；
6. 已知重根：用修正 Newton。

## 坑与陷阱

!!! danger "十二条"
    1. **\(f(a)f(b)<0\) 只保证存在，不保证唯一**；偶重根（如 \(x^2\)）两端同号，二分法根本发现不了。
    2. **二分法误差界是 \((b-a)/2^n\)，不是 \((b-a)/2^{n+1}\)**。索引从 \(n=1\) 开始时，区间长度已经是 \((b-a)/2^{n-1}\)，再取一半才是误差界。
    3. **\(|f(p)|<\varepsilon\) 不是误差界**。函数在根附近很平时，\(f\) 很小但 \(p\) 可能离根很远。
    4. **不动点定理要求 \(g\) 把区间映到自身**。只验证 \(|g'(p)|<1\) 只能得到局部收敛，不能保证从任意 \(p_0\in[a,b]\) 出发都收敛。
    5. **\(k\) 接近 1 时不动点迭代极慢**；\(k<0\) 时误差变号，迭代值在根两侧摆动，不代表发散。
    6. **Newton 的二次收敛是局部的**，且要求 \(f'(p)\ne0\)。初值不好会发散、跳到别的根或进入循环。
    7. **重根让 Newton 退化为线性**：\(g'(p)=1-1/m\)。不要看到"用了 Newton"就以为一定二次。
    8. **\(f'(p_n)\) 很小时 Newton 步长巨大**，可能溢出；实现中要检查分母。
    9. **割线法的 \(1.618\) 阶需要两个都靠近根的初值**；它不是全局收敛，也不保括号。
    10. **试位法虽然保括号，但可能单侧停滞**，收敛比二分法还慢；必要时用 Illinois 修正。
    11. **Aitken/Steffensen 的分母 \(\Delta^2p_n\) 接近零时会数值爆炸**，不要对噪声大的序列盲目加速。
    12. **有限精度会封顶**：无论二次收敛多快，误差降到舍入水平后就不再下降；迭代到"两步完全相同"时应停止，而不是继续追求更小误差。

## 速览

1. 极值定理 → Rolle → 中值定理，是误差估计的主链条；介值定理负责存在性；Taylor 定理负责 Newton 的推导与误差。
2. 二分法：初始括号 \(f(a)f(b)<0\)，误差界 \(|p_n-p|\le(b-a)/2^n\)，迭代次数 \(n\ge\lceil\log_2((b-a)/\varepsilon)\rceil\)。
3. 二分法绝对可靠但只有线性收敛，适合提供初值或括号，不适合单独追求高精度。
4. 不动点迭代：把 \(f(x)=0\) 改写成 \(x=g(x)\)；若 \(g\) 把区间映到自身且 \(|g'|\le k<1\)，则从任意初值收敛，误差按 \(k^n\) 衰减。
5. 先验估计 \(|p_n-p|\le\frac{k^n}{1-k}|p_1-p_0|\)；后验估计 \(|p_n-p|\le\frac{k}{1-k}|p_n-p_{n-1}|\)。
6. 不动点迭代的渐近常数是 \(|g'(p)|\)：越接近 0 越快；等于 0 时至少二次。
7. Newton 法：\(p_n=p_{n-1}-f(p_{n-1})/f'(p_{n-1})\)，几何上是切线零点。
8. Newton 局部收敛定理：\(g(x)=x-f/f'\)，\(g'(p)=0\)，在根附近构成压缩映射。
9. Newton 二次收敛：\(e_{n+1}=-\frac{f''(\xi_n)}{2f'(p_n)}e_n^2\)，渐近常数 \(\frac{|f''(p)|}{2|f'(p)|}\)；正确数字每步翻倍。
10. Newton 的弱点：要导数、局部收敛、导数接近零、重根退化、不保括号。
11. 割线法用差商代替导数，每步一个新函数值，误差 \(e_{n+1}\approx A e_ne_{n-1}\)，阶 \(\phi=(1+\sqrt5)/2\approx1.618\)。
12. 试位法把割线装进括号，保收敛但通常线性，可能单侧停滞；Illinois 修正可缓解。
13. 重根 \(m\)：Newton 退化到线性；已知 \(m\) 用 \(x-mf/f'\)，未知 \(m\) 用 \(x-ff'/((f')^2-ff'')\)，均恢复二次。
14. Aitken \(\Delta^2\)：\(\hat p_n=p_n-(\Delta p_n)^2/\Delta^2p_n\)，对纯几何误差可精确消去主项。
15. Steffensen：把 Aitken 嵌入不动点迭代，\(p_{n+1}=p_n-[g(p_n)-p_n]^2/[g(g(p_n))-2g(p_n)+p_n]\)，无需导数即可二次收敛（\(g'(p)\ne1\)）。
