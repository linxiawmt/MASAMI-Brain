# 计算光学与全息

从傅里叶光学到光波传播数值仿真，再到光学扫描全息——三本经典 MATLAB 教材的精读笔记。**本栏目代码均为 MATLAB + Python 双实现**（页面内 tab 切换，仓库 `matlab/` 与 `python/` 文件夹同步存放），物理量纲与采样约定在注释中逐一对齐。

<div class="grid cards" markdown>

-   **计算傅里叶光学**

    ---

    Voelz《Computational Fourier Optics: A MATLAB Tutorial》(SPIE TT89)。
    解析傅里叶理论 → 采样与定标 → 菲涅耳/角谱传播 → 成像系统 → 部分相干。

    [:octicons-arrow-right-24: 进入](fourier/ch1.md)

-   **光波传播数值模拟**

    ---

    Schmidt《Numerical Simulation of Optical Wave Propagation》(SPIE PM199)。
    标量衍射理论 → 传播算子数值实现 → 湍流与自适应 optics 仿真基础。

    [:octicons-arrow-right-24: 进入](waveprop/ch1.md)

-   **光学扫描全息**

    ---

    Poon《Optical Scanning Holography with MATLAB》(Springer)。
    全息基础 → 扫描全息原理 → 外差检测 → 全息显示与应用。

    [:octicons-arrow-right-24: 进入](scanholo/ch1.md)

</div>
