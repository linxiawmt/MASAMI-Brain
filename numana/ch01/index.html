    第 1 章 引言：误差、算法与收敛#

    本章解决：数值分析的基本问题——用有限步浮点运算近似求解连续数学问题。介绍了数值计算的四个典型问题（线性方程组、非线性方程、数值微分与积分、偏微分方程），以及贯穿全学科的核心概念：误差来源、有效数字、IEEE 浮点算术、误差传播与条件数、算法稳定性、Big-O 与收敛阶。学完能从误差、条件数、稳定性与收敛速度四个维度判断一个数值方法是否可用。

    本栏目笔记依据浙江大学 Qiwei Zhan 教授《Numerical Analysis》课程课件（Lec01–13）整理，课件原文见各章末链接。

    1.1 四个问题与课程目标#

    1.1.1 四个典型问题#

    课件用四个问题说明"为什么需要数值方法"。

    Q1：解线性方程组。 给定 \(A\in\mathbb{R}^{n\times n}\) 与 \(\mathbf{b}\in\mathbb{R}^n\)，求 \(\mathbf{x}\) 使

    \[ A\mathbf{x}=\mathbf{b}. \]

    Cramer 法则需要约 \(n!\) 次运算，\(n=30\) 时已不可行；Gauss 消元约 \(2n^3/3\) 次，且必须选主元才能控制舍入误差。同一个问题的不同算法，代价与精度可以差很多个数量级。

    Q2：解非线性方程。 求 \(x\) 使

    \[ x=(x+1)^{1/2}+x^{1/3}. \]

    这是不动点形式 \(x=g(x)\)，通常用迭代逼近；迭代是否收敛、收敛多快，是后面要回答的问题。

    Q3：算一个积分。 无线信道容量可写成

    \[ C=\int_0^\infty \log(1+x)\exp(-x)\,dx . \]

    被积函数没有初等原函数，无穷区间还要截断。数值积分必须同时处理"截断到有限区间"和"用有限个函数值近似积分"两种误差。

    Q4：解偏微分方程。 引导深度上采样模型为

    \[ \frac{\partial D(p;t)}{\partial t}=\operatorname{div}\big(W(p;t)\nabla D(p;t)\big), \qquad D(p;0)=D_0(p). \]

    空间、时间都要离散；离散格式是否稳定、是否收敛到真解，决定了结果能不能用。

    1.1.2 课程目标#

    本课程介绍四类问题的实用数值方法：

    • 线性方程组的直接法与迭代法；
    • 非线性方程与方程组的求根；
    • 数值微分与数值积分；
    • 偏微分方程的差分与有限元方法。

    每引入一个方法，都配套四件事：误差从哪来、问题本身是否病态、算法是否稳定、收敛有多快。这四件事比公式本身更重要。

    1.2 误差从哪里来#

    1.2.1 四类误差#

    1. 模型误差：用数学模型近似真实系统。例如把黏性流体当成无黏流，或把分布参数系统集总成有限维。
    2. 数据误差：输入数据本身带测量噪声或舍入。例如 \(\mathbf{b}\) 的每个分量只有 3 位有效数字。
    3. 截断误差：用有限过程代替极限过程。Taylor 展开只取前几项、积分用有限和代替、导数用差商代替，都会留下余项。
    4. 舍入误差：计算机只能表示有限个浮点数，每次运算都要把精确结果舍入到最近的浮点数。

    四类误差在总误差中按三角不等式叠加：

    \[ \|x_{\text{计算}}-x_{\text{真}}\|\le \|x_{\text{模型}}-x_{\text{真}}\|+ \|x_{\text{数据}}-x_{\text{模型}}\|+ \|x_{\text{离散}}-x_{\text{数据}}\|+ \|x_{\text{舍入}}-x_{\text{离散}}\|. \]

    前三项属于"方法"，最后一项属于"计算机"。本章主要讨论后两项，以及它们如何被问题本身放大。

    1.2.2 截断与舍入的权衡#

    截断误差随步长 \(h\) 减小而减小，舍入误差随运算次数增加而增大。以差商近似导数为例，总误差大致是

    \[ E(h)\approx C h^p+\frac{\varepsilon}{h}, \]

    其中 \(\varepsilon\) 是单位舍入误差。令导数为零：

    \[ E'(h)=Cph^{p-1}-\frac{\varepsilon}{h^2}=0 \quad\Longrightarrow\quad h^{p+1}=\frac{\varepsilon}{Cp}, \]

    即最优步长

    \[ h_*=\left(\frac{\varepsilon}{Cp}\right)^{1/(p+1)}, \qquad E(h_*)=O\!\left(\varepsilon^{\,p/(p+1)}\right). \]

    结论：不是 \(h\) 越小越好。步长小到一定程度后，舍入误差接管，结果反而变差。这也是"数值方法不能盲目加密"的最早提醒。

    1.3 绝对误差、相对误差与有效数字#

    1.3.1 两种误差#

    设 \(p^*\) 是精确值 \(p\) 的近似。绝对误差与相对误差分别定义为

    \[ e_{\mathrm{abs}}(p^*)=|p-p^*|, \qquad e_{\mathrm{rel}}(p^*)=\frac{|p-p^*|}{|p|}\quad(p\ne0). \]

    绝对误差带量纲，相对误差无量纲。判断"算得准不准"通常看相对误差：\(p=10^9\) 时误差 \(1\) 微不足道，\(p=1\) 时误差 \(1\) 就是 100%。

    1.3.2 有效数字的定义#

    课件采用如下定义：若 \(k\) 是使

    \[ \frac{|p-p^*|}{|p|}\le5\times10^{-k} \]

    成立的最大非负整数，则称 \(p^*\) 近似 \(p\) 到 \(k\) 位有效数字（significant digits）。

    这里的 \(5\times10^{-k}\) 不是随手取的：它正好对应"第 \(k\) 位有效数字的半个单位"。把 \(p\) 写成规格化形式

    \[ p=0.d_1d_2d_3\cdots\times10^n,\qquad d_1\ne0, \]

    则 \(10^{n-1}\le|p|<10^n\)。第 \(k\) 位数字 \(d_k\) 的位值是 \(10^{n-k}\)，半个单位就是 \(5\times10^{n-k-1}\)。下面的定理把这件事说清楚。

    1.3.3 相对误差与有效数字的关系#

    定理 1.1. 设 \(p=0.d_1d_2\cdots\times10^n\)，\(d_1\ne0\)。若

    \[ \frac{|p-p^*|}{|p|}\le5\times10^{-k}, \]

    则

    \[ |p-p^*|\le\frac12\,10^{n-k}. \]

    反之，若 \(p^*\) 是把 \(p\) 四舍五入到 \(k\) 位有效数字的结果，则

    \[ \frac{|p-p^*|}{|p|}\le5\times10^{-k}. \]

    证明. 前半：由 \(|p|<10^n\)，

    \[ |p-p^*|\le5\times10^{-k}|p|<5\times10^{-k}\cdot10^n=\frac12\,10^{n-k}. \]

    这正是第 \(k\) 位上的半个单位，说明 \(p^*\) 落在"把 \(p\) 舍入到第 \(k\) 位"的误差带内。

    后半：把 \(p\) 舍入到 \(k\) 位，误差不超过第 \(k\) 位的半个单位，即

    \[ |p-p^*|\le5\times10^{n-k-1}. \]

    又 \(|p|\ge10^{n-1}\)，相除得

    \[ \frac{|p-p^*|}{|p|}\le\frac{5\times10^{n-k-1}}{10^{n-1}}=5\times10^{-k}. \]

    证毕。

    边界上的细节

    不等式只保证"误差不超过第 \(k\) 位的半个单位"，在 \(0.99995\) 与 \(1.0000\) 这种进位边界上，逐位数字串可能看起来"不一样"，但按上面的定义仍然是 \(k\) 位有效数字。写程序判断有效数字时，应比较误差界，不要逐字符比较。

    推论. 相对误差 \(10^{-d}\) 大约对应 \(d\) 位正确的十进制数字；反过来，想要 \(k\) 位有效数字，相对误差必须控制在 \(5\times10^{-k}\) 以内。

    1.4 浮点数与计算机算术#

    1.4.1 IEEE 754 二进制浮点#

    课件给出双精度的位布局：1 位符号、11 位阶码、52 位尾数（共 8 字节）；单精度是 1 位符号、8 位阶码、23 位尾数（共 4 字节）。MATLAB 的默认数值类型是 double，C 的 double 也是 8 字节，float 对应单精度。

    格式 总位数 符号 \(s\) 阶码 \(c\) 尾数 \(f\) 偏置
    单精度 32 1 8 23 127
    双精度 64 1 11 52 1023

    规格化数的值为

    \[ x=(-1)^s\,2^{\,c-\text{bias}}\,(1+f), \qquad f=\sum_{i=1}^{t}b_i2^{-i}, \]

    其中 \(t=52\)（双精度）或 \(t=23\)（单精度）。尾数前隐含一个 1，所以二进制有效位数是 \(t+1\)。

    课件中的例子

    0 10000000011 101110...0

    表示 \(s=0\)、\(c=1027\)、指数 \(1027-1023=4\)，尾数为 \(1.10111\ldots_2\)，即 \(2^4(1.10111\ldots)_2\)。

    双精度的范围：

    \[ x_{\max}=2^{1023}\left(2-2^{-52}\right)\approx1.7977\times10^{308}, \]
    \[ x_{\min}=2^{-1022}\approx2.2251\times10^{-308}. \]

    课件把这两个数写成 \(0.17977\times10^{309}\) 与 \(0.22251\times10^{-307}\)，只是小数点位置不同，数值完全一样。

    • 上溢（overflow）：结果超过 \(x_{\max}\)，通常得到 \(\pm\infty\) 或报错。
    • 下溢（underflow）：结果小于 \(x_{\min}\)，进入次正规数（gradual underflow），最终变成 0。
    • 特殊值：阶码全 0 表示次正规数或 0；阶码全 1 表示 \(\pm\infty\) 或 NaN。

    单精度的对应量是 \(x_{\max}\approx3.4028\times10^{38}\)、\(x_{\min}\approx1.1755\times10^{-38}\)。

    1.4.2 浮点间距与机器 epsilon#

    浮点数在实轴上不是均匀分布的：数越大，间距越大。

    定理 1.2. 对双精度浮点数，若 \(x\in[2^e,2^{e+1})\)，则该 binade 内相邻浮点数的间距为

    \[ \Delta(x)=2^{e-52}. \]

    证明. 该区间内的数可写成 \(x=2^e(1+f)\)，其中 \(f=m/2^{52}\)，\(m=0,1,\dots,2^{52}-1\)。于是

    \[ x=2^e+\frac{m}{2^{52}}2^e=2^e+m\,2^{e-52}, \]

    相邻两个数正好相差 \(2^{e-52}\)。在 \(x=1\)（即 \(e=0\)）处，间距为 \(2^{-52}\)。证毕。

    定理 1.3（相对舍入误差界）. 对规格化范围内的 \(x\)，就近舍入满足

    \[ \frac{|\mathrm{fl}(x)-x|}{|x|}\le2^{-53}=:u, \]

    而向零截断满足

    \[ \frac{|\mathrm{fl}(x)-x|}{|x|}\le2^{-52}. \]

    证明. 设 \(x\in[2^e,2^{e+1})\)。就近舍入的绝对误差不超过半个间距：

    \[ |\mathrm{fl}(x)-x|\le\frac12\Delta(x)=2^{e-53}. \]

    又 \(|x|\ge2^e\)，故

    \[ \frac{|\mathrm{fl}(x)-x|}{|x|}\le\frac{2^{e-53}}{2^e}=2^{-53}. \]

    截断误差小于一个间距 \(2^{e-52}\)，除以 \(|x|\ge2^e\) 得小于 \(2^{-52}\)。证毕。

    机器 epsilon. 定义

    \[ \varepsilon_{\mathrm{mach}}=2^{-52}\approx2.220446049250313\times10^{-16}, \]

    它是 \(1\) 与下一个双精度数之间的距离，也就是 MATLAB 的 eps。而单位舍入误差是

    \[ u=\frac{\varepsilon_{\mathrm{mach}}}{2}=2^{-53}\approx1.110223024625157\times10^{-16}. \]

    两者相差一倍，很多教材都叫"machine epsilon"，读文献时必须看清定义。

    十进制有效位数约为

    \[ \log_{10}\frac1u\approx15.95, \]

    所以双精度能给出 15 到 16 位十进制有效数字。

    % 双精度浮点的几个关键量
fprintf('eps     = %.20g\n', eps);       % 2^-52，1 处的浮点间距
fprintf('eps/2   = %.20g\n', eps/2);     % 2^-53，单位舍入误差 u
fprintf('realmin = %.20g\n', realmin);   % 2^-1022，最小正规数
fprintf('realmax = %.20g\n', realmax);   % 最大有限数

x = 8;
fprintf('eps(8)  = %.20g\n', eps(x));    % 8*2^-52 = 2^-49，间距随数量级增大

    eps 不是最小正数

    eps 是 \(1\) 处的间距，约 \(2.2\times10^{-16}\)。最小正规数是 realmin \(\approx2.2\times10^{-308}\)，最小次正规数约 \(4.9\times10^{-324}\)。三者不要混。

    1.4.3 十进制 k 位浮点#

    课件的十进制模型是

    \[ y=\pm0.d_1d_2\cdots d_kd_{k+1}\cdots\times10^n, \qquad 1\le d_1\le9,\quad 0\le d_i\le9. \]

    用 \(k\) 位表示 \(y\) 有两种方式。

    截断（chopping）：直接丢掉第 \(k\) 位之后的数字，

    \[ \mathrm{fl}(y)=0.d_1d_2\cdots d_k\times10^n. \]

    舍入（roundoff）：先加 \(5\times10^{n-k-1}\)，再截断，

    \[ \mathrm{fl}(y)=0.\delta_1\delta_2\cdots\delta_k\times10^n. \]

    误差界如下：

    \[ |\mathrm{fl}(y)-y|<10^{n-k}, \qquad \frac{|\mathrm{fl}(y)-y|}{|y|}<10^{-k+1} \quad\text{(截断)}, \]
    \[ |\mathrm{fl}(y)-y|\le5\times10^{n-k-1}, \qquad \frac{|\mathrm{fl}(y)-y|}{|y|}\le5\times10^{-k} \quad\text{(舍入)}. \]

    证明. 截断时，被丢掉的尾部是

    \[ 0.d_{k+1}d_{k+2}\cdots\times10^{n-k}<10^{n-k}. \]

    又 \(|y|\ge10^{n-1}\)，所以相对误差小于

    \[ \frac{10^{n-k}}{10^{n-1}}=10^{-k+1}. \]

    舍入时，加 \(5\times10^{n-k-1}\) 再截断，等价于舍入到第 \(k\) 位，误差不超过该位的半个单位，即 \(5\times10^{n-k-1}\)。相对误差不超过

    \[ \frac{5\times10^{n-k-1}}{10^{n-1}}=5\times10^{-k}. \]

    证毕。

    例. \(y=0.123456\)，取 \(k=4\)。截断得 \(0.1234\)，绝对误差 \(5.6\times10^{-5}\)，相对误差 \(4.5\times10^{-4}<10^{-3}\)；舍入得 \(0.1235\)，绝对误差 \(4.4\times10^{-5}\)，相对误差 \(3.6\times10^{-4}<5\times10^{-4}\)。两者都满足上面的界。

    1.5 浮点运算与误差传播#

    1.5.1 浮点运算模型#

    课件把机器运算写成

    \[ x\oplus y=\mathrm{fl}\big(\mathrm{fl}(x)+\mathrm{fl}(y)\big), \qquad x\ominus y=\mathrm{fl}\big(\mathrm{fl}(x)-\mathrm{fl}(y)\big), \]
    \[ x\otimes y=\mathrm{fl}\big(\mathrm{fl}(x)\times\mathrm{fl}(y)\big), \qquad x\oslash y=\mathrm{fl}\big(\mathrm{fl}(x)\div\mathrm{fl}(y)\big). \]

    对加减乘除统一写成

    \[ \mathrm{fl}(x\circ y)=(x\circ y)(1+\delta), \qquad |\delta|\le u, \]

    其中 \(u=2^{-53}\) 是单位舍入误差。这个模型假设每次运算只舍入一次、不溢出、不下溢；实际硬件可能用扩展精度，连续两次舍入会带来更细的偏差，但一阶分析用这个模型足够。

    1.5.2 四则运算的误差#

    设输入已经带舍入误差：\(\mathrm{fl}(x)=x(1+\delta_x)\)，\(\mathrm{fl}(y)=y(1+\delta_y)\)，\(|\delta_x|,|\delta_y|\le u\)。

    加减法：绝对误差相加。 以减法为例，

    \[ \mathrm{fl}(x)-\mathrm{fl}(y) =(x-y)+(x\delta_x-y\delta_y). \]

    于是

    \[ |\mathrm{fl}(\mathrm{fl}(x)-\mathrm{fl}(y))-(x-y)|\le u(|x|+|y|)+u|x-y|+O(u^2). \]

    相对误差为

    \[ \frac{|\mathrm{fl}(\mathrm{fl}(x)-\mathrm{fl}(y))-(x-y)|}{|x-y|} \le u\,\frac{|x|+|y|}{|x-y|}+u+O(u^2). \]

    乘除法：相对误差相加。 若 \(x,y\) 本身是浮点数，则

    \[ \mathrm{fl}(xy)=xy(1+\delta), \qquad \frac{|\mathrm{fl}(xy)-xy|}{|xy|}\le u. \]

    若还计入输入的舍入，则

    \[ \frac{|\mathrm{fl}(xy)-xy|}{|xy|} \le|\delta_x|+|\delta_y|+u+O(u^2). \]

    除法同理，只是 \(y\) 的误差取负号：

    \[ \frac{|\mathrm{fl}(x/y)-x/y|}{|x/y|} \le|\delta_x|+|\delta_y|+u+O(u^2). \]

    记住这条分工

    加减法保绝对误差（误差按绝对值相加），乘除法保相对误差（相对误差按加法累积）。所以"大数相减"最危险，"大数相乘"通常没事。

    1.5.3 相消：有效数字的丢失#

    课件给出十进制相消的典型画面。设

    \[ \mathrm{fl}(x)=0.d_1d_2\cdots d_p\alpha_{p+1}\cdots\alpha_k\times10^n, \]
    \[ \mathrm{fl}(y)=0.d_1d_2\cdots d_p\beta_{p+1}\cdots\beta_k\times10^n. \]

    两者前 \(p\) 位相同，相减后

    \[ \mathrm{fl}\big(\mathrm{fl}(x)-\mathrm{fl}(y)\big) =0.\sigma_{p+1}\sigma_{p+2}\cdots\sigma_k\times10^{n-p}. \]

    前 \(p\) 位被消掉，结果只剩 \(k-p\) 位有效数字。原来 \(k\) 位的输入，误差在末位量级 \(10^{n-k}\)，相减后结果量级只有 \(10^{n-p}\)，相对误差被放大到

    \[ \frac{10^{n-k}}{10^{n-p}}=10^{p-k} \]

    的量级。\(p\) 越接近 \(k\)，损失越严重。这就是灾难性相消（catastrophic cancellation）。

    课件用一组五位数演示：

    运算 五位截断结果 精确值 绝对误差 相对误差
    \(x\ominus u\) \(0.30000\times10^{-4}\) \(0.34714\times10^{-4}\) \(0.471\times10^{-5}\) \(0.136\)
    \((x\ominus u)\oplus w\) \(0.27000\times10^{1}\) \(0.31242\times10^{1}\) \(0.424\) \(0.136\)
    \((x\ominus u)\otimes v\) \(0.29629\times10^{1}\) \(0.34285\times10^{1}\) \(0.465\) \(0.136\)
    \(u\oplus v\) \(0.98765\times10^{5}\) \(0.98766\times10^{5}\) \(0.161\times10^{1}\) \(0.163\times10^{-4}\)

    其中

    \[ x=5/7,\quad u=0.714251,\quad v=98765.9,\quad w=0.111111\times10^{-4}. \]

    读表要点：

    • \(x\ominus u\) 的精确值约 \(3.47\times10^{-5}\)，而 \(x,u\) 都是 \(0.7\) 量级，前四位全部消掉，结果只剩一位有效数字，相对误差 13.6%。
    • 再加 \(w=1.11\times10^{-5}\) 也救不回来，因为 \(w\) 与被消剩的差同量级，误差仍在 13.6%。
    • 乘以 \(v\) 只放大绝对误差，不改变相对误差，仍是 13.6%。
    • 对照 \(u\oplus v\)：没有相消，相对误差只有 \(1.6\times10^{-5}\)。

    1.5.4 二次求根的稳定算法#

    课件用方程

    \[ x^2+62.10x+1=0 \]

    演示相消的破坏力。两个根约为

    \[ x_1=-0.01610723,\qquad x_2=-62.08390. \]

    用四位舍入算术和标准求根公式

    \[ x_{1,2}=\frac{-b\pm\sqrt{b^2-4ac}}{2a}, \]

    先算判别式 \(\sqrt{b^2-4ac}\approx62.06\)，再算

    \[ \mathrm{fl}(x_1)=\frac{-62.10+62.06}{2.000}=-0.02000. \]

    分子是两个大数之差，只剩一位有效数字；相对误差

    \[ \frac{|-0.01611+0.02000|}{|-0.01611|}\approx2.4\times10^{-1}. \]

    把公式改写成

    \[ x_1=\frac{-2c}{b+\sqrt{b^2-4ac}}, \]

    同样的四位算术给出

    \[ \mathrm{fl}(x_1)=\frac{-2.000}{62.10+62.06}=-0.01610, \]

    这里 \(62.10+62.06\) 在四位算术中先舍入为 \(124.2\)，再算 \(2.000/124.2\)。相对误差降到 \(6.2\times10^{-4}\)。推导只需分子分母同乘 \(b+\sqrt{b^2-4ac}\)：

    \[ \frac{-b+\sqrt{b^2-4ac}}{2a} =\frac{(-b+\sqrt{b^2-4ac})(b+\sqrt{b^2-4ac})}{2a(b+\sqrt{b^2-4ac})} =\frac{-4ac}{2a(b+\sqrt{b^2-4ac})} =\frac{-2c}{b+\sqrt{b^2-4ac}}. \]

    分子的 \(b^2\) 与 \(b^2-4ac\) 相消，避开了大数相减。先想清楚再计算（think before you compute），比换更快的机器有效得多。

    function [x1, x2] = quad_roots(a, b, c)
% 数值稳定的二次求根，要求 a ~= 0
d = sqrt(b^2 - 4*a*c);
if b >= 0
    q = -0.5 * (b + d);      % 同号相加，避免 -b 与 d 相消
else
    q = -0.5 * (b - d);
end
x1 = q / a;                  % 模较大的根
x2 = c / q;                  % 由 x1*x2 = c/a 得另一根
end

    1.5.5 多元函数的误差传播#

    设 \(y=f(x_1,\dots,x_n)\)，计算值为 \(f(\tilde x_1,\dots,\tilde x_n)\)，其中 \(\tilde x_i=x_i+\Delta x_i\)。假设 \(f\in C^2\)、扰动足够小，Taylor 展开到一阶：

    \[ f(\tilde x_1,\dots,\tilde x_n)-f(x_1,\dots,x_n) =\sum_{i=1}^{n}\frac{\partial f}{\partial x_i}\Delta x_i +O\!\left(\|\Delta x\|^2\right). \]

    于是绝对误差界为

    \[ |\Delta y|\le\sum_{i=1}^{n}\left|\frac{\partial f}{\partial x_i}\right||\Delta x_i| +O\!\left(\|\Delta x\|^2\right), \]

    相对误差界为

    \[ \frac{|\Delta y|}{|y|} \le\sum_{i=1}^{n} \left|\frac{x_i}{y}\frac{\partial f}{\partial x_i}\right| \frac{|\Delta x_i|}{|x_i|} +O\!\left(\|\Delta x\|^2\right). \]

    括号中的量

    \[ c_i=\left|\frac{x_i}{f}\frac{\partial f}{\partial x_i}\right| \]

    是第 \(i\) 个输入的相对敏感度。它把"输入的相对误差"换算成"输出的相对误差"，下一节的条件数就是它的单变量版本。

    1.6 条件数与稳定性#

    1.6.1 问题的条件数#

    对单变量问题 \(y=f(x)\)，定义条件数

    \[ \kappa_f(x)=\left|\frac{x f'(x)}{f(x)}\right|. \]

    推导. 输入 \(x\) 有相对扰动 \(\Delta x/x\)，输出变化为

    \[ f(x+\Delta x)-f(x)\approx f'(x)\Delta x. \]

    两边除以 \(f(x)\)：

    \[ \frac{f(x+\Delta x)-f(x)}{f(x)} \approx\frac{x f'(x)}{f(x)}\cdot\frac{\Delta x}{x}. \]

    取绝对值即得 \(\kappa_f\)。它表示"输入的相对误差被放大多少倍传到输出"。

    • \(f(x)=\sqrt{x}\)：\(\kappa=1/2\)，误差反而缩小一半，问题良态。
    • \(f(x)=1/(1-x)\)，\(x\to1\)：\(\kappa=|x/(1-x)|\to\infty\)，问题病态。
    • \(f(x)=x_1-x_2\)：\(\kappa=(|x_1|+|x_2|)/|x_1-x_2|\)，相消就是病态问题。

    条件数是问题的属性

    \(\kappa_f\) 只依赖 \(f\) 和 \(x\)，与你用哪种算法无关。算法再好也不能把病态问题变成良态问题，只能避免额外放大误差。

    1.6.2 线性方程组的条件数#

    对 \(A\mathbf{x}=\mathbf{b}\)，定义

    \[ \kappa(A)=\|A\|\,\|A^{-1}\|. \]

    设 \(\mathbf{b}\) 有扰动 \(\Delta\mathbf{b}\)，解有扰动 \(\Delta\mathbf{x}\)，则

    \[ \frac{\|\Delta\mathbf{x}\|}{\|\mathbf{x}\|} \le\kappa(A)\frac{\|\Delta\mathbf{b}\|}{\|\mathbf{b}\|}. \]

    证明. 由 \(A\Delta\mathbf{x}=\Delta\mathbf{b}\) 得 \(\Delta\mathbf{x}=A^{-1}\Delta\mathbf{b}\)，所以

    \[ \|\Delta\mathbf{x}\|\le\|A^{-1}\|\,\|\Delta\mathbf{b}\|. \]

    又 \(\|\mathbf{b}\|=\|A\mathbf{x}\|\le\|A\|\,\|\mathbf{x}\|\)，即

    \[ \frac{1}{\|\mathbf{x}\|}\le\frac{\|A\|}{\|\mathbf{b}\|}. \]

    两式相乘：

    \[ \frac{\|\Delta\mathbf{x}\|}{\|\mathbf{x}\|} \le\|A^{-1}\|\,\|\Delta\mathbf{b}\|\cdot\frac{\|A\|}{\|\mathbf{b}\|} =\kappa(A)\frac{\|\Delta\mathbf{b}\|}{\|\mathbf{b}\|}. \]

    证毕。

    \(\kappa(A)\ge1\)，且 \(\kappa(I)=1\)。若 \(\kappa(A)=10^6\)，即使右端只有 \(10^{-16}\) 的相对扰动，解的相对误差也可能达到 \(10^{-10}\)，大约损失 6 位十进制有效数字。这是"解线性方程组会丢位数"的根本原因，不是某个算法的 bug。

    1.6.3 稳定性与误差增长#

    课件给出稳定性的定义：

    • 稳定（stable）：初始数据的小变化只引起最终结果的小变化。
    • 不稳定（unstable）或条件稳定（conditionally stable）：对全部或部分初始数据，小误差会导致最终结果的大误差。

    稳定性是算法的属性，条件数是问题的属性。一个稳定的算法作用在病态问题上，误差仍会被放大 \(\kappa\) 倍；一个不稳定的算法即使在良态问题上也会把误差放大到不可接受。

    误差随运算步数的增长有两种基本形态：

    \[ E_n\approx CnE_0\quad\text{（线性增长）}, \qquad E_n\approx C^nE_0\quad\text{（指数增长）}. \]

    指数情形中若 \(C>1\)，误差会在几十步内吞掉全部有效数字；若 \(0<C<1\)，误差指数衰减，这是好事。

    例：一个不稳定的递推. 令

    \[ I_n=\int_0^1\frac{x^n}{x+10}\,dx . \]

    因为

    \[ I_n+10I_{n-1} =\int_0^1\frac{x^n+10x^{n-1}}{x+10}\,dx =\int_0^1x^{n-1}\,dx =\frac1n, \]

    所以

    \[ I_n=\frac1n-10I_{n-1}. \]

    设 \(I_{n-1}\) 有误差 \(E_{n-1}\)，则 \(E_n=-10E_{n-1}\)，即

    \[ |E_n|=10^n|E_0|, \]

    指数增长，正向递推不稳定。反过来解出

    \[ I_{n-1}=\frac1{10}\left(\frac1n-I_n\right), \]

    误差满足 \(|E_{n-1}|=|E_n|/10\)，反向递推稳定。实际计算时从较大的 \(N\) 开始反向递推，初值可用

    \[ I_N\approx\frac{1}{10(N+1)} \]

    近似（因为 \(1/(x+10)\approx1/10\)），其误差不超过 \(1/(100(N+2))\)，再被反向递推逐步缩小。

    1.7 算法、Big-O 与收敛#

    1.7.1 算法的评价标准#

    课件把算法定义为一个操作序列：

    An algorithm is a set of operations to solve a problem or approximate a solution to the problem.

    评价一个算法至少看五件事：

    1. 正确性：在精确算术下是否给出真解。
    2. 精度：舍入与截断后误差多大，是否满足容差。
    3. 效率：时间复杂度和空间复杂度，随问题规模怎么增长。
    4. 稳定性：输入小扰动是否被放大。
    5. 收敛性：迭代法是否收敛，收敛多快。

    前两条决定"能不能用"，后三条决定"好不好用"。

    1.7.2 Big-O 记号与增长率比较#

    定义（序列）. 若存在常数 \(C>0\) 和 \(N\)，使得对所有 \(n\ge N\) 有

    \[ |f(n)|\le C|g(n)|, \]

    则记 \(f(n)=O(g(n))\)。若 \(f=O(g)\) 且 \(g=O(f)\)，记 \(f(n)=\Theta(g(n))\)。若

    \[ \lim_{n\to\infty}\frac{f(n)}{g(n)}=0, \]

    记 \(f(n)=o(g(n))\)。

    定义（函数）. 若存在 \(K>0\)，使得对足够小的 \(h\) 有

    \[ |F(h)-L|\le K|G(h)|, \]

    则记

    \[ F(h)=L+O(G(h)). \]

    数值分析中最常见的是 \(G(h)=h^p\)，此时 \(p\) 就是误差的阶。

    增长率的层级. 对 \(0<\epsilon<p<q\)、\(a>1\)，有

    \[ 1\ll\log\log n\ll\log n\ll n^{\epsilon}\ll n^{p}\ll n^{q}\ll a^{n}\ll n!\ll n^{n}. \]

    这里 \(\ll\) 表示"前者被后者压住"，即前者除以后者趋于 0。下面证明三个关键环节。

    (1) \(\log n=o(n^{\epsilon})\). 令 \(t=\log n\)。由指数函数的 Taylor 级数，

    \[ e^{\epsilon t}\ge\frac{(\epsilon t)^2}{2}, \]

    所以

    \[ 0\le\frac{\log n}{n^{\epsilon}} =\frac{t}{e^{\epsilon t}} \le\frac{2}{\epsilon^2t}\to0. \]

    因此对数增长比任何正幂次都慢。

    (2) \(n^{p}=o(a^{n})\). 考察相邻两项之比：

    \[ \frac{(n+1)^{p}/a^{n+1}}{n^{p}/a^{n}} =\left(1+\frac1n\right)^{p}\frac1a \longrightarrow\frac1a<1. \]

    比值最终小于某个 \(\rho<1\)，故 \(n^{p}/a^{n}\to0\)，且是几何速度。

    (3) \(a^{n}=o(n!)\). 同样用比值：

    \[ \frac{a^{n+1}/(n+1)!}{a^{n}/n!} =\frac{a}{n+1}\longrightarrow0. \]

    所以阶乘比任何指数都快。

    顺带，\(n!=o(n^{n})\)：因为

    \[ \frac{n!}{n^{n}}=\prod_{k=1}^{n}\frac{k}{n}\le\frac1n\to0. \]

    并且 \(\log(n!)=\Theta(n\log n)\)：上界由 \(n!\le n^{n}\)，下界由 \(n!\ge(n/2)^{n/2}\) 得到。

    Big-O 只是上界

    \(f=O(g)\) 不说明 \(f\) 和 \(g\) 同阶。说"某方法二阶收敛"时，通常指误差确实按 \(h^2\) 的量级下降，且常数不随 \(h\) 爆炸；只说 \(O(h^2)\) 在数学上允许更小的误差，比较算法时要看紧的界和常数。

    观测阶. 若

    \[ F(h)=L+Ch^{p}+O(h^{p+1}), \]

    两边取对数：

    \[ \log|F(h)-L|=\log|C|+p\log h+O(h). \]

    所以 \(\log|F(h)-L|\) 对 \(\log h\) 的斜率就是 \(p\)。用两种步长估计：

    \[ p\approx\frac{\log|F(h)-L|-\log|F(h/2)-L|}{\log2}. \]

    这正是有限元、有限差分做收敛阶验证时画 log-log 图的依据。课件特别提到"take a log operator"，说的就是这件事。

    1.7.3 迭代序列的收敛阶#

    对迭代序列 \(\{x_k\}\)，记误差 \(e_k=x_k-x^*\)。

    线性收敛：

    \[ \lim_{k\to\infty}\frac{|e_{k+1}|}{|e_k|}=C, \qquad 0<C<1. \]

    超线性收敛： 上述比值趋于 0。

    \(p\) 阶收敛：

    \[ \lim_{k\to\infty}\frac{|e_{k+1}|}{|e_k|^{p}}=C<\infty, \qquad p\ge1. \]

    \(p=1\) 是线性收敛（还要求 \(C<1\)），\(p=2\) 是二次收敛。实际证明中常用不带极限的形式：

    \[ |e_{k+1}|\le C|e_k|^{p}. \]

    两种收敛速度不是一回事

    课件第 25 页的定义 \(\alpha_n=\alpha+O(\beta_n)\) 是拿误差与一个给定的参考序列 \(\beta_n\)（如 \(1/n^{p}\)）比较，回答"误差随 \(n\) 以什么幂次衰减"。迭代法的阶 \(p\) 则是拿下一步误差与当前误差的 \(p\) 次方比较，回答"每迭代一次，精度怎么翻倍"。两者都叫 rate of convergence，但坐标轴不同，不要混用。

    1.7.4 线性收敛与二次收敛#

    定理 1.4（二次收敛意味着有效数字翻倍）. 若存在 \(C>0\) 使

    \[ |e_{k+1}|\le C|e_k|^{2}, \]

    且 \(C|e_0|<1\)，则

    \[ |e_k|\le\frac1C\left(C|e_0|\right)^{2^{k}}. \]

    证明. 令 \(q_k=C|e_k|\)。则

    \[ q_{k+1}=C|e_{k+1}|\le C^2|e_k|^2=q_k^2. \]

    反复平方：

    \[ q_k\le q_{k-1}^2\le q_{k-2}^{4}\le\cdots\le q_0^{2^{k}}. \]

    代回 \(q_k=C|e_k|\) 即得

    \[ |e_k|\le\frac1C\left(C|e_0|\right)^{2^{k}}. \]

    证毕。

    若 \(C|e_0|<1\)，则 \(|e_k|\) 大致按 \((C|e_0|)^{2^k}\) 下降。取对数：

    \[ -\log_{10}|e_k| \approx 2^{k}\left(-\log_{10}(C|e_0|)\right), \]

    即每一步正确十进制位数大约翻倍。线性收敛则只有

    \[ |e_k|\le C^{k}|e_0|, \qquad -\log_{10}|e_k|\approx k\left(-\log_{10}C\right), \]

    每步增加固定位数。

    三个例子.

    二分法. 区间长度每步减半，\(|e_k|\le(b-a)/2^{k}\)，线性收敛，\(C=1/2\)。要达到 \(d\) 位十进制精度，约需 \(k\approx3.32d+\log_2(b-a)\) 步。

    不动点迭代. \(x_{k+1}=g(x_k)\)，展开得

    \[ e_{k+1}=g(x^*+e_k)-g(x^*) =g'(x^*)e_k+\frac{g''(\xi)}{2}e_k^2. \]

    若 \(g'(x^*)\ne0\)，线性收敛，\(C=|g'(x^*)|\)；若 \(g'(x^*)=0\)，则至少二次收敛。

    Newton 法. 迭代函数 \(g(x)=x-f(x)/f'(x)\)。在单根 \(f(x^*)=0\)、\(f'(x^*)\ne0\) 处，

    \[ g'(x^*)=\frac{f(x^*)f''(x^*)}{[f'(x^*)]^2}=0, \qquad g''(x^*)=\frac{f''(x^*)}{f'(x^*)}, \]

    所以

    \[ e_{k+1}=\frac{f''(x^*)}{2f'(x^*)}e_k^2+O(e_k^3), \]

    二次收敛。若 \(x^*\) 是重根（\(f'(x^*)=0\)），Newton 法退化为线性收敛，因子 \((m-1)/m\)（\(m\) 为根的重数）。

    观测阶. 用相邻三次误差可以估计阶：

    \[ p\approx \frac{\log\left(|e_{k+1}|/|e_k|\right)} {\log\left(|e_k|/|e_{k-1}|\right)}. \]
    function [x, err] = fixed_point(g, x0, tol, maxit)
% 不动点迭代 x_{k+1} = g(x_k)
% err(k) 记录相邻两次迭代之差，可用于估计收敛阶
x = x0;
err = zeros(maxit, 1);
for k = 1:maxit
    xn = g(x);
    err(k) = abs(xn - x);
    if err(k) < tol
        x = xn;
        err = err(1:k);
        return
    end
    x = xn;
end
warning('fixed_point:notConverged', '未在 maxit 步内收敛');
end

    坑与陷阱#

    八条

    1. 绝对误差小不等于结果好：误差 \(1\) 对 \(10^9\) 是 \(10^{-9}\) 的相对误差，对 \(1\) 就是 100%。先看问题的尺度和相对误差。
    2. 有效数字的阈值是 \(5\times10^{-k}\)，不是 \(10^{-k}\)：它对应第 \(k\) 位的半个单位。只按 \(10^{-k}\) 判断会把有效数字少算约 0.7 位（允许误差被收紧 5 倍）。
    3. eps 不是最小正数：eps 等于 \(2^{-52}\)，是 1 处的浮点间距；最小正规数 realmin \(\approx2.2\times10^{-308}\)，最小次正规数约 \(4.9\times10^{-324}\)。
    4. 相对误差界用 \(u=2^{-53}\)，不是 \(\varepsilon_{\mathrm{mach}}=2^{-52}\)：机器 epsilon 的定义各书不同，写报告时要注明是"间距"还是"单位舍入误差"。
    5. 相消不是减法算错了：IEEE 减法本身可以精确（Sterbenz 引理：\(y/2\le x\le2y\) 时 \(x-y\) 可精确表示），错在输入在减法之前就已经被舍入。改写公式（如稳定二次求根）才是解法。
    6. 条件数与稳定性是两回事：条件数 \(\kappa(A)\)、\(\kappa_f\) 是问题固有的；稳定性是算法属性。稳定算法作用在病态问题上，误差仍会被放大 \(\kappa\) 倍。
    7. 截断误差和舍入误差此消彼长：\(h\) 减小，截断误差降、舍入误差升，存在最优 \(h_*=(\varepsilon/(Cp))^{1/(p+1)}\)。盲目加密网格可能越算越差。
    8. Big-O 与收敛阶不能混用：\(O(h^2)\) 是误差上界，二次收敛是 \(e_{k+1}=O(e_k^2)\) 的自指关系；\(O(1/n^p)\) 的 \(n\) 是网格数，\(e_k\) 的 \(k\) 是迭代步数，两个坐标轴不同。

    速览#

    1. 数值分析的四类问题：线性方程组、非线性方程、微分与积分、偏微分方程；每个方法都要配误差、条件、稳定性、收敛性分析。
    2. 误差四来源：模型、数据、截断、舍入；总误差按三角不等式叠加。
    3. 绝对误差带量纲，相对误差无量纲；判断精度通常看相对误差。
    4. 有效数字：\(|p-p^*|/|p|\le5\times10^{-k}\)，阈值对应第 \(k\) 位的半个单位。
    5. IEEE 双精度：1 位符号、11 位阶码（偏置 1023）、52 位尾数；单精度：1、8（偏置 127）、23。
    6. 双精度范围约 \(10^{-308}\) 到 \(10^{308}\)；阶码全 0 为次正规数，全 1 为 Inf/NaN。
    7. 浮点间距 \(\Delta(x)=2^{e-52}\)（\(x\in[2^e,2^{e+1})\)）；\(\varepsilon_{\mathrm{mach}}=2^{-52}\)，单位舍入误差 \(u=2^{-53}\)。
    8. 十进制 \(k\) 位：截断相对误差 \(<10^{-k+1}\)，舍入相对误差 \(\le5\times10^{-k}\)。
    9. 加减法绝对误差相加，乘除法相对误差相加；相消放大因子 \((|x|+|y|)/|x-y|\)，稳定二次求根避开大数相减。
    10. 条件数衡量问题病态程度，稳定性衡量算法；Big-O 比较增长率，线性收敛每步加固定位数，二次收敛每步位数翻倍。
