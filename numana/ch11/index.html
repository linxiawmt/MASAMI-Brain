    第 11 章 数值积分#

    本章解决：定积分的数值计算问题——被积函数没有初等原函数或只有离散采样值时如何求积。以插值型求积为统一框架，介绍了梯形公式、Simpson 公式与一般 Newton–Cotes 公式、代数精度的概念、复合求积与 Romberg 积分加速。学完能按精度要求选择求积公式并估计截断误差。

    11.1 插值型求积公式#

    11.1.1 构造#

    取区间 \([a,b]\) 上 \(n+1\) 个互异节点 \(x_0,\dots,x_n\)，作 Lagrange 插值多项式

    \[ P_n(x)=\sum_{i=0}^{n} f(x_i)L_i(x),\qquad L_i(x)=\prod_{\substack{j=0\\ j\neq i}}^{n}\frac{x-x_j}{x_i-x_j}. \]

    用 \(P_n\) 代替 \(f\) 积分，并把插值余项一起积进去：

    \[ \int_a^b f(x)\,dx=\int_a^b\sum_{i=0}^{n}f(x_i)L_i(x)\,dx+\int_a^b\prod_{i=0}^{n}(x-x_i)\frac{f^{(n+1)}(\xi(x))}{(n+1)!}\,dx . \]

    记

    \[ \boxed{\ a_i=\int_a^b L_i(x)\,dx\ }\qquad\Longrightarrow\qquad \int_a^b f(x)\,dx=\sum_{i=0}^{n}a_if(x_i)+E(f), \]

    其中

    \[ E(f)=\frac{1}{(n+1)!}\int_a^b f^{(n+1)}(\xi(x))\prod_{i=0}^{n}(x-x_i)\,dx . \]

    关键：权 \(a_i\) 只依赖节点位置，与 \(f\) 无关——这就是"求积公式"的全部内容。

    为什么权可以预先算好

    \(L_i\) 是纯几何量（节点决定的插值基函数），所以 \(\int L_i\) 可以离线算成常数。真正依赖 \(f\) 的只有 \(E(f)\)。

    11.2 梯形公式#

    11.2.1 推导#

    取 \(n=1\)：\(x_0=a,\ x_1=b,\ h=b-a\)，

    \[ P_1(x)=\frac{x-x_1}{x_0-x_1}f(x_0)+\frac{x-x_0}{x_1-x_0}f(x_1). \]

    逐项积分：

    \[ \int_{x_0}^{x_1}\frac{x-x_1}{x_0-x_1}\,dx=\frac{1}{-h}\cdot\left.\frac{(x-x_1)^2}{2}\right|_{x_0}^{x_1}=\frac{h}{2}, \qquad \int_{x_0}^{x_1}\frac{x-x_0}{x_1-x_0}\,dx=\frac{h}{2}. \]

    于是

    \[ \int_a^b f\,dx=\frac{h}{2}\big[f(x_0)+f(x_1)\big]+E_T,\qquad E_T=\frac{1}{2}\int_{x_0}^{x_1}f''(\xi(x))(x-x_0)(x-x_1)\,dx . \]

    11.2.2 误差项#

    \((x-x_0)(x-x_1)\le 0\) 在 \([x_0,x_1]\) 上不变号，故可用积分加权中值定理：存在 \(\xi\in(x_0,x_1)\) 使

    \[ E_T=\frac{f''(\xi)}{2}\int_{x_0}^{x_1}(x-x_0)(x-x_1)\,dx . \]

    计算积分：令 \(x=x_0+th\)，\((x-x_0)(x-x_1)=th\cdot(t-1)h\)，\(dx=h\,dt\)，

    \[ \int_{x_0}^{x_1}(x-x_0)(x-x_1)\,dx=h^3\int_0^1 t(t-1)\,dt =h^3\Big[\frac{t^3}{3}-\frac{t^2}{2}\Big]_0^1=-\frac{h^3}{6}. \]

    所以

    \[ \boxed{\ \int_a^b f\,dx=\frac{h}{2}\big[f(a)+f(b)\big]-\frac{h^3}{12}f''(\xi),\qquad \xi\in(a,b)\ } \]

    误差为什么是负的

    \(f''>0\)（凸函数）时梯形面积大于真实积分——梯形的斜边在曲线上方。负号与此一致。

    11.3 Simpson 公式#

    11.3.1 朴素推导（只到 \(O(h^4)\)）#

    取 \(n=2\)，\(x_0=a,\ x_1=a+h,\ x_2=b\)，\(h=(b-a)/2\)。对二次插值多项式积分可得

    \[ \int_{x_0}^{x_2}f\,dx=\frac{h}{3}\big[f(x_0)+4f(x_1)+f(x_2)\big]+E, \quad E=\int_{x_0}^{x_2}\frac{(x-x_0)(x-x_1)(x-x_2)}{6}f^{(3)}(\xi(x))\,dx . \]

    但 \((x-x_0)(x-x_1)(x-x_2)\) 在 \([x_0,x_2]\) 上变号，中值定理用不上，误差只能写成 \(O(h^4)\) 且含 \(f^{(3)}\)——比实际精度低一阶。

    11.3.2 改进推导（得到 \(f^{(4)}\)）#

    在 \(x_1\) 处作三阶 Taylor 展开：

    \[ f(x)=f(x_1)+f'(x_1)(x-x_1)+\frac{f''(x_1)}{2}(x-x_1)^2+\frac{f'''(x_1)}{6}(x-x_1)^3+\frac{f^{(4)}(\xi(x))}{24}(x-x_1)^4 . \]

    逐项积分，注意 \(h=x_2-x_1=x_1-x_0\)，所以

    \[ \int_{x_0}^{x_2}(x-x_1)\,dx=0,\qquad \int_{x_0}^{x_2}(x-x_1)^3\,dx=0 \]

    （奇次项关于 \(x_1\) 对称抵消），而

    \[ \int_{x_0}^{x_2}(x-x_1)^2\,dx=\frac{(h)^3-(-h)^3}{3}=\frac{2h^3}{3}. \]

    于是

    \[ \int_{x_0}^{x_2}f\,dx=2hf(x_1)+\frac{f''(x_1)}{2}\cdot\frac{2h^3}{3} +\frac{1}{24}\int_{x_0}^{x_2}f^{(4)}(\xi(x))(x-x_1)^4\,dx . \]

    \((x-x_1)^4\ge0\) 不变号，对末项用加权中值定理：存在 \(\xi_1\) 使

    \[ \frac{1}{24}\int_{x_0}^{x_2}f^{(4)}(\xi(x))(x-x_1)^4dx =\frac{f^{(4)}(\xi_1)}{24}\cdot\frac{2h^5}{5}=\frac{h^5}{60}f^{(4)}(\xi_1). \]

    故

    \[ \int_{x_0}^{x_2}f\,dx=2hf(x_1)+\frac{h^3}{3}f''(x_1)+\frac{h^5}{60}f^{(4)}(\xi_1). \tag{$\ast$} \]

    再用二阶导数的中点公式

    \[ f''(x_1)=\frac{f(x_0)-2f(x_1)+f(x_2)}{h^2}-\frac{h^2}{12}f^{(4)}(\xi_2) \]

    代入 \((\ast)\)：

    \[ \int_{x_0}^{x_2}f\,dx=2hf(x_1)+\frac{h}{3}\big[f(x_0)-2f(x_1)+f(x_2)\big]-\frac{h^5}{36}f^{(4)}(\xi_2)+\frac{h^5}{60}f^{(4)}(\xi_1). \]

    合并前两项正是 Simpson 组合：

    \[ \boxed{\ \int_{x_0}^{x_2}f\,dx=\frac{h}{3}\big[f(x_0)+4f(x_1)+f(x_2)\big]+E_S,\qquad E_S=h^5\Big[\frac{f^{(4)}(\xi_1)}{60}-\frac{f^{(4)}(\xi_2)}{36}\Big] \ } \]

    两个中值点可以合并为同一个 \(\xi\in(x_0,x_2)\)（严格证明需要更细的分析，课件注明"可由其他方法证明"），合并后系数为

    \[ \frac{1}{60}-\frac{1}{36}=-\frac{1}{90}, \]

    即

    \[ \boxed{\ \int_{x_0}^{x_2}f\,dx=\frac{h}{3}\big[f(x_0)+4f(x_1)+f(x_2)\big]-\frac{h^5}{90}f^{(4)}(\xi)\ } \]

    结论：Simpson 公式对三次多项式精确（\(f^{(4)}\equiv0\)）。

    11.3.3 数值对比#

    在 \([0,2]\) 上比较两种公式（\(h=1\)）：

    \(f(x)\) 精确值 梯形 Simpson
    \(x^2\) 2.667 4.000 2.667
    \(x^4\) 6.400 16.000 6.667
    \((x+1)^{-1}\) 1.099 1.333 1.111
    \(\sqrt{1+x^2}\) 2.958 3.326 2.964
    \(\sin x\) 1.416 0.909 1.425
    \(e^x\) 6.389 8.389 6.421

    \(x^2\) 一列 Simpson 完全精确——因为误差含 \(f^{(4)}\) 而 \((x^2)^{(4)}=0\)。

    11.4 代数精度与 Newton–Cotes 公式#

    11.4.1 定义#

    代数精度（degree of precision）：使求积公式对 \(x^k\ (k=0,1,\dots,n)\) 全部精确的最大 \(n\)。

    等价说法：精度为 \(n\) \(\iff\) 对所有次数 \(\le n\) 的多项式误差为零，且存在某个 \(n+1\) 次多项式误差非零。

    11.4.2 梯形与 Simpson 的精度#

    梯形：\(n=1\)。

    • \(f=1\)：\(\frac{h}{2}(1+1)=h=\int_a^b 1\) ✓
    • \(f=x\)：\(\frac{h}{2}(a+b)=\frac{(b-a)(a+b)}{2}=\frac{b^2-a^2}{2}\) ✓
    • \(f=x^2\)：误差 \(=-\frac{h^3}{12}\cdot2\ne0\) ✗

    故梯形精度为 \(1\)。

    Simpson：\(n=3\)。误差含 \(f^{(4)}\)，故对 \(1,x,x^2,x^3\) 全精确；对 \(x^4\) 误差 \(=-\frac{h^5}{90}\cdot24\ne0\)。故精度为 \(3\)。

    11.4.3 Newton–Cotes 误差公式#

    定理. 设 \(\sum_{i=0}^n a_if(x_i)\) 为 \((n+1)\) 点闭型 Newton–Cotes 公式（\(x_0=a,\ x_n=b,\ h=(b-a)/n\)）。则存在 \(\xi\in(a,b)\)，使

    \[ \int_a^b f\,dx=\sum_{i=0}^n a_if(x_i)+ \begin{cases} \dfrac{h^{n+3}f^{(n+2)}(\xi)}{(n+2)!}\displaystyle\int_0^n t^2(t-1)\cdots(t-n)\,dt, & n\ \text{为偶},\\[3mm] \dfrac{h^{n+2}f^{(n+1)}(\xi)}{(n+1)!}\displaystyle\int_0^n t(t-1)\cdots(t-n)\,dt, & n\ \text{为奇}. \end{cases} \]

    证明思路. 作变量替换 \(x=a+th\)，插值余项为

    \[ E(f)=\frac{h^{n+2}}{(n+1)!}\int_0^n f^{(n+1)}(\xi(a+th))\prod_{j=0}^{n}(t-j)\,dt . \]
    • \(n\) 为奇数：\(\prod_{j=0}^n(t-j)\) 关于 \(t=n/2\) 反对称，积分不为零，直接用加权中值定理（核不变号？不——核变号，但可对 \(\int_0^n\) 用推广中值定理）得 \(O(h^{n+2})\)。
    • \(n\) 为偶数：\(\prod_{j=0}^n(t-j)\) 关于 \(t=n/2\) 对称，其积分为零，一阶项消失。把 \(f^{(n+1)}\) 在 \(t=n/2\) 处再展开一次，多出一项正比于 \(\int_0^n t^2\prod(t-j)dt\)，于是阶数升到 \(h^{n+3}\)。

    这正是"偶数点公式精度高一级"的来源：Simpson（\(n=2\)）精度 3 而非 2，Simpson ⅜（\(n=3\)）精度仍是 3。

    11.4.4 常用 Newton–Cotes 公式#

    \(n\) 名称 公式 误差
    1 梯形 \(\frac{h}{2}(f_0+f_1)\) \(-\frac{h^3}{12}f''\)
    2 Simpson \(\frac{h}{3}(f_0+4f_1+f_2)\) \(-\frac{h^5}{90}f^{(4)}\)
    3 Simpson ⅜ \(\frac{3h}{8}(f_0+3f_1+3f_2+f_3)\) \(-\frac{3h^5}{80}f^{(4)}\)
    4 Boole \(\frac{2h}{45}(7f_0+32f_1+12f_2+32f_3+7f_4)\) \(-\frac{8h^7}{945}f^{(6)}\)

    11.5 复合求积#

    11.5.1 动机#

    \([0,4]\) 上 \(\int e^x dx\)：

    做法 \(h\) 结果 误差
    单段 Simpson 2 56.76958 \(-3.171\)
    2 段 1 53.86385 \(-0.266\)
    4 段 0.5 53.61622 \(-0.018\)

    误差按 \(h^4\) 缩小：\(h\) 减半，误差约降 16 倍。

    11.5.2 复合 Simpson 的推导#

    取偶数 \(n\)，\(h=(b-a)/n\)，\(x_j=a+jh\)。把 \([a,b]\) 分成 \(n/2\) 个长度为 \(2h\) 的子区间，每个用一次 Simpson：

    \[ \int_a^b f\,dx=\sum_{j=1}^{n/2}\left\{\frac{h}{3}\big[f(x_{2j-2})+4f(x_{2j-1})+f(x_{2j})\big]-\frac{h^5}{90}f^{(4)}(\xi_j)\right\}. \]

    合并同类项：内部节点 \(x_{2j}\)（\(j=1,\dots,n/2-1\)）同时出现在左右两个子区间，被计两次；奇数下标节点只出现一次且系数 4；两端点系数 1：

    \[ \boxed{\ \int_a^b f\,dx=\frac{h}{3}\Big[f(a)+2\!\!\sum_{j=1}^{n/2-1}\!\!f(x_{2j})+4\sum_{j=1}^{n/2}f(x_{2j-1})+f(b)\Big]+E(f) \ } \]

    误差合并：\(E(f)=-\dfrac{h^5}{90}\sum_{j=1}^{n/2}f^{(4)}(\xi_j)\)。因 \(f^{(4)}\) 连续，由最值定理存在上下界，故

    \[ \frac{n}{2}\min f^{(4)}\le\sum_{j=1}^{n/2}f^{(4)}(\xi_j)\le\frac{n}{2}\max f^{(4)} \quad\Longrightarrow\quad \min f^{(4)}\le\frac{2}{n}\sum_{j=1}^{n/2}f^{(4)}(\xi_j)\le\max f^{(4)} . \]

    由介值定理，存在 \(\mu\in(a,b)\) 使 \(f^{(4)}(\mu)=\dfrac{2}{n}\sum f^{(4)}(\xi_j)\)。于是

    \[ E(f)=-\frac{h^5}{90}\cdot\frac{n}{2}f^{(4)}(\mu)=-\frac{n h^5}{180}f^{(4)}(\mu) =-\frac{b-a}{180}h^4f^{(4)}(\mu). \]
    \[ \boxed{\ \int_a^b f\,dx=\frac{h}{3}\Big[f(a)+2\!\!\sum_{j=1}^{n/2-1}\!\!f(x_{2j})+4\sum_{j=1}^{n/2}f(x_{2j-1})+f(b)\Big]-\frac{b-a}{180}h^4f^{(4)}(\mu) \ } \]

    \(O(h^4)\) 与 \(O(h^5)\) 不矛盾

    单段 Simpson 的 \(h=(b-a)/2\) 是固定的；复合公式的 \(h=(b-a)/n\) 可以任意减小。所以复合公式虽写作 \(O(h^4)\)，实际能达到任意精度。

    11.5.3 复合梯形#

    同理（每个子区间用一次梯形）：

    \[ \boxed{\ \int_a^b f\,dx=\frac{h}{2}\Big[f(a)+2\sum_{j=1}^{n-1}f(x_j)+f(b)\Big]-\frac{b-a}{12}h^2f''(\mu) \ } \]

    梯形只需一段，故 \(n\) 可奇可偶；Simpson 必须偶数 \(n\)（每段两格）。

    11.5.4 舍入误差不随 \(n\) 增长#

    设每个函数值带误差 \(f(x_i)=\tilde f(x_i)+e_i\)，\(|e_i|\le\varepsilon\)。复合 Simpson 的权绝对值和：

    \[ \sum|a_i|=\frac{h}{3}\big[1+2\cdot\tfrac n2+4\cdot\tfrac n2+1\big]\ \text{的量级} =\frac{h}{3}\big[2+3n\big]\approx nh=(b-a). \]

    严格地

    \[ |e(h)|\le\frac{h}{3}\big[\varepsilon+2(\tfrac n2-1)\varepsilon+4\cdot\tfrac n2\varepsilon+\varepsilon\big] =nh\varepsilon=(b-a)\varepsilon . \]
    \[ \boxed{\ \text{舍入误差上界}=(b-a)\varepsilon\ \text{，与 }n\text{ 无关}\ } \]

    意义：加密网格不会放大舍入误差，所以复合低阶公式比高阶单段公式更实用。

    11.6 Romberg 积分#

    11.6.1 误差的幂级数结构#

    对 \(f\in C^\infty\)，复合梯形的误差可展开成 \(h\) 的偶次幂（Euler–Maclaurin 公式）：

    \[ \boxed{\ T(h)=\int_a^b f\,dx+K_1h^2+K_2h^4+K_3h^6+\cdots\ } \]

    其中 \(K_i\) 只依赖 \(f^{(2i-1)}\) 在端点的值，与 \(h\) 无关。

    11.6.2 Richardson 外推的推导#

    设

    \[ T(h)=I+K_1h^2+K_2h^4+\cdots \]

    取步长减半：

    \[ T(h/2)=I+K_1\frac{h^2}{4}+K_2\frac{h^4}{16}+\cdots \]

    消去 \(h^2\) 项：计算 \(4T(h/2)-T(h)\)：

    \[ 4T(h/2)-T(h)=3I+\Big(4\cdot\frac{K_1h^2}{4}-K_1h^2\Big)+\Big(4\cdot\frac{K_2h^4}{16}-K_2h^4\Big)+\cdots =3I-\frac34K_2h^4+\cdots \]

    于是

    \[ \boxed{\ \frac{4T(h/2)-T(h)}{3}=I+O(h^4) \ } \]

    即

    \[ R_{k,2}=R_{k,1}+\frac{1}{3}\big(R_{k,1}-R_{k-1,1}\big),\qquad k=2,3,\dots \]

    同理，若已有 \(O(h^{2j-2})\) 的两个近似，消去 \(h^{2j-2}\) 项：

    \[ \frac{4^{j-1}T_{j-1}(h/2)-T_{j-1}(h)}{4^{j-1}-1}=I+O(h^{2j}), \]

    即

    \[ \boxed{\ R_{k,j}=R_{k,j-1}+\frac{1}{4^{\,j-1}-1}\big(R_{k,j-1}-R_{k-1,j-1}\big),\qquad k=j,j+1,\dots \ } \]

    系数来历：\(4^{j-1}-1\) 就是"两次步长的 \(h^{2j-2}\) 项之比 \(2^{2j-2}=4^{j-1}\) 减 1"。

    11.6.3 例：sin x 在 [0, π] 上的积分#

    真值 \(2\)。复合梯形取 \(n=1,2,4,8,16\)：

    \[ \begin{aligned} R_{1,1}&=\tfrac{\pi}{2}(\sin0+\sin\pi)=0\\ R_{2,1}&=\tfrac{\pi}{4}(\sin0+2\sin\tfrac\pi2+\sin\pi)=1.57079633\\ R_{3,1}&=1.89611890,\quad R_{4,1}=1.97423160,\quad R_{5,1}=1.99357034 \end{aligned} \]

    外推：

    \[ \begin{aligned} R_{2,2}&=R_{2,1}+\tfrac13(R_{2,1}-R_{1,1})=2.09439511\\ R_{3,2}&=R_{3,1}+\tfrac13(R_{3,1}-R_{2,1})=2.00455976\\ R_{4,2}&=2.00026917,\quad R_{5,2}=2.00001659\\[1mm] R_{3,3}&=R_{3,2}+\tfrac1{15}(R_{3,2}-R_{2,2})=1.99857073\\ R_{4,3}&=1.99998313,\quad R_{5,3}=1.99999975\\[1mm] R_{4,4}&=R_{4,3}+\tfrac1{63}(R_{4,3}-R_{3,3})=2.00000555\\ R_{5,4}&=2.00000001,\qquad R_{5,5}=1.99999999 \end{aligned} \]

    Romberg 表：

    \(k\) \(O(h^2)\) \(O(h^4)\) \(O(h^6)\) \(O(h^8)\) \(O(h^{10})\)
    1 0
    2 1.57079633 2.09439511
    3 1.89611890 2.00455976 1.99857073
    4 1.97423160 2.00026917 1.99998313 2.00000555
    5 1.99357034 2.00001659 1.99999975 2.00000001 1.99999999

    只用 17 个函数值（\(n=16\)）就得到 \(10^{-8}\) 精度——纯靠外推，没有额外求值。

    11.6.4 MATLAB#

    function [R, k] = romberg(f, a, b, n, tol)
% Romberg 积分：返回 n×n 表 R，R(k,j) 为 O(h^{2j}) 近似
if nargin < 5, tol = 1e-10; end
R = zeros(n, n);
h = b - a;
R(1,1) = h/2 * (f(a) + f(b));
for k = 2:n
    h = h/2;
    x = a + h : 2*h : b - h;          % 新增的中点
    R(k,1) = 0.5*R(k-1,1) + h*sum(f(x));   % 复合梯形递推
    for j = 2:k
        R(k,j) = R(k,j-1) + (R(k,j-1) - R(k-1,j-1)) / (4^(j-1) - 1);
    end
    % 双列判据：连续两行对角线都收敛才接受
    if k >= 3 && abs(R(k,k)-R(k-1,k-1)) < tol && abs(R(k-1,k-1)-R(k-2,k-2)) < tol
        R = R(1:k, 1:k); return
    end
end
end

    只看一行会误判

    两个相邻对角线元素相等，可能只是"都算错了但错得一样"。所以要检查连续两对都收敛（\(\left|R_{k-1,k-1}-R_{k,k}\right|\) 与 \(\left|R_{k-2,k-2}-R_{k-1,k-1}\right|\) 同时小于容差）。

    坑与陷阱#

    八条

    1. Simpson 必须偶数 \(n\)：每段吃两个子区间，\(n\) 为奇数会漏掉最后半格。
    2. 梯形公式误差是 \(O(h^2)\)，Simpson 是 \(O(h^4)\)，但单段 Simpson 的 \(h\) 固定为 \((b-a)/2\)，想提精度必须复合。
    3. 复合 Simpson 的误差是 \(O(h^4)\) 而不是 \(O(h^5)\)——单段的 \(h^5\) 是绝对误差量级，复合后被 \(n\) 放大成 \((b-a)h^4/180\)。
    4. Simpson 对三次多项式精确，别按"二次插值所以精度 2"去记。
    5. 代数精度看的是"对 \(x^k\) 精确"，不是插值多项式的次数。
    6. 变号核不能直接用中值定理：Simpson 的 \((x-x_0)(x-x_1)(x-x_2)\) 变号，所以朴素推导只能给 \(O(h^4)\)。
    7. Romberg 依赖 \(f\in C^\infty\)（误差要能展成 \(h^2\) 的幂级数）；被积函数不光滑时外推可能发散。
    8. 舍入误差界 \((b-a)\varepsilon\) 与 \(n\) 无关，但截断误差仍随 \(h\) 减小而减小——两者权衡决定最优 \(n\)。

    速览#

    1. 插值型求积：\(a_i=\int L_i(x)dx\)，权只与节点有关。
    2. 梯形：\(\frac h2(f_0+f_1)\)，误差 \(-\frac{h^3}{12}f''(\xi)\)，代数精度 1。
    3. Simpson：\(\frac h3(f_0+4f_1+f_2)\)，误差 \(-\frac{h^5}{90}f^{(4)}(\xi)\)，代数精度 3。
    4. 偶数点 Newton–Cotes 公式精度高一级（误差中的一阶项因对称性消失）。
    5. 复合 Simpson：\(O(h^4)\)，\(-\frac{b-a}{180}h^4f^{(4)}(\mu)\)；复合梯形：\(O(h^2)\)，\(-\frac{b-a}{12}h^2f''(\mu)\)。
    6. 复合公式的合并规则：端点权 1、奇数节点权 4、偶数内部节点权 2。
    7. 复合求积的舍入误差 \(\le(b-a)\varepsilon\)，与 \(n\) 无关——加密安全。
    8. Romberg：复合梯形误差可展成 \(K_1h^2+K_2h^4+\cdots\)，逐步外推消项。
    9. 外推系数 \(1/(4^{j-1}-1)\)，\(j=2\) 时是 \(1/3\)，\(j=3\) 时是 \(1/15\)。
    10. 停止判据要用连续两对对角线同时收敛。
